# Public_company

全国上市公司地域与行业分布地图，帮助辽宁物化生家庭先观察真实产业落点，再继续核对专业、学校与地区的连接。

合并到主站后，页面入口为：

```text
/Public_company/
```

## 目录

- `index.html`、`assets/`、`data/`：可直接由静态站点托管的发布产物；
- `source/`：Vite 源码、数据生成脚本、数据校验和自动化测试；
- 页面运行时只读取本目录静态数据，不调用地图服务，也不需要高德账号或密钥。

## 本地开发与发布

```bash
cd Public_company/source
npm ci
npm run check:data
npm test
npm run build
npm run preview
```

生成并同步根目录发布产物：

```bash
npm run release
```

浏览器回归需要先安装 Playwright 与 Chromium：

```bash
npm install --no-save --no-package-lock playwright@1.55.0
npx playwright install chromium
npm run test:browser
```

## 当前范围

- 全国 34 个省级行政区矢量地图及南海诸岛示意；
- 沪市主板、深市主板、原中小板、科创板、创业板、北交所；
- 省份上市公司数量；
- 点击省份查看企业名称、证券代码、上市板块、行业与主要方向；
- 企业名称、代码、行业和经营方向搜索；
- 当前快照共 5,522 家沪深京 A 股公司。

## 数据边界

- 地图开发底图：ECharts 3.6.2 随包中国 GeoJSON，BSD-3-Clause；南海诸岛和钓鱼岛几何沿用同版本修正代码。
- 公司范围：新浪财经公开地域板块中的沪深京 A 股，生成数据时排除 B 股、无法识别板块及已退市简称。
- 地区字段：新浪财经地域板块归属，适合作为注册省份线索，但不是工商注册地址全文。
- 行业字段：新浪财经公开行业板块分类。
- 主要方向：优先取东方财富公开主营构成中的最新披露产品，缺失时回退为行业分类；不等同于完整经营范围。
- 快照会随上市、退市、迁址和披露更新而变化；它用于产业观察，不构成就业承诺或投资建议。
- 当前地图用于产品验证；正式大规模传播前，应换用经过审图的标准地图并完成相应合规核验。
