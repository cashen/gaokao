# Component Contract Map

- chip：`.ln-chip` / `.ln-filter-summary-chip` / `.ln-tab-chip` / `.lm-pill`，不拆字。
- card：`.ln-result-card` / `.ln-selection-card` / `.ln-report-card` / `.ln-mainline-card` / `.ln-trend-card`，显式类，不使用 `[class*=card]`。
- report：最大阅读宽度，不铺满 PC 大屏。
- diagnosis：默认短解释，长提醒可折叠；不得显示工程状态。
- actions：每个区域只允许一个主按钮，移动端按钮组单列。
