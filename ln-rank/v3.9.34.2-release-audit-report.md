# v3.9.34.2 Release Audit Report

## Version
v3.9.34.2-ln-rank-aux-entry-density-ui-consistency-no-fenxi

## Scope
This release only adjusts the homepage auxiliary background entry density and UI weight. It does not change the main score query logic, local-mainline / 211-mainline APIs, Feishu, AI diagnosis, selection pool, or rank calculation.

## Changes
- 首页“资料与背景复核”从大卡片宣传区压缩为低权重资料入口条。
- 两个入口卡片目标高度从旧版大约 116px 降为 PC 约 64px。
- 主标题、说明文字和入口按钮降级，不再使用强 CTA 视觉。
- Android 下入口单列，按钮短文案“查看”，避免挤压和竖排。
- 延续 v3.9.34.1 的 AI 文案合同、P0 趋势修复、报告统计合同和 no-fenxi 边界。
