## 本版主要修复

1. 修复 `major-trend-accessor.js` 依赖的 `getTrendHint` 缺失问题，避免趋势、报告、飞书与诊断链路动态导入失败。
2. 新增 `diagnosis-human-copy-gate.js`，统一清理 AI/规则兜底/单卡诊断/飞书报告中的工程状态和内部字段。
3. 新增 `report-count-contract.js`，为报告数量一致性提供单一统计口径。
4. 修复“主要参考参考”“方案解读解读”“AI不可用时按规则...”等家长不可读表达。
5. 单卡诊断中将“知识库依据 / 命中已收录学科 / 行业特色相关”改为更适合家长阅读的“背景线索 / 相关学科线索 / 学校行业方向线索”。
6. 增加报告与单卡诊断多终端防溢出 CSS。
