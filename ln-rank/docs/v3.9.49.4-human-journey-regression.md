# v3.9.49.4 多终端真实体验回归合同

版本：`v3.9.49.4-ln-rank-multi-terminal-human-journey-regression-12-role-no-fenxi`

## 目标

本版本不清理目录、不裁剪动态依赖、不改变招生数据和排序口径。只验证并保护真实家长的完整路径：输入分数 → 查看结果范围 → 浏览更多 → 比较 → 加入自选池 → 生成报告 → 返回修改。

## 固定终端

- 手机窄屏：375×812，补充 360×800。
- Android Chrome：412×915，补充 360×780；覆盖地址栏伸缩、软键盘和系统返回。
- iPad 横屏：1024×768，补充 1180×820。
- PC 宽屏：1440×900，补充 1920×1080，并补测浏览器缩放 125%。

## 固定分数

- 555 分：结果密集、连续分页、自选池 10—20 条。
- 580 分：同校 / 同专业比较、普通项目与合作或高收费项目隔离。
- 600 分：证据边界、历史参考表达、校区费用和项目资格复核。

## 七条路径

1. 首次进入并查询。
2. 理解符合条件、已加载、当前显示数量。
3. 展示已加载下一批与请求下一页。
4. 当前列表与院校背景提示切换。
5. 同校 / 同专业比较的打开、切换、扩展与关闭。
6. 自选池添加、去重、删除、排序、返回继续添加。
7. 生成前检查、报告生成、修改后报告过期。

## 发布阻断

- P0：白屏、查询失败、数据链或报告链断裂。
- P1：主要按钮不可操作、固定区遮挡、分页重复或丢数据、比较项目混组、自选池状态不一致。
- P2：阅读顺序不自然、范围文案容易误解、375px 横向溢出。

P0/P1 必须阻止合并；P2 原则上在本版本修复。

## 自动合同

- 新增 `css/dist/ln-rank-multi-terminal.v3949_4.css`，只覆盖布局、触控尺寸、安全区和响应式阅读顺序。
- 新增 `js/ux/multi-terminal.v3949_4.js`，只增加滚动锚点、重复点击保护、焦点恢复、Android 动态视口和返回行为、状态播报。
- 新增 `js/ux/v3949_4-self-check.js`，从自测页检查入口、版本、保护层与发布合同。
- 首页和自选池页面同时加载体验保护层；其他辅助页只同步版本与缓存查询参数。

## 禁区

不得修改或删除：

- `/fenxi/`
- `functions/fenxi/`
- `functions/_middleware.js`
- `ln-rank/js/feature/**` 的既有运行模块
- domain/config/knowledge/data/kb 动态依赖
- Functions API 和报告构建链的既有语义

发现不确定依赖时保留文件，修复行为，不做静态最小化裁剪。
