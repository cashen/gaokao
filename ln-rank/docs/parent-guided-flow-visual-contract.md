# v3.9.37 家长向导式视觉落地合同

本版不是门户化改造，只服务辽宁物理类/物化生家庭。UI 工程师只能调整视觉层级、向导顺序、卡片密度、按钮主次和移动端阅读秩序，不能移除主查询、自选、报告、飞书、AI/单卡诊断、省内背景、211 背景、趋势、核验清单和数据边界。

## 可见变化
- 查询页增加 4 步向导：输入位置、筛专业、加入自选、生成报告核验。
- 自选池增加方案整理向导：确认分数、检查已选、看结构、保存报告。
- 省内/211/趋势页增加复核顺序提示，明确辅助属性。
- 按钮、卡片、报告、诊断和移动端布局统一使用家长可读视觉层级。

## 不改动
- 不改查询算法、数据读取、AI 调用、飞书接口、本地背景/211 背景匹配、趋势数据逻辑。
