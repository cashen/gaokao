# ln-rank 产品意图保真表｜v3.9.46.3

本表用于 UI 工程师接入。UI 可以调整视觉表达，但不能让产品经理、高报师和架构师定义的关键能力“破相”、被删除、被弱化到不可见，或被误写成录取判断。

## 总原则

- 主流程优先：输入孩子位置 → 筛出可讨论专业 → 加入自选 → 检查方案结构 → 生成报告 → 人工核验。
- 辅助复核降权但不删除：省内背景、211 背景、近两年位次变化、AI/单卡解释都服务于复核，不抢主查询。
- 高报核验点不能丢：校区、计划人数、体检、学费、培养模式、选科/单科、专业路径接受度。
- 家长正文不出现工程状态：AI fallback、rules-only、JSON parse、stack trace 等只能进 debug。
- 不写录取承诺：禁止“推荐、稳、保底、捡漏、能上、录取概率、王牌、优势专业”。

## 页面意图表

| 页面/模块 | 产品目的 | 家长要理解什么 | 可折叠/弱化 | 不可删除 |
|---|---|---|---|---|
| 查询页 / 分数与筛选 | 建立孩子当前位置并筛出可讨论专业 | 先查专业，不是直接判断录取 | 更多筛选可折叠 | 分数输入、查看专业、当前查看摘要 |
| 查询页 / 当前查看摘要 | 告诉家长当前条件 | 我现在按什么条件看结果 | 完整条件可折叠 | 短摘要不可删除，不可竖排 |
| 查询页 / 结果卡片 | 展示可讨论专业条目 | 这是什么专业、离孩子位置多远、要先看什么 | 背景长解释可折叠 | 学校、专业、2025分/位次、相对孩子位置、加入自选 |
| 自选池 / 顶部状态 | 把收藏夹升级为方案工作台 | 当前方案是否成型、还缺什么 | 详细解释可折叠 | 已选数量、前中后结构、核验数量 |
| 自选池 / 卡片操作 | 支持排序、解释、删除、报告 | 我能整理这套方案 | 操作可分主次 | 上移/下移/删除/查看解释/生成报告入口 |
| 报告 / 六段结构 | 输出家庭复核文档 | 概要、结构、清单、边界 | 段内长说明可精简 | 六段结构、最终清单、确认清单、数据边界 |
| 单卡诊断 | 解释单条为什么可讨论 | 依据、现实提醒、核验点 | 现实提醒可折叠 | 一句话判断、依据、需要核验、边界 |
| 飞书报告 | 保存和复盘方案 | 不是录取预测，是复核文档 | 失败提示可短 | 入口和人话失败兜底 |
| 省内背景 | 复核辽宁省内学校与专业方向 | 学校背景相关，不等于就业保证 | 入口低权重 | 学校/专业/孩子位置三入口、边界说明 |
| 211 背景 | 复核 211 院校与本科方向 | 211 是背景线索，不是光环推荐 | 入口低权重 | 学校/专业/孩子位置三入口、军事类边界 |
| 分数趋势 | 看两年同校同专业变化 | 趋势不是预测 | 放报告后段或独立页 | “不代表2026结果”的边界 |
| 自测页 | 发版自查 | 工程用，不给家长 | 可隐藏于入口 | active 版本、资源、文案合同检查 |

## UI 工程师施工边界

可以改：字号、颜色、间距、卡片密度、按钮主次、折叠方式、移动端布局。

不能改：查询逻辑、筛选逻辑、数据口径、报告六段结构、核验清单、AI/单卡诊断语义、飞书入口、省内/211/趋势入口、版本合同。
