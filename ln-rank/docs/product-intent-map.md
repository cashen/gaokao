# ln-rank 产品意图保真表｜v3.9.49.0

本文件用于发版自测和 UI 工程接入，不面向家长展示。

## 主流程不可删除

输入分数/位次 → 查看符合条件的专业 → 全部专业/学校强项 → 放进报告 → 打开自选 → 复制或生成报告 → 官方系统与招生章程核验。

## 不可删除的用户入口

- 查询专业
- 全部专业 / 学校强项视图切换
- 放进报告
- 打开自选
- 看懂这条
- 专业理解与家庭确认问题
- 省内背景 / 211 背景辅助复核
- 核验清单

## UI 底线

PC 端不允许反馈浮层遮挡卡片；移动端必须保留安全距离。结果视图控制区不能进入专业卡片 grid。长专业名、专业理解 KB、学校强项提示必须分层展示，不能撑爆卡片。

## 文案边界

不说冲稳保、能上、录取概率、捡漏、就业好坏、薪资、高薪、推荐报考。本工具只用于家庭讨论和人工复核。
