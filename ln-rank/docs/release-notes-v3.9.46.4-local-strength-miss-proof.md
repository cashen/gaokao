# v3.9.46.5｜学校强项防漏看：省内背景 + 211背景统一视图

## 本版目标

基于 v3.9.46.2 唯一基线，新增“学校强项防漏看”结果视图。该视图只从当前分数/位次查询结果中识别与辽宁省内学校背景、行业方向或专业建设线索相关的学校专业组合，帮助家长防止只看学校综合名气而漏看有学校底子的方向。

## 关键边界

- 不改 /fenxi 静态目录。
- 不改 functions/fenxi/。
- 不改 functions/_middleware.js。
- 不新增推荐 API。
- 不改变 /api/major-bands 主查询口径。
- 不改变 selection-pool localStorage 主 key。
- 不使用“推荐、稳、保底、能上、录取概率、捡漏、最适合”等前台话术。

## 主要变更

1. 搜索结果区新增“全部专业 / 学校强项”二级视图。
2. 新增 `ln-rank/js/feature/major-pool/local-strength-view.js`，复用既有省内背景与 localContext 能力。
3. “学校强项”只从当前结果中筛出，不脱离当前分数窗口。
4. 学校强项卡片显示：为什么提醒、和当前分数关系、填报前再确认。
5. 放进报告时保存 `localStrengthMark`，保持旧数据兼容。
6. 自选池增加“本次别漏看的学校强项方向”摘要。
7. 复制文字版报告与飞书报告增加学校强项/院校背景复核内容。
8. 版本合同同步到 v3.9.46.5 / v3946_5，并保留 `LN_RANK_RELEASE_CONTRACT` 与 `RELEASE_CONTRACT` 双导出。

## 2026 一分一段后的维护口径

学校强项证据层相对稳定，2026 一分一段出来后主要更新年度位次换算、等位分/同位分参考、当年计划和专业位次映射。不要把学校强项库写死成某个分数可报某专业。
