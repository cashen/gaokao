# 辽宁属地强链专业库 v0.1

> 用途：作为 `/ln-rank/` 与 `/fenxi` 后续“辽宁属地强链专业识别”的规则底稿。  
> 目标：不是做泛泛的“王牌专业”标签，而是识别辽宁本地院校中 **学校历史、行业底盘、专业名称、就业路径高度一致** 的专业组合。  
> 版本建议：`v3.9.30-ln-rank-local-strong-chain-contract-no-fenxi`  
> 适用范围：辽宁物理类专业筛选、专业卡片、自选专业页、生成前确认、飞书报告诊断。

## 0. 命名规则：不要直接给家长看“一级命中”

“一级命中”是内部开发词，家长不一定理解。建议改成：

| 内部概念 | 内部字段 | 家长显示 | 含义 |
|---|---|---|---|
| 一级命中 | `coreHit` | 学校主干方向 | 专业与学校历史、行业背景、学科底盘、就业路径高度一致 |
| 二级命中 | `supportHit` | 学校特色相关 | 专业不是第一门面，但明显服务学校主线行业 |
| S 级命中 | `tier: S` | 辽宁属地强链 | 辽宁本地院校中非常值得重点识别的专业链 |
| A 级命中 | `tier: A` | 属地特色线索 | 有明显特色，但需结合招生计划、专业方向、孩子接受度复核 |

家长端推荐显示：

```text
辽宁属地强链 · 学校主干方向
辽宁属地特色 · 学校特色相关
```

不要显示：

```text
一级命中
二级命中
必选
推荐
稳赢
```

## 1. 匹配规则设计

### 1.1 三重匹配

程序里建议使用三重匹配，不只靠文本模糊：

```text
学校精确匹配 + 专业标准名匹配 + 本科目录代码候选
```

建议字段：

```js
{
  school: '辽宁石油化工大学',
  schoolAliases: ['辽石化', '辽宁石化'],
  tier: 'S',
  internalDepth: 'coreHit',
  displayLabel: '辽宁属地强链 · 学校主干方向',
  chainName: '石油化工储运方向',
  exactMajorNames2025: ['油气储运工程', '石油工程', '化学工程与工艺'],
  majorNamePatterns: ['油气储运', '石油工程', '化学工程'],
  catalogCodeCandidates: ['081504', '081502', '081301'],
  reviewPoints: ['行业环境', '工作地点', '能源化工企业路径'],
  cardTip: '该专业与学校石油化工储运主线高度一致，建议重点复核油气管道、炼化、储运、能源化工企业路径。'
}
```

### 1.2 2025 专业名处理

实际招生专业名常带括号，应拆成：

| 原始字段 | 处理字段 |
|---|---|
| `电气工程及其自动化(辽宁省高校专项计划)` | baseMajorName = `电气工程及其自动化` |
| `会计学(在珲春校区办学)` | baseMajorName = `会计学` |
| `经济学类(经济学、金融学、国际经济与贸易)` | baseMajorName = `经济学类`；children = `经济学/金融学/国际经济与贸易` |
| `工科试验班(智能制造与先进材料类...)` | baseMajorName = `工科试验班`；children 从括号拆分 |

程序建议：

```text
优先 exactMajorName2025
其次 baseMajorName
再次 majorNamePatterns
最后 catalogCodeCandidates
```

# 7. 最终产品原则

```text
不要把“学校主干方向”写成推荐。
不要把“属地强链”写成录取优势。
不要替家长判断孩子一定适合。
只提示：学校、专业、行业路径的匹配度较高，值得重点复核。
```

家长最终看到的应该是：

```text
这个学校不是最热门，但这个专业是它的主干方向。
这个专业不一定适合所有孩子，但值得认真复核。
这个标签不代表录取概率，只代表学校专业行业链条更一致。
```
