# Bug 自动归类 / 自动纠错 / 自动回归机制

每个 bug 的处理流程：

发现问题 → 判断影响范围 → 归类到规则集 → 修代码 → 新增自动审计用例 → 加入回归矩阵 → 输出审计报告 → 后续发版自动检查。

## 原则
- 小 bug 不小看。
- 先归类，再修复。
- 修一次，沉淀一条规则。
- 规则进审计，审计进发版门禁。
- 代码保持可读、可接手、可维护。
- 禁止堆散乱 fix，禁止过度抽象，禁止后来的人看不懂。

## 本版沉淀
- 低于 400 / 700–750 / 超过 750 导致查询页竖排，归类为“分数边界状态合同 + 查询摘要抗变形合同 + chip/tag 不拆字合同 + CSS 选择器爆炸半径合同”。
- 修复后新增 score-state matrix、long-text stress、chip nowrap、button group mobile、selector blast-radius 审计。
