# v3.9.29 知识库合同落地场景样例

本文件用于发版验收：确认知识库不是形式结构，而是能在专业卡片、已选专业列表、复制文字版、飞书报告里真实出现复核提示。

## 场景 1：585 分，工科试验班（长专业名 / 大类招生）

示例专业：东北大学 · 工科试验班（智能制造与先进材料类、机械类、自动化类、能源动力类）

前台专业卡片应出现：
- 复核提示：试验班/大类招生，确认分流规则、可选专业范围、退出机制、是否承诺具体专业。
- 如命中材料/能源动力词：提示材料方向或能源动力方向需确认学校侧重。

已选专业列表应出现：
- 知识库复核：试验班/大类招生……
- 长专业名默认两行，提供“展开完整名称”。

复制文字版 / 飞书报告应出现：
- 知识库复核提示：大类/试验班提醒……必须查看分流规则、培养方向和招生计划备注。

## 场景 2：520 分，车辆工程 / 交通行业学校

示例专业：大连交通大学 · 车辆工程

前台专业卡片应出现：
- 车辆工程：确认偏汽车、轨道车辆、新能源、车辆仿真，还是设计制造方向。
- 交通行业背景：解释轨道、公路、海运、民航等方向需看培养方向。
- 辽宁省内：复核省内就业、离家距离、生活成本、沈阳/大连产业基础。

已选专业列表应出现：
- 知识库复核：车辆工程方向差异 / 交通行业背景 / 辽宁省内城市背景。

飞书报告应出现：
- 知识库复核提示中汇总车辆工程和交通行业背景。

## 场景 3：610 分，能源与动力工程 / 电力背景

示例专业：华北电力大学 · 能源与动力工程

前台专业卡片应出现：
- 能源动力类：确认电力系统、水动、内燃机、船舶动力或新能源方向。
- 电力行业背景：电气、能源动力相关方向可解释背景，但需查具体专业和校招路径。
- 京津冀：生活成本、竞争压力、距离需要家庭确认。

飞书报告应出现：
- 知识库复核提示：能源动力类需要看学校侧重；电力行业背景只解释背景，不替代招生章程。

## 场景 4：580 分，金融学 / 211 平台

示例专业：辽宁大学 · 金融学

前台专业卡片应出现：
- 经济/金融类：对学校层次、城市资源、数学能力和实习机会较敏感，生成前重点复核。
- 211/双一流只解释平台背景，不替代专业、城市和招生章程复核。
- 辽宁省内城市背景提示。

生成前看一眼应出现：
- 知识库复核：金融类对城市资源和实习机会敏感。

报告应出现：
- 不写“推荐金融”，只写复核提示。

## 场景 5：615 分，临床医学 / 医药背景

示例专业：中国医科大学 · 临床医学

前台专业卡片应出现：
- 医学核心方向：地域属性强、培养周期长，确认规培、执业资格、读研压力、家庭承受周期。
- 医药行业背景：只作为医学/药学/医学技术方向背景说明。
- 辽宁省内就业和生活距离复核。

复制文字版 / 飞书报告应出现：
- 医学方向提醒：培养周期和地域属性较强，确认规培、读研、执业资格和未来就业地。

## 验收原则

- 知识库提示只做“复核”，不做“结论”。
- 不出现录取概率、稳进、必录、保底、兜底、捡漏、强烈推荐、男生适合、女生适合等表达。
- 专业卡片、已选列表、复制文字版、飞书报告至少能在以上场景中各命中一类真实提示。
