# v3.9.29 知识库合同可感知场景

## 场景 1：610 分，电子科学与技术
- 查询页专业卡片：显示“同名专业复核：电子方向可能偏微电子、光电、器件材料、通信或计算机融合，建议查看所在学院和课程设置。”
- 院校背景标签：若命中邮电/电子信息背景，会显示“电子信息背景”。
- 已选专业页：该条下方显示“知识库复核”，提醒电子方向差异和城市产业环境。
- 飞书报告：该条“知识库复核”写入报告，提示不要只看专业名。

## 场景 2：590 分，材料科学与工程 / 材料类
- 查询页专业卡片：提示“材料类不同学校侧重差异大，可能偏航空航天材料、粉体冶金、建筑材料、高分子或汽车材料。”
- 已选专业页：生成前看一眼会汇总“有若干专业名称较宽或方向差异较大，建议重点看培养方向和课程设置。”
- 飞书报告：人工确认部分会保留材料方向复核提示。

## 场景 3：580 分，车辆工程 / 交通运输 / 交通工程
- 查询页专业卡片：提示车辆或交通方向差异，如汽车、轨道车辆、新能源、民航、海事、公路等。
- 院校背景标签：大连交通、西南交通、海事、民航类院校可出现“交通行业背景”。
- 已选专业页：提醒确认学校具体行业侧重。
- 飞书报告：按每条专业写入“知识库复核”。

## 场景 4：570 分，电气工程及其自动化 / 能源动力
- 查询页专业卡片：提示电气/能源方向需确认电力系统、工厂/现场、考证或国企招聘路径。
- 院校背景标签：华北电力、东北电力、上海电力等可能显示“电力行业背景”。
- 已选专业页：汇总中会提示电气/能源方向相关复核。
- 飞书报告：保留“电力行业背景”和“专业方向复核”提示。

## 场景 5：550 分，中外合作 / 高收费专业
- 查询页专业卡片：显示费用复核：确认学费、培养模式、校区、证书口径和家庭承受能力。
- 已选专业页：该专业下方显示“知识库复核”。
- 生成前看一眼：汇总“有 X 个专业涉及费用或合作办学线索”。
- 飞书报告：对应专业写入费用复核提示。

## 场景 6：560 分，法学
- 查询页专业卡片：提示法学要确认法考、长期备考、考公/律所/法务路径。
- 院校背景标签：政法类/五院四系命中时显示“法学传统背景”。
- 已选专业页：提醒学校法学平台和城市实习资源。
- 飞书报告：写入法学路径复核，不写录取概率。

## 场景 7：540 分，教育学 / 师范类
- 查询页专业卡片：提示“教育学不等于直接当老师，需确认具体师范方向、教师资格和当地招聘要求。”
- 已选专业页：提示教师资格、当地招聘、是否接受跨地区就业。
- 飞书报告：进入“知识库复核”，用于家庭讨论。

## 场景 8：520 分，医学 / 药学 / 护理 / 检验
- 查询页专业卡片：提示培养周期、执业资格、地域就业、体检限制。
- 已选专业页：生成前看一眼会提示医学医药方向需要确认培养周期和地域。
- 飞书报告：把医学复核写入每条专业的“知识库复核”。
