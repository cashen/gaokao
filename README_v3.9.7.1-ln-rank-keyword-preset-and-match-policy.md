# v3.9.7.1 ln-rank keyword preset and match policy

本版目标：前端保持短路径和优质体验，后台保持可维护的关键词匹配储备能力。

## 核心变化

1. 搜索页“常用词”改为默认 10 个：计算机、电气、自动化、机械、会计、医学、师范、法学、中外、交通。
2. 新增“更多方向”轻面板：只展开一层，不做专业目录大树，不做多级路径。
3. 更多方向分为：工科技术、医学健康、财经文法、行业项目。
4. 用户输入的原词继续永远参与搜索，未预设的词也能直接查，例如：土木、测绘、水利、储能、动医。
5. 后端新增 keyword-preset-policy.js 和 search-scorer.js，搜索主流程保持配置化，后续新增词优先改 policy，不改 matcher 主逻辑。
6. 页面版本统一到 V3.9.7.1。

## 不改动

- 不动 /fenxi。
- 不动 /fenxi/data。
- 不包含 functions/fenxi。
- 不包含 functions/_middleware.js。
- 不改公办底线显示边界。
- 不改 AI 诊断接口主逻辑。
