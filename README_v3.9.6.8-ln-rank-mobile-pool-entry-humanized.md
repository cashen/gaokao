# v3.9.6.8-ln-rank-mobile-pool-entry-humanized

本版只修搜索页自选池入口的人类动线，不改关键词搜索、专业池 API、公办底线、AI 诊断和 /fenxi。

## 变化

1. PC 端继续保留右侧固定“自选池 N”入口，点击直接进入完整自选池页。
2. 平板/手机端取消底部常驻自选池按钮，避免遮挡结果卡片和误触。
3. 搜索条件卡片右上角显示“自选池 N”入口。
4. 搜索结果区在已选数量大于 0 时显示粘性整理条：“已选 N 个专业｜去整理”。
5. 加入专业后显示 2.6 秒短提示：“已加入自选池 · 共 N 个｜去整理”。
6. 继续保持点击自选池入口直接跳转完整整理页，不做抽屉、不做半屏弹层。

## 验收

- 手机端底部不再常驻自选池按钮。
- 搜索卡右上角可以看到自选池入口。
- 加入专业后数量立即变化，并出现短提示。
- 自选池入口点击后进入 selection-pool.html，携带当前分数参数。
- 不包含 /fenxi、functions/fenxi、functions/_middleware.js。
