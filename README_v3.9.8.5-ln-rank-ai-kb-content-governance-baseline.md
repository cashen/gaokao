# v3.9.8.5 ln-rank AI KB content governance baseline

本版基于 v3.9.8.4，重点不是扩 UI，而是把 AI 诊断、报告和三处飞书输出依赖的真实知识内容收口到 functions/_lib/kb。

## 核心新增

- 年度口径 KB：辽宁 2025 物理类本科线 367、特控线 515、专科线 150；公办底线只在本科线到特控线之间显示。
- 辽宁志愿政策 KB：普通类本科批按“专业+学校”平行志愿理解，2025 口径最多 112 个。
- 本科专业目录口径 KB：2025 目录与 2026 目录摘要、交叉学科与新增专业提醒。
- 招生章程核验 KB：学费、校区、培养模式、中外/高收费/定向/试验班等必须核验项。
- 体检限制 KB：色弱/色盲相关专业复核提醒，仅在用户主动提供体检限制时使用。
- 医学/法学/师范路径 KB：规培、法考、教师资格等路径提醒。
- 双一流/学科评估/就业质量报告使用边界 KB。
- 专业热度数据 server KB：标注为 internalDerived / sourceLevel C，只作热度变化参考。
- copy policy KB：正式页面和飞书报告禁用工程词与承诺性词。

## 飞书输出硬规则

三处输出都要可用：普通家庭讨论报告、带解读报告、复制文字版报告。报告失败提示统一：报告暂时生成失败。可以先复制文字版报告，稍后再试。技术详情只折叠展示，不进入家长正文。

## 禁入目录

zip 不包含 /fenxi/、functions/fenxi/、functions/_middleware.js。
