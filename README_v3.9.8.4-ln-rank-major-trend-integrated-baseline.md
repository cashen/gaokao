# v3.9.8.4-ln-rank-major-trend-integrated-baseline-no-fenxi

本版本基于 v3.9.8.3，整合“辽宁物理类 2024/2025 同校同专业录取位次变化”数据，形成专业热度变化参考层。

## 本版定位

- 不改变 ln-rank 主搜索排序。
- 不做录取承诺。
- 只用于解释某个专业方向在近两年是否更拥挤。
- UI 与 ln-rank 主页面保持一致，不沿用外部 HTML 的独立棕金报告风格。

## 新增内容

- `ln-rank/data/major-trend-2025.json`：结构化热度数据。
- `ln-rank/major-trend-2025.html`：独立热度变化参考页。
- 搜索页：在搜索条件下方增加专业热度轻提示。
- 自选专业页：在方案解读中增加“专业热度变化参考”轻提示。
- 家庭讨论报告：增加最多 3 条专业热度变化参考。

## 口径

基于 2024/2025 辽宁物理类本科批同校同专业普通项目录取位次变化整理。按 2025 投档分切分为 590—624、550—589、500—549、450—499、367—449 五段。高费、合作、预科、专项、试验班、本博等特殊项目不进入主表。

## 分类审计

专业方向识别按“标准专业名/代码优先、完整专业名优先、专业类优先、组合词优先、关键词兜底”。重点避免：

- 机械设计制造及其自动化误归电气/自动化/能源。
- 园艺与园林混淆。
- 动物医学归入医学核心。
- 电力方向强命中石油、采矿、资源勘查。

## 不包含

- 不包含 `/fenxi/`。
- 不包含 `functions/fenxi/`。
- 不包含 `functions/_middleware.js`。
