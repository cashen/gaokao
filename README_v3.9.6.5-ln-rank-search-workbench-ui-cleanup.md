# v3.9.6.5-ln-rank-search-workbench-ui-cleanup

本版基于 v3.9.6.4，核心不改搜索逻辑，只修搜索页工作台 UI 与多终端布局。

## 主要变化

1. 搜索区从散落字段升级为稳定的“搜索条件”工作台。
2. 自选池入口移到搜索工作台右上角，不再漂浮挤压专业输入框。
3. `专业 / 项目 / 行业关键词` 输入框拥有独立说明，不再撑乱 PC 端布局。
4. 新增当前筛选摘要：标准范围、地域、学校、关键词、公办底线。
5. PC / 笔记本 / 平板 / 手机使用明确断点，不再依赖自然换行。
6. 搜索页与自选池页版本号同步到 v3965。

## 保持不变

- 不改 v3.9.6.4 的专业 / 项目 / 行业关键词搜索能力。
- 不改 `/api/major-bands` 数据逻辑。
- 不改公办底线显示规则：本科线 ≤ 分数 ≤ 特控线显示，超过特控线不显示。
- 600 分附近中外上探仍只在 AI/报告解释，不做前端按钮。
- 不包含 `/fenxi/`、`functions/fenxi/`、`functions/_middleware.js`。

## 验收重点

- 1440+ PC：三列搜索条件稳定，自选池在右上角。
- 1280/1366 笔记本：专业关键词可独占一行，不溢出。
- 平板：两列或单列自然排布。
- 手机：全部单列，自选池入口不遮挡输入框，查询按钮全宽。
