# v3.9.6.9-ln-rank-pool-entry-responsive-human-fix

本版只修搜索页自选池入口的人类化响应式规则，不改关键词搜索后端逻辑、不改公办底线规则、不改 /fenxi。

## 核心规则

- PC / Pad（宽度 >= 768px）：只显示右侧固定“自选池 N”入口，点击直接进入完整自选池页。
- 手机（宽度 < 768px）：不显示右侧固定入口，不显示搜索卡入口，不显示底部常驻入口；只在结果区顶部显示“已选 N 个专业｜去整理”。
- toast 只做加入成功反馈：`已加入自选池 · 共 N 个`，不再包含“去整理”链接。
- 加入成功后，手机端结果区整理条短暂高亮。

## 修复点

1. 避免 PC 搜索卡与右侧固定入口重复出现。
2. Pad 改用 PC 逻辑，右侧固定入口更容易在长列表中找到。
3. 手机端入口跟随结果列表，不压底部、不做抽屉、不要求用户回到搜索卡顶部。
4. toast 不承担导航，避免字小、时间短、点不到的问题。
5. 继续保持搜索页与自选池页版本统一到 v3969。

## 不包含

- `/fenxi/`
- `functions/fenxi/`
- `functions/_middleware.js`

## 关键验收

- `index.html` 引用 `app.v3969.js`。
- `selection-pool.html` 引用 `selection-pool.v3969.js`。
- 页面显示版本为 `V3.9.6.9`。
- 手机端不再出现底部常驻“自选池”按钮，也不显示 toast 内的“去整理”。
