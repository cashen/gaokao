# v3.9.6.1-ln-rank-bottomline-ui-cleanup

## 目标
修复 v3.9.6.0 中“办学性质底线”在主页面呈现为左侧孤立小卡片的问题。

## 核心变化
- 保持 v3.9.6.0 的底层逻辑不变：仅在特控线以下/边缘分段显示公办底线。
- 600 分左右仍不显示前端公办/中外上探按钮；中外上探继续由 AI 诊断和报告解释。
- UI 从孤立卡片改为与“查看范围”同层级的横向筛选条。
- 文案从“办学性质底线”收口为“公办底线”，减少技术感。
- PC 端不再出现左侧小卡片 + 右侧大空白的割裂布局。
- 移动端自动变为两列/单列按钮。

- `ln-rank/index.html`
- `ln-rank/js/app.v3961.js`
- `ln-rank/css/bottomline.v3961.css`

- 不包含 `functions/fenxi/`
- 不包含 `functions/_middleware.js`
- 不改后端鉴权链路

## 验收
- 未输入分数：不显示公办底线。
- 480/515：显示横向“公办底线”筛选条。
- 600：不显示该筛选条。
- 选项仍为：全部院校、公办优先、只看公办普通、公办含中外/高收费。
