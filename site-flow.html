API 服务面

浏览器看到的是页面；真正决定数据和降级边界的是这些接口及其内部 provider / engine。

接口服务内容主要调用页面关系
/api/major-bands分数对应的专业候选、分段、位次窗口/ln-rank/、/aiplus/确定性招生事实，受分页和资源预算约束。
/api/school-majors学校在辽宁的专业记录/ln-rank/学校模式，支持学校实体和聚焦参数。
/api/ai/major-history专业在各校的历史投档记录/ln-rank/、/aiplus/专业模式的核心事实来源。
/api/ai/turnAI 家庭顾问的一轮对话/aiplus/模型负责理解和组织，不替代分数、位次和学校事实 owner。
/api/tongxue-summary、/api/tongxue-school-portrait学校体验摘要与画像/tongxue/、/aiplus/学校实体不一致时必须 fail-closed。
/api/score-equivalence同位次历史分数对照/ln-rank/score-converter/只作历史参考，不生成未来录取结论。
/api/path-analysis、/api/feishu-*家庭方案路径分析与报告/ln-rank/selection-pool报告建立在已选记录上，不建立第二份招生事实。

当前审计风险与判断

这些不是“页面一定坏了”的结论，而是从代码关系中推导出的必须持续验证的点。

版本标识不一致

VERSION.txt 为 v3.9.90.0，而 canonical release 与多个页面 runtime 为 v3.9.90.3。根版本文件是历史标记还是仍有消费者，需要持续确认。

锚点不能只靠动画滚动

#schoolAllResultsPanel 和 #majorAllResultsPanel 是跨模块直达契约。Android、Alook 和弱网场景需要验证“参数、异步结果、定位”三者同时成立。

学校实体必须先统一

school + entity 共同决定同学你好请求的身份。名称可显示，不代表实体一定有效；错误实体不能扩散成整页失败。

独立入口不能被漏审

/fenxi/、历史页和专题页没有全部出现在主导航，但仍可由 URL 直接访问。它们需要明确保留、迁移或退役。

返回不是同一件事

模块根目录、返回上一个模块、恢复原查询和跳到结果锚点分别属于不同契约，不能用一个“返回首页”替代。

版本化资源要看 owner

文件名较旧不代表它是错误版本；应以 release center、active manifest、页面实际加载关系和测试证据判断。

使用说明：这是根目录下的静态审计页，不参与招生计算，也不改变现有模块导航。流程图节点点击会打开相应生产地址；手机上流程图可横向滑动。
