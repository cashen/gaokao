# V2.9.8.fix1｜兴趣闭环前端联动修正版说明

本版基于 V2.9.8，不改变主筛选算法和访问保护，重点修复兴趣闭环在前端的两处断点。

## 修复目标

1. 已选兴趣或自动带入方向的 `×` 可以即时取消，不再只能通过“清空兴趣”全部重置。
2. 详细候选列表默认排序也读取同一套兴趣闭环结果，形成：抽屉兴趣 → A/B/C → 详细候选 → 导出证据 的一致链条。

## 关键原则

- 兴趣仍然只做软加权，不做默认硬过滤。
- A「守底线」轻度参考兴趣，B「看专业」最重参考兴趣，C「争上限」适度参考兴趣。
- 详细候选只在默认画像排序下优先展示真实命中项；用户显式选择按位次、热度、放宽、贴近、升值排序时，尊重用户排序。
- 未直接命中孩子关注点的候选仍可保留，但展示为“综合备选”。
- 不覆盖根目录首页，仍保持 fenxi-only 更新包。

## 技术变更

- 新增 `filter-engine.v298fix1.js`：详细候选默认排序加入 `_interestSortScore`。
- 新增 `app.v298fix1.js`：补齐 `child-interest-auto-toggle` 和 `child-intent-remove` 事件入口。
- 新增 `child-interest-runtime.v298fix1.js`：补齐单项自动带入方向取消处理。
- 新增 `child-intent-translator.v298fix1.js`：提供单个孩子想法移除接口。
- 新增 `child-interest-ui.v298fix1.js` / `child-intent-ui.v298fix1.js`：保持即时点选、即时生效。
- `diagnostics.html` 增加兴趣单项删除和详细候选兴趣排序检查。

## 验收重点

- 点选“动物生命”后，A/B/C 和详细候选都能体现真实命中排序。
- 点自动带入方向右侧 `×` 可以取消该自动带入方向。
- “清空兴趣”仍可一次清空全部兴趣。
- A/B/C 切换不触发全量重算。
- 未命中的专业显示为综合备选，不冒充兴趣匹配。
