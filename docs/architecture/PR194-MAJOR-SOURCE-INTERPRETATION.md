# PR194：专业解读来源层

## 用户意图

把专业页面从难懂的固定文案，改成学生和家长能直接读懂的四个问题：

- 专业是什么
- 主要学什么
- 毕业后做什么
- 就业方向

## 数据边界

- 专业身份仍由 2026 本科专业目录（883 条）负责；源站不是第二专业目录。
- 源站 `eo.srgaoxiao.cn` 的专业详情通过 `/api/specialties/{slug}` 抓取，按专业代码优先对齐。
- 本次生成 816 条可核验本科源站解读；67 条源站没有对应条目，界面明确显示“暂无可核验的原站专业解读”，不编造内容。
- 源站的 1783 条混合了本科和高职，代码不在本科 883 条中的条目不会进入本科专业解读。
- “大学生怎么说”是独立的经验层。评价数量为 0 或内容不足时不拿评论补齐官方四字段。

## 展示顺序

推荐卡片先显示一句“先看懂这个专业”，展开后按“专业是什么 / 主要学什么 / 毕业后做什么 / 就业方向”展示源站字段，并保留原站链接和抓取日期。原有目录归属、读研方向和家庭复核仍在各自层，不混成就业承诺。

## 验证

运行：

```bash
node tools/verify-major-source-profile-v001.mjs
```

验证覆盖量、能源与动力工程（080501）四字段、来源链接、缺失源站资料的 fail-closed 行为，以及高职代码不会误入本科 resolver。
