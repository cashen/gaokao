# V2.9.5.5｜孩子专业兴趣与规则中心增强版

本版基于 V2.9.5.4.fix3｜Pages Function 服务端访问保护版继续开发，保留 `/fenxi` 遮罩入口与 Pages Functions 服务端校验结构。

## 核心变化

1. 新增第 3 步：孩子感兴趣的专业方向。
2. 新增 `child-interest-rules.v2955.js`：9 大专业方向规则集。
3. 新增 `rule-runtime.v2955.js`：统一把孩子兴趣转成场景提示、A/B/C 加权、专业匹配标签和高级筛选。
4. 孩子兴趣默认是软偏好，不直接排除非兴趣专业。
5. “只看孩子已选方向”为高级收窄项，默认关闭。
6. A/B/C 方案卡新增“专业匹配”解释线。
7. 场景卡会提示“与孩子兴趣较匹配”，但不自动切换场景。
8. 继续保留家长底线优先原则，孩子兴趣不覆盖预算、地域、高收费、民办等家庭底线。

## 9 大方向

- 计算机与信息
- 电气与能源
- 机械与制造
- 医学与健康
- 财经与管理
- 土木与建筑
- 师范与教育
- 化工与材料
- 其他方向

## 周期提醒

每个方向均带有培养周期或复核提示。例如医学强调学制、读研/规培和执业资格；电气能源强调电气正主、相近方向和泛相关方向的区分。

## 保护边界

- 孩子兴趣不是硬排除项。
- 家庭底线优先于孩子兴趣。
- 最终仍需以当年辽宁招生计划、高校招生章程、学费、代码和专业备注为准。

## 部署提醒

真实使用时只需要上传：

```text
fenxi/
functions/
```

如果根目录首页是其他页面，不要覆盖根目录 `index.html`。
