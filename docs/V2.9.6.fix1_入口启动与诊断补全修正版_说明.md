# V2.9.6.fix1｜入口启动与诊断补全修正版

## 修复范围

本版只修复 V2.9.6 正式页启动失败与诊断覆盖不足问题，不调整数据、筛选、A/B/C 业务口径。

## 修复点

1. 修复 `app.v296.js` 中 `requestRefreshV296 is not defined` 导致入口脚本中断的问题。
2. 新增 `requestRefreshV296()` 统一刷新包装函数，接入 `LN_REFRESH_SCHEDULER_V296`。
3. 新增 `window.__LN_AUTO_REFRESH_DIRECT__`，供刷新调度器执行真实刷新。
4. `diagnostics.html` 增加 `app` 入口脚本加载检查。
5. `diagnostics.html` 增加 `LN_APP` 挂载检查，避免“诊断全绿但正式页不可用”。
6. 主资产文件升级为 `v296fix1`，规避浏览器或 Cloudflare 缓存继续使用旧的 `v296` 文件。

## 部署说明


不要覆盖根目录 `index.html`。
