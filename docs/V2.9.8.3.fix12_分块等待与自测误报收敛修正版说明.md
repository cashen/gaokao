# V2.9.8.3.fix12｜分块等待与自测误报收敛修正版

本版基于 V2.9.8.3.fix11，仅做调试与数据就绪体验修复，不重写主业务链路。

## 修复重点

1. Debug 深度矩阵自测增加分块数据等待器：
   - 每次切换位次后，优先调用 `ensureDataForCurrentRank()`；
   - 轮询 `loadedRows / DATA.length`，等真实分块数据到位后再断言；
   - 报告新增 `waitData=xxms rows=xx`；
   - 等待超时时按 WARN 处理，避免把网络/分块未就绪误判为业务 FAIL。

2. Debug 自测保留自动访问能力：
   - debug 页自动使用 `ln2026` 在沙盒 iframe 中进入工具；
   - 不再要求先手动回主页面输入凭证。

3. 主页面增加数据未就绪保护：
   - 当位次已输入但 `DATA` 仍为空时，不直接渲染为空结果；
   - 候选区提示“正在加载位次附近数据”；
   - debug 增加 `dataWaiting` 细分，方便判断是等待数据还是业务筛选失败。

## 未改变内容

- 不改兴趣快速预筛主逻辑；
- 不改地域 hard 规则；
- 不改 A/B/C 主渲染逻辑；
- 不改根目录首页。
