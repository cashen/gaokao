# V2.9.5.4.fix3｜Pages Function 服务端访问保护版

本版基于 V2.9.5.4.fix1 继续修复，不回退到 V2.9.4.x 或 V2.9.5.0。

## 修复重点

1. 修正 A/B/C 方案盘中场景倾向只停留在文案层的问题。`planBias` 不再只是乘以固定常数，而是转成具体评分加减项。
2. 建立规则运行适配层：`scenarioRuntimeV2954Fix2`、`scoreBandFitV2954Fix2` 等，用于场景卡分段提示、排序和方案盘评分。
3. 场景卡只建议、不覆盖底线：预算、收费类型、区域、省份、城市、拒绝项、专业偏好等手动设置会被保留。
4. “预算较宽 / 中外合作可比较”会在用户未手动拒绝高收费时放开默认高收费拒绝项；若用户手动拒绝，则保留该底线并提示。
5. 场景分数段参与前置引导：当前分段匹配的场景优先展示，偏离场景保留但提示“作为对照”。
6. 电网能源路径拆分为电气正主、相近路径、泛相关需复核，降低“自动化/测控/电子信息直接等同电气正主”的误导。
7. 医学方向场景改为 `priority: medical`，目标路径面板与医学场景保持一致。

## 未改变

- 不改变 2024 / 2025 投档数据。
- 不改变一分一段数据。
- 不新增 2026 招生计划或学费模型。
- 不改变访问凭证本身。
- 不改变 CSV / PNG 导出口径。
