# V2.9.6｜控制区收纳与交互性能优化版

本版基于 V2.9.5.5，只更新 `/fenxi` 工具与 Pages Functions 结构，不改变根目录首页。

## 目标

- 主页面从“大表单”改成“紧凑控制台”。
- 孩子兴趣、场景选择从主页面大块平铺改为摘要卡 + 抽屉。
- A/B/C 从三列重卡改为分段控制 + 当前视角。
- 轻交互先响应，重计算通过刷新调度器合并执行。
- 规则、UI、调度、缓存拆成独立功能文件，避免继续堆大文件。

## 交互治理规则

| 交互 | 刷新等级 | 说明 |
|---|---|---|
| 位次/分数 | full | 重新加载对应分段并重算 |
| 家庭底线 | full / soft | 影响硬底线时重算，普通 chip 合并刷新 |
| 孩子兴趣 | soft | 先更新标签，再延迟刷新 A/B/C |
| 场景切换 | soft | 先更新摘要和抽屉，再合并刷新 |
| A/B/C 切换 | render-only | 只切换视角，不重新跑全库 |
| 抽屉开关 | ui-only | 不触发筛选 |

## 部署提醒

只需要上传：

```text
fenxi/
functions/
docs/
tools/
```

不要覆盖根目录 `index.html`，否则会影响 `gaokao.powers.org.cn/` 首页。

## 验收重点

- `/fenxi/diagnostics` 中 V2.9.6 模块全部通过。
- 孩子兴趣主页面只显示摘要，点击“编辑兴趣”打开抽屉。
- 删除兴趣标签点击区明显变大，点击后立即消失。
- 场景主页面只显示当前场景摘要，点击“切换场景”打开抽屉。
- A/B/C 切换时不重新跑全量筛选。
- 快速连续点击区域或兴趣卡，只触发合并后的刷新。
