# V2.9.8.3.fix6｜启动资源容错与主题令牌内联修正版

## 修复背景
线上 F12 报错显示：`theme-tokens.v297fix2.js` 被 Cloudflare 返回为 `text/html`，浏览器按严格 MIME 检查拒绝执行，导致启动链路中断，页面无法测试。

## 核心修复
- 将主题令牌 `LN_THEME_TOKENS_V297` 内联到 `fenxi/index.html` 启动脚本中。
- 从启动关键脚本队列中移除 `assets/theme-tokens.v297fix2.js`，避免该资源缺失或被站点 fallback 成 HTML 时阻断整页启动。
- 版本戳升级为 `2983fix6-20260511`，便于绕过浏览器/Cloudflare 缓存。
- 保留 `fenxi/assets/theme-tokens.v297fix2.js` 文件，作为历史兼容资源，但不再作为启动必需资源。

## 包边界
保持 fenxi-only update，只包含：`fenxi/ functions/ docs/ tools/`，不覆盖根目录首页。
