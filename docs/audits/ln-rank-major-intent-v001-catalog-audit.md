# ln-rank 全专业意图目录审计 v001

## 审计结论

当前 2026 本科专业目录实际包含 883 条专业记录、13 个学科门类和 92 个本科专业类。`交叉学科门类` 是学科门类，不计入普通本科专业类，避免把目录层级误报成 93 个专业类。

本审计使用目录生成文件作为唯一覆盖基线，逐条验证：

- 883 个专业代码可唯一解析到自身；
- 883 个正式专业名称可唯一解析到自身；
- T、K、TK 和新代码专业不因标记丢失；
- 专业类、学科门类、一级学科和口语方向不会静默替换成一个本科专业；
- 方向集合由每条目录记录的 `directionLabel` 动态生成，新增目录专业可自动进入所属方向，不依赖手写 883 条别名。

## 人类输入验收

| 输入 | 解析层级 | 预期行为 |
|---|---|---|
| `机械` | 方向 | 展示机械/装备/车辆核心专业集合，不能只变成机械工程 |
| `计算机` | 方向 | 包含计算机、软件、网络安全、信息安全等核心集合 |
| `网络安全` | 方向 | 优先给网络工程、信息安全、网络空间安全、密码/保密等候选 |
| `机` | 过宽领域 | 先给机械、计算机、电气等方向选择，拒绝混杂查询 |
| `工科` | 过宽领域 | 先给工科方向选择，不直接返回数百条混合结果 |
| `医学` | 学科/过宽理解 | 先提示继续选临床、口腔、护理、药学等方向 |
| `机械类` | 专业类 | 展示专业类边界，不当作单一专业 |
| `一级学科机械工程` | 学科理解 | 明确本科专业方向与学科口径边界 |
| `交叉学科门类` | 学科门类 | 保留 2026 交叉学科门类身份，不虚构专业类 |
