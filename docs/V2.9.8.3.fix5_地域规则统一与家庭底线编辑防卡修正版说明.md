# V2.9.8.3.fix5｜地域规则统一与家庭底线编辑防卡修正版

## 发版边界

本包仍为 fenxi-only update，仅包含：

- `fenxi/`
- `functions/`
- `docs/`
- `tools/`

不覆盖根目录首页。

## 本版修复重点

### 1. 地域规则统一

新增：

- `fenxi/assets/region-filter-rules.v2983fix5.js`

将家庭底线中的地域规则统一为一套判断：

- `hard`：严格只看所选省份，不符合的学校在 `basePool` 阶段直接排除。
- `soft`：所选省份优先，非目标省份保留但做标记，后续仅作降权/提醒。
- `none`：不限制地域。

### 2. 地域 hard 前置到 basePool

此前地域 strict/hard 主要在 `profileScore()` 中以“画像排除”形式处理，导致高级筛选可能和家庭底线路径不一致。

本版改为：

```text
loadedRows
→ 资格入口保护
→ 地域 hard
→ 预算/关键词/层级/位次
→ 画像/兴趣/A-B-C
```

这样高级筛选“匹配/稳妥/可冲”等只能在家庭底线后的候选池中继续筛。

### 3. 家庭底线省份编辑防卡

省份和快捷区域 chip 点击改为 `region-chip-change`，默认 1300ms 合并刷新，避免用户取消黑龙江后还没来得及取消吉林时就触发重算。

### 4. Debug 增强

新增 `regionFilterDebug`，用于查看：

- 当前地域模式
- 目标省份
- 输入行数
- 保留数
- 排除数
- soft 模式下非目标省份保留数量
- hard 模式下异常保留样本
- 排除样本

## 验证重点

1. 家庭底线选择“严格：只看所选区域 + 辽宁”后，高级筛选不应出现非辽宁学校。
2. 选择“软筛：所选区域优先 + 辽宁”时，外省可出现，但应为软保留口径。
3. 连续取消/选择省份 chip 时，不应每点一次立即卡顿。
4. debug 深度报告中应出现 `regionFilterDebug`。
