# V2.9.8.2｜统一决策上下文、兴趣抽屉稳定与旧规则收口版

本版不是继续堆功能，而是把 V2.9.8.1.fix2 中遗留的“新入口 + 旧 DOM 暗规则”问题做一次收口。

## 核心修正

1. **统一决策上下文**
   - 新增 `decision-context-model.v2982.js`。
   - 家庭底线、学生画像、孩子兴趣、兴趣转译、场景、资格入口和排序方式先汇总为同一个 `currentDecisionContext`。
   - 后续规则集不再各自读一套旧状态。

2. **旧规则读取源收口**
   - 新增 `legacy-preference-adapter.v2982.js`。
   - 旧 `medicine / teacher / chem / gridPower / gradPlan / timePressure / mathTolerance` 等读取，统一桥接到新“孩子画像与兴趣 + 家庭底线 + 场景”口径。
   - 普通家长视图下，不再允许隐藏旧控件里的 `avoid/prefer` 暗中影响结果。

3. **高报师诊断统一到新逻辑线**
   - 新增 `advisor-diagnosis-engine.v2982.js`。
   - 高报师诊断不再作为另一套高级规则系统，而是对同一套候选筛选结果进行解释。
   - 输出候选变少原因、压缩点、区域/预算/资格入口压力、A/B/C 建议和复核重点。

4. **兴趣抽屉与画像抽屉稳定性修复**
   - 新增 `interaction-stability.v2982.js`。
   - `child-interest-start` 打开成功后明确返回有效处理。
   - “编辑兴趣 / 编辑画像”增加直接兜底绑定，不只依赖旧全局代理。
   - 增加抽屉类型标记，避免画像抽屉被误刷新成兴趣抽屉。

5. **详细卡展开修复**
   - 详细卡“展开证据 / 展开专业解释 / 展开取舍”不再依赖 `CSS.escape(id)`。
   - 改为在当前卡片内直接查找展开面板，降低浏览器兼容风险。

6. **主流程收口**
   - 家庭底线下一步跳到 `孩子画像与兴趣`，不再直接跳场景。
   - 主页面默认隐藏旧 `profileAsk` 与 `mentorRules` 大块。
   - 主页面默认隐藏大号“可冲 / 匹配 / 稳妥 / 保底”四卡，保留紧凑位次带宽说明。

## 保留原则

- 本科目录匹配、兴趣闭环、资格入口保护、访问控制和 diagnostics 不删除。
- 旧字段能力不是直接删除，而是通过统一适配层迁移到新上下文。
- 旧 DOM 仅作为历史兼容兜底，不再作为普通家长模式的主判断来源。

## 输出包

仅包含：

- `fenxi/`
- `functions/`
- `docs/`
- `tools/`

不覆盖根目录首页。
