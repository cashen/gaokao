# V2.9.7｜路径色彩系统与家长阅读体验优化版

本版基于 V2.9.6.fix6 继续迭代，只调整视觉系统与证据卡阅读体验，不改变筛选规则、资格入口保护、Pages Function 登录逻辑。

## 核心原则

- 不是彩虹装饰，而是路径色彩：位次/数据、家庭底线、孩子兴趣、场景路径、A/B/C 方案、复核提醒各有功能色。
- 大面积使用中性底色，小面积使用路径色帮助家长快速分清信息层级。
- A/B/C 方案颜色语义固定：A 守底线为绿色，B 看专业为蓝紫色，C 争上限为金橙色。
- 证据卡继续强化 2025/2024 分数位次、两年变化、与当前位次距离。

## 不变范围

- 不改变数据。
- 不改变 A/B/C 业务含义。
- 不改变资格入口默认隐藏逻辑。
- 不改变 Pages Function 访问保护。
- 不覆盖根目录首页。
