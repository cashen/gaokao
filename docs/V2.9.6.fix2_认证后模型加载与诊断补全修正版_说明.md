# V2.9.6.fix2｜认证后模型加载与诊断补全修正版

## 修复背景

V2.9.6.fix1 在 `/fenxi/data/*` 已经由 Cloudflare Pages Function 保护的前提下，仍然让 `major-name-model.v2946.js` 与 `confusable-major-model.v29462.js` 在页面脚本加载阶段自动预加载 JSON。

未输入访问凭证前，这些 JSON 会被 middleware 返回 401，控制台出现：

```text
major-name model preload failed: 401
confusable-major model preload failed: 401
```

这不是数据缺失，而是加载时机不对。

## 本版处理

1. 取消专业名模型与易混专业模型的未授权自动预加载。
2. 保留 `loadMajorNameModelV2944` 与 `loadConfusableMajorModelV2946` 全局函数。
3. 登录通过并进入 `boot()` 后，再加载这些受保护 JSON。
4. 主资产升级为 `v296fix2`，避免继续加载旧缓存。
5. diagnostics 继续检查模型加载函数是否存在，但不在未授权状态主动拉取受保护 JSON。

## 不改动内容

- 不改 Pages Function 密码逻辑。
- 不改根目录首页。
- 不改 A/B/C 业务含义。
- 不改数据文件内容。
- 不把孩子兴趣改成硬过滤。

## 部署检查

部署后先打开：

```text
https://gaokao.powers.org.cn/fenxi/diagnostics.html
```

然后打开：

```text
https://gaokao.powers.org.cn/fenxi
```

未登录前不应再出现大量 `major_name_model` / `confusable_major_model` 的 401 preload 报错。
登录后，数据和模型再进入加载流程。
