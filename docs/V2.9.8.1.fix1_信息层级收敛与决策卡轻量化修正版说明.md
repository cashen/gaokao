# V2.9.8.1.fix1｜信息层级收敛与决策卡轻量化修正版

## 一、版本定位

V2.9.8.1 已经完成“学生画像、兴趣闭环、A/B/C 证据卡、详细候选标签化”的主体增强。

本次 fix1 不继续堆功能，重点做页面收口：

- 辅助信息降级，不抢 A/B/C 主线；
- 诊断信息默认收起；
- 学生画像与孩子兴趣合并成一个摘要卡；
- 删除独立“高级规则”主页面模块，改成“当前口径”；
- 详细候选卡默认轻量化；
- 提醒去重，每张候选默认只保留一个主判断；
- 清理确认无入口的旧展示逻辑，但保留底层规则与兼容能力。

## 二、用户侧变化

### 1. 资格入口提醒压缩

原来两段较长提醒改为一行：

```text
资格入口：普通考生口径｜高校专项/预科/民族班/定向等 N 条已隐藏｜管理资格入口
```

点击说明后再展开资格入口解释。

### 2. 位次带宽压缩

原来的“可冲 / 匹配 / 稳妥 / 保底”四张大卡默认收起，改为一行：

```text
位次带宽：可冲 xxx｜匹配 xxx｜稳妥 xxx｜保底 xxx｜查看解释
```

### 3. 高报师诊断默认折叠

诊断保留，但降级为摘要：

```text
高报师诊断：可观察 xxx｜可冲 xx｜匹配 xx｜稳妥 xx｜保底 xx｜区域排除 xx｜预算排除 xx
```

详细漏斗和建议放在展开区。

### 4. 高级规则不再作为独立主页面模块

不再展示：

```text
高级规则：资格保护｜预算保护｜兴趣软排序｜默认排序
```

改为：

```text
当前口径：普通考生｜公办/普通学费优先｜兴趣只做软排序｜默认综合排序
```

各口径可点击解释。

### 5. 学生画像与兴趣整合

原来的学生画像和兴趣分散展示，改为一个摘要卡：

```text
孩子画像与兴趣
画像：女｜偏表达｜本科就业优先｜只知道热门词
兴趣：动物生命｜医药健康
系统处理：只调整提醒顺序，不按性别排除专业；兴趣只做软排序，不硬排除其他候选。
```

### 6. 详细候选卡轻量化

默认只显示：

```text
稳｜正主匹配｜2025收紧｜需复核：代码｜+2

沈阳农业大学｜动物医学
2025：566分｜28420位｜相对有一定安全垫

主判断：方向贴近孩子关注点；优先复核专业代码和培养方案。

[展开证据] [展开专业解释] [展开取舍] [加入候选]
```

更多证据和解释点击后查看。

## 四、代码清理口径

本版执行谨慎清理：

- 隐藏独立高级规则主页面模块；
- 隐藏旧版大号位次带宽卡；
- 隐藏旧版默认大数字诊断区；
- 隐藏详细候选卡默认长说明；
- 保留本科目录匹配、兴趣闭环、资格入口保护、访问控制、导出、诊断与旧状态兼容逻辑。

原则：

```text
能确认再删；不能确认就降级、折叠或保留兼容入口。
```
