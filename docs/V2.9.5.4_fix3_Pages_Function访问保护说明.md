# V2.9.5.4.fix3｜Pages Function 服务端访问保护版

## 目标

在不改变现有 UI 遮罩入口的前提下，把访问凭证校验从前端移到 Cloudflare Pages Functions。

## 运行逻辑

```text
用户访问 /fenxi
↓
看到原有页面和遮罩入口
↓
输入访问凭证
↓
前端 POST /fenxi/api/login
↓
Pages Function 读取 Cloudflare Pages 变量 LN_ACCESS_PASSWORD
↓
正确后写入 HttpOnly Cookie
↓
前端解除遮罩并加载数据
```

## 保护范围

服务端 middleware 保护：

```text
/fenxi/data/*
/data/*
```

说明：为了保持现有 UI 不变，`/fenxi/index.html` 与 `/fenxi/assets/*` 仍允许加载；真正的数据 JSON 由服务端 Cookie 保护。

## Cloudflare Pages 变量

建议添加：

```text
LN_ACCESS_PASSWORD=你的访问凭证
LN_SESSION_SECRET=一段随机长字符串，建议 32 位以上
LN_SESSION_DAYS=30
```

## 注意

- 不要把真实访问凭证写入 GitHub 文件。
- 不要把 `.env`、`.dev.vars` 之类本地密钥文件提交到 GitHub。
- 如果需要连 JS 源码也完全隐藏，应使用 Cloudflare Access 或专门的服务端登录壳；但那样无法做到现有 UI 完全不变。
