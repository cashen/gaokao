# Human Copy Contract v001

## Purpose

统一用户可见表达，让产品更像高考老师与家长交流，而不是工具输出。

## Scope

覆盖：

- loading
- empty
- error
- button
- tooltip
- result explanation

## Rules

禁止：

- AI认为
- 智能推荐
- 精准预测
- 成功率保证
- 最佳选择
- 闭眼选择

## Expression order

1. 先说明用户当前问题。
2. 再解释依据。
3. 再展示数据。
4. 最后提示需要关注的因素。

## Ownership

所有用户可见文案逐步迁移到统一规则。

业务模块不得创建新的营销化表达规则。
