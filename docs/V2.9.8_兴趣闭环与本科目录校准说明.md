# V2.9.8｜兴趣闭环与本科目录校准版

本版解决“孩子说的是兴趣，不是专业名”的闭环问题。

## 核心原则

- 兴趣不是专业结论，只是激活规则。
- 规则绑定本科目录门类、专业类、专业代码和标准专业名。
- A/B/C 与导出只使用当前真实候选，不生成不存在的专业。
- 匹配分为：正主匹配、相近方向、需复核方向、综合备选。
- 关键词命中只能作为弱依据，不能直接进入正主匹配。
- 性别只影响兴趣入口展示顺序，不参与专业判断。
- 兴趣只做软加权，不默认硬过滤。

## 新增模块

- `catalog-interest-binding.v298.js`：兴趣方向与本科目录代码绑定。
- `candidate-catalog-normalizer.v298.js`：从真实候选记录提取目录字段。
- `catalog-match-engine.v298.js`：按专业代码、专业类代码、标准名、招生名关键词分级匹配。
- `interest-hit-summary.v298.js`：统计当前真实候选中正主、相近、需复核命中数量。
- `child-interest-runtime.v298.js`：统一输出兴趣软加权。
- `child-interest-ui.v298.js`：主页面摘要、抽屉点选即生效、真实候选命中统计。
- `path-explain-engine.v298.js`：候选卡和导出使用目录级匹配依据。

## 展示逻辑

孩子选择“动物生命”时，页面不再说“自动带入动物医学、动物药学”等具体专业，而是显示：

- 已激活方向：动物医学与生命科学
- 当前真实候选命中：正主 X｜相近 Y｜需复核 Z
- 系统不会生成不存在的专业，只会对当前真实候选做本科目录匹配。

候选卡显示示例：

- 孩子关注：动物生命｜相近方向
- 依据：本科专业类代码 0830 生物工程类

导出 CSV 增加：孩子关注点、激活方向、兴趣匹配等级、匹配依据、匹配专业代码、匹配专业名、匹配专业类代码、匹配专业类、兴趣复核说明。
