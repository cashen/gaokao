# V2.9.7｜路径色彩系统与家长阅读体验优化版

本版基于 V2.9.6.fix4，聚焦“高校专项资格”和“资格型入口保护”重复并列的问题。

## 本版目标

- 不再在家庭底线主页面单独展示“高校专项资格”下拉框。
- 高校专项、辽宁省高校专项、少数民族预科/民族班、边防军人子女预科、医学定向、高水平运动队等统一进入“资格型入口保护”。
- 家庭底线页面只保留一个资格入口摘要卡，点击“管理资格入口”进入抽屉统一管理。
- 旧的 `specialPlanStatus` 保留为隐藏兼容字段，不作为主界面入口，也不覆盖资格入口抽屉状态。

## 主要变化

1. **主页面整合**
   - 移除可见的“高校专项资格”下拉框。
   - 保留一张“资格型入口保护”状态卡。
   - 卡片显示“默认隐藏 x 类资格入口”或“已纳入 x 类资格入口”。

2. **统一资格入口状态**
   - 高校专项不再作为独立家庭底线项。
   - `LN_QUALIFICATION_GATE_V296.specialPlanStatus()` 对旧模块提供兼容。
   - filter / plan 的旧高校专项判断通过资格入口状态读取。

3. **版式优化**
   - 资格入口卡片改为更完整的状态卡。
   - 抽屉中每个入口显示“默认隐藏 / 符合条件可纳入 / 不考虑”。

## 不做的事

- 不判断用户是否真的具备专项或预科资格。
- 不预测预科降分。
- 不将提前批或特殊入口混入普通本科批主逻辑。
- 不改根目录首页。

## 部署说明

仍然只覆盖：

```text
fenxi/
functions/
docs/
tools/
```

不要覆盖根目录 `index.html`。
