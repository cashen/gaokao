# V2.9.7.6｜兴趣联动、路径场景与 A/B/C 闭环修正版

本版基于 V2.9.7.5 继续迭代，重点修复“孩子想法只是静态解释、没有真正联动下方专业方向和 A/B/C 候选”的问题。

## 本版目标

把原来的静态说明升级为软规则闭环：

```text
性别画像 → 兴趣入口展示顺序 → 孩子想法 → 自动映射专业方向 → 正主/相近/需复核匹配 → A/B/C 软加权 → 候选卡显示匹配理由
```

## 关键边界

- 性别不参与硬过滤，只影响兴趣入口展示顺序和提醒重点。
- 孩子兴趣默认只做软加权，不排除其他专业。
- 家庭底线、资格型入口保护仍是硬边界。
- A/B/C 仍是家庭决策视角：A 守底线、B 看专业、C 争上限。
- 不使用“适合女生、女生慎报、高薪、轻松、稳定专业”等表达。


## 专业方向卡扩展

新增/重构为 11 类：医药健康、药学与制药、动物医学与生命科学、师范与教育、人文法政、计算机与信息、电气与能源、电子信息与通信、机械制造与仪器、财经与管理、化工材料食品环境。

## 权重规则

基础规则：

| 匹配等级 | A 守底线 | B 看专业 | C 争上限 |
|---|---:|---:|---:|
| 正主匹配 | +10 | +45 | +12 |
| 相近方向 | +5 | +22 | +6 |
| 需复核 | +1 | +8 | 0 |
| 综合备选 | 0 | 0 | 0 |

多兴趣合并不直接累加，采用“最高权重 + 第二权重 35% + 第三权重 20%”，并设置上限：A +18、B +55、C +26。

## 典型效果

选择“动物生命”后，系统自动带入“动物医学与生命科学”：

- 动物医学：正主匹配，B 看专业中获得较高软加权。
- 生物工程：相近方向，获得中等软加权。
- 环境工程：需复核方向，只轻微加权并提示复核。
- 电气工程及其自动化：综合备选，不显示为孩子兴趣匹配。
