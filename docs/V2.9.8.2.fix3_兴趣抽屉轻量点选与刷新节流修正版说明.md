# V2.9.8.2.fix3｜兴趣抽屉轻量点选与刷新节流修正版

本版是针对 V2.9.8.2.fix2 的紧急交互修复版。

## 修复目标

解决“孩子兴趣抽屉可以打开，但点任意兴趣卡后页面卡死、关闭也不好使”的问题。

## 根因

兴趣抽屉内点选兴趣后，旧逻辑会立即执行：

1. 重绘整个兴趣抽屉；
2. 重新计算每张兴趣卡的真实候选命中；
3. 立即触发主页面 A/B/C 和详细候选刷新；
4. 抽屉内搜索框还会重新 focus。

这些同步动作叠加后，容易阻塞主线程，表现为抽屉卡死、关闭按钮无响应、后续流程无法测试。

## 本版修复

1. 兴趣抽屉内点选兴趣时，只更新卡片选中状态、已选标签和抽屉顶部提示。
2. 不再每点一次兴趣卡就重绘整个抽屉。
3. 不再在抽屉卡片内实时全量计算每个兴趣方向的候选命中数。
4. 主页面 A/B/C 和详细候选刷新延后到关闭抽屉后统一执行。
5. 子想法卡片点选同样走轻量刷新，不再触发抽屉整页重绘。
6. 抽屉首次打开时才 focus 搜索框，点选兴趣时不再反复抢焦点。
7. 详细候选展开逻辑进一步去除旧版 `CSS.escape` 依赖。
8. 继续保留 V2.9.8.2.fix2 的缓存版本戳、滚动锁守卫、旧模块隐藏和统一决策上下文。

## 验证重点

部署后优先验证：

1. 输入成绩/位次后页面仍可滚动；
2. 点击“编辑兴趣”能打开抽屉；
3. 在兴趣抽屉里连续点选 2—3 个兴趣不卡死；
4. 点选后关闭抽屉，A/B/C 和详细候选会统一刷新；
5. 关闭按钮始终可用；
6. 详细卡“展开证据 / 专业解释 / 取舍”仍可打开。
