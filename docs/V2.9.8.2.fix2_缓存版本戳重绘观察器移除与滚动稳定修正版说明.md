# V2.9.8.2.fix2｜缓存版本戳、重绘观察器移除与滚动稳定修正版

本版为 V2.9.8.2.fix1 的运行层修复。

## 修复重点

1. 将前端资源版本戳提升为 `2982fix2-20260511`，避免浏览器或 Cloudflare 继续命中旧 `app.v2982.js`。
2. 直接移除 `app.v2981fix2.js` 中的全页面 `MutationObserver`，避免旧 overlay 继续触发 `renderAllLight → DOM变化 → renderAllLight` 循环。
3. body 明确增加 `v2982fix2` 标记，便于部署后现场确认。
4. 新增 `scroll-lock-guard.v2982fix2.js`，自动释放异常残留的 `drawer-open-v296`、抽屉遮罩和滚动锁。
5. 继续保留 V2.9.8.2 的统一决策上下文、旧规则收口、孩子画像与兴趣前置、家长必读和详细卡稳定逻辑。

## 部署后确认

浏览器控制台执行：

```js
document.body.className
```

应包含：

```text
v2982fix2
```

并且默认不应包含：

```text

```
