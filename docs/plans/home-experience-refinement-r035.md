# 首页体验收口 r035

## 基线

## 本轮纠偏

r034 原方案在 Hero 主按钮下额外注入 `专业初选 → 模拟志愿` 路径。这会与首页主线卡片中的同一条路径重复，增加一层视觉解释，和“第二部分模块直接承载入口”的方向不一致。

r035 将首页收敛为：

1. Hero 只负责说明“现在做什么”和提供唯一主按钮。
2. 模拟志愿只在首页 `先从这里开始` 主线卡片中作为第二个入口出现，不再在 Hero 额外复制一条路径。
3. 倒计时突出“天”，时/分/秒作为辅助信息。
4. 已有分数、已有专业选择的返回状态继续使用自然的“继续整理”语言，不再出现“家庭方案”“检查家庭方案”等系统化词汇。
5. 保留 `了解 / 证据 / 产业` 为次级入口，并维持现有折叠、触控、滚动位置和路由行为。
6. 首页浏览器标题收敛为 `辽宁高考｜2027专业初选与模拟志愿`。

## 非目标
