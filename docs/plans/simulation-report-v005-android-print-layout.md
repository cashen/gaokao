# 模拟志愿 Android 打印版 v005

## 问题
Android 打印 fallback 使用 9 列纸面表格的紧凑布局直接作为手机屏幕预览，导致列宽被压缩、文字纵向断裂、输入区域和核对信息难以阅读。

## 修复边界
- 只调整 Android `?print=1` 屏幕预览的移动呈现。
- 手机屏幕改为逐条志愿卡片：志愿号、学校、专业、核对/重点提醒、历史数据分栏展示。
- 不改变现有 A4 `@media print` 纸面布局。
- 不改变模拟志愿数据结构、历史数据口径和核对字段语义。
- 保留 Android popup 被阻止时的当前窗口 fallback。

## 验收
- Android Pixel 5 模拟：打印按钮进入同源打印版。
- 手机宽度下不再显示被压缩的 9 列表格。
- 志愿号、学校、专业、核对区、历史列仍可见。
- `window.print()` 不作为 Android 入口依赖。
- 原有 v003 compact paper card 回归测试继续通过。
