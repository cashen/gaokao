# 首页与倒计时重构 v001

## 目标

把根首页从“链接目录”调整为面向辽宁高考家庭的决策起点：倒计时是唯一视觉主角，`开始专业初选` 是唯一主要动作，现有功能按主线、了解、证据、产业分组渐进呈现。

## 必须保留

- 保留首页现有链接、路由、`data-*` 标记、`localStorage` 状态和家庭方案动态状态。
- 倒计时继续以北京时间 2027-06-07 09:00 为目标，每秒更新，并保留四个稳定时间单元和当前北京时间。
- 保留“专业升学地图”“历史位置对照”“全国上市公司产业落地图”“家庭方案与逐项复核”“辽宁2026专业报考难度变化”“辽宁2026招生结构变化”“同学你好”等入口。
- 保留当前数据边界：历史投档记录只帮助缩小范围，不作为 2027 录取结论；不新增无依据的个性化建议。

## 交互与视觉方案

- 首屏：简短产品定位、倒计时主卡、唯一主按钮和当前动态家庭状态。
- 工具入口：按“主线 / 了解 / 证据 / 产业”分组；主线默认展开，其余按需展开，避免平级卡片堆叠。
- PC：宽屏双栏，倒计时和主任务在同一首屏层级；辅助分组可收回。
- Pad：竖屏单列决策路径，不依赖横向卡片压缩。
- Android：360–479px 文档流布局，无横向溢出、自动滚动、固定底部大按钮和突然高度变化；触控目标不小于 44px；支持 `prefers-reduced-motion`。
- 倒计时增强只使用数字层级、节奏线和轻量背景装饰，不重新加入“按天安排节奏”等堆叠文案。

## 非目标

- 不重写 ln-rank、tongxue、aiplus 的业务逻辑。
- 不新增第二套共享 UI，不迁移现有路由，不采集阳光高考招生计划。
- 不把“今日建议”变成 AI 或无来源的录取建议。

## 版本与发布

- 全站公共 release 保持 `v3.9.90.2 / v3990_2` 一致。
- 首页运行时版本升级为 `family-home-runtime-v3990_2-r031`。
- 首页资源缓存修订为 `r031-home-redesign`，并同步 current release、runtime cache、site contract、执行注册、变更日志和进度断点。

## 验收

1. 静态合同确认所有既有入口各保留一个、路由不变、倒计时四单元和唯一 module bootstrap。
2. 本地运行首页 release、资源一致性、站点 generation、score-equivalence 相关测试。
3. Playwright 覆盖 Android 360/390、iPad 768、桌面 1280：无横向溢出、倒计时推进、动态家庭状态、分组入口和专业路径跳转。
4. Preview 使用 PR 精确 SHA 验证；再核验 Pages、正式站、资源版本和首页关键交互后才合并。
