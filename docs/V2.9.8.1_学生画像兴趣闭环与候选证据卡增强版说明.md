# V2.9.8.1｜学生画像、兴趣闭环与候选证据卡增强版

本版基于 `V2.9.8.fix1｜兴趣闭环前端联动修正版` 继续迭代，仍为 `fenxi-only update`，只更新：

- `fenxi/`
- `functions/`
- `docs/`
- `tools/`

不覆盖站点根目录首页。

## 一、本版目标

把原来的“兴趣能联动真实候选”继续推进为：

`学生画像 → 兴趣卡排序与提示 → 本科目录规则 → 当前真实候选 → A/B/C 证据卡 → 详细候选标签卡 → 导出保留依据`

本版重点不是增加更多长文案，而是把候选卡改成更适合家长阅读的“决策卡”。

## 二、产品改动

### 1. 学生画像接入兴趣卡

新增 `profile-interest-bridge-rules.v2981.js`。

学生画像会影响兴趣卡的展示顺序和提示语，例如：

- 偏理工：计算机、电气、电子、机械等方向靠前。
- 偏表达：法学表达、师范教育、人文法政等方向靠前。
- 本科就业优先：医药、生物、材料等方向增加本科出口复核提示。
- 只知道热门词：强化易混专业和本科目录代码提醒。

边界不变：性别和画像不用于专业排除，不生成“女生适合 / 男生适合”的结论。

### 2. A/B/C 升级为证据卡

A/B/C 仍保持原定位：

- A：守底线
- B：看专业
- C：争上限

但每张 A1-A4、B1-B4、C1-C4 增加：

- 录取安全标签：保 / 稳 / 小冲 / 冲 / 需谨慎
- 2025/2024 投档分数位次
- 位次变化：收紧 / 放宽 / 稳定 / 不可比
- 提醒标签条
- 换来的价值
- 需要接受
- 填报前复核

观点池位置调整为：

- A/B/C 组标题下：本组观点池
- 每张小卡内：单卡取舍

避免把观点池误挂到 A1、B1、C1 后面。

### 3. 详细候选卡标签化

底部详细候选卡新增“提醒标签条”：

`稳｜正主匹配｜2025收紧｜公办｜需复核：代码｜+2`

默认只展示短标签和主判断。点击某个标签后，卡片下方只展开该标签对应解释。再次点击收起；点击另一个标签替换当前解释。

这样减少一张卡默认展示的长文本，保留复核入口。

### 4. 导出增强

CSV 导出新增字段：

- 录取安全标签
- 投档证据2025
- 投档证据2024
- 位次变化说明
- 学生画像摘要
- 提醒标签
- 换来的价值
- 需要接受
- 填报前复核

导出复用候选决策对象，不另起一套判断口径。

### 5. 访问保护补强

`functions/_middleware.js` 已将保护范围从 `/fenxi/data/*` 扩展到同时保护 `/data/*`。

如果仓库根目录仍存在旧数据目录，也会被 Pages Function 访问控制覆盖。

## 三、新增规则集文件

新增独立规则集，避免继续放大单一大文件：

- `student-profile-rules.v2981.js`
- `student-profile-ui.v2981.js`

- `admission-safety-rules.v2981.js`
- `admission-evidence-rules.v2981.js`
- `candidate-decision-tags.v2981.js`
- `candidate-tradeoff-rules.v2981.js`
- `abc-decision-card-model.v2981.js`
- `detail-candidate-card-model.v2981.js`
- `candidate-tag-ui.v2981.js`

核心原则：规则集负责判断，模型层负责组装，UI 层负责展示，导出层复用结果。

## 四、验证重点

建议部署后优先测试：

1. 学生画像选择后，兴趣卡顺序和提示是否变化。
2. 选择兴趣后，A/B/C 与详细候选是否仍按真实候选匹配。
3. A/B/C 每张小卡是否显示冲稳保和 2025/2024 投档证据。
4. 观点池是否出现在 A/B/C 组标题下，而不是挂在 A1/B1/C1 后面。
5. 详细候选卡标签能否点击展开解释，且一张卡只展开一个解释。
6. 2024 缺记录或不可比时，是否不强行显示收紧/放宽。
7. CSV 导出是否包含新增决策字段。
8. 未登录状态下 `/fenxi/data/*` 和 `/data/*` 是否均受保护。

## 五、说明

本版继续坚持：

- 兴趣不是推荐结果，只是检索和解释真实候选的入口。
- 学生画像只调整提醒顺序和复核重点，不排除专业。
- 冲稳保只是初筛参考，不承诺录取结果。
- 2025/2024 数据不可比时，不强行下结论。
- 文案保持温和，不使用“避坑、闭眼选、稳录”等刺激性表达。
