# V2.9.8.2.fix1｜交互冻结与重绘循环修正版说明

本版是在 V2.9.8.2 基础上的紧急交互稳定修正版。

## 修复目标

解决输入成绩/位次后页面反复轻量重绘，导致菜单、抽屉、展开按钮无法正常点击的问题。

## 主要修复

1. 移除 V2.9.8.2 中对整个 `#app` 的 `MutationObserver` 监听，避免 `renderAll → DOM变化 → renderAll` 的自触发循环。
2. `app.v2982.js` 增加重入锁，统一上下文、紧凑提醒、孩子画像与兴趣摘要只在明确事件后刷新。
3. `profile-interest-summary.v2981fix2.js` 增加内容一致性判断，摘要内容不变时不再反复 `innerHTML` 重绘；“编辑画像 / 编辑兴趣”按钮增加直接绑定兜底。
4. `detail-card-lite-ui.v2981fix2.js` 去掉对 `CSS.escape(id)` 的依赖，同一卡片内直接查找展开面板，修复“展开证据 / 专业解释 / 取舍”点击失败。
5. `interaction-stability.v2982.js` 暴露 `openInterest / openProfile`，便于前置画像兴趣卡直接调用抽屉。
6. 继续隐藏普通家长视图中不应默认出现的旧模块：`profileAsk`、`mentorRules` 和大号位次带宽卡。

## 未改变的逻辑

- 统一决策上下文仍保留。
- 旧规则通过 `legacy-preference-adapter.v2982.js` 桥接到新上下文的方向不变。
- 高报师诊断仍作为同一筛选结果的解释层。
- 访问保护路径不变。

## 验证重点

部署后优先验证：

1. 输入成绩/位次后，页面不会卡住或吞点击。
2. “编辑兴趣”抽屉能打开。
3. “编辑画像”抽屉能打开。
4. 详细卡“展开证据 / 展开专业解释 / 展开取舍”能打开。
5. 资格入口、位次带宽、高报师诊断说明能展开。
6. 主页面不再默认展示旧的“可选细化”和“高级规则设置”。
