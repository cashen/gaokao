# V2.9.8.3.fix10｜Debug一键联动自测与矩阵体检版

## 基线

- 基于：`V2.9.8.3.fix9｜兴趣匹配快速预筛与画像缓存修正版`
- 输出方式仍为：`fenxi-only update`
- 只包含：`fenxi/ functions/ docs/ tools/`
- 不覆盖根目录首页

## 本版目标

本版不重写主筛选链路，不修改 fix9 的兴趣快速预筛业务逻辑。重点解决人工测试成本高的问题：

> 把“手动点一圈模块”改为 `/fenxi/debug.html` 的一键联动自测。

## 新增能力

### 1. Debug 页新增一键联动自测

`/fenxi/debug.html` 新增：

- 快速体检
- 深度矩阵自测
- 复制自测报告

自测会在同源 iframe 中加载 `index.html`，自动模拟以下链路：

- 位次 / 分数输入
- 家庭预算
- 地域 hard / soft / none
- 辽宁 hard 地域一致性
- 学生画像抽屉打开、变更、关闭
- 孩子兴趣抽屉打开、点选、上限拦截、删除、关闭
- 只看真实命中兴趣方向
- interestFastFilter / preInterestFilter 检查
- 场景联动：employment / grid / exam / broad
- A/B/C 渲染记录
- 详细候选翻页
- 高级筛选入口与导出函数存在性检查（不主动触发下载）

### 2. 深度矩阵自测

深度自测覆盖代表性组合：

- 位次：高位段 / 中位段 / 低位段
- 地域：辽宁 hard / 东北 soft / 全国 none
- 预算：normal / flex
- 兴趣：无兴趣、动物生命、计算机信息、电气机械组合
- manualOnly：false / true

为避免浏览器被无限穷举拖死，当前深度矩阵设有安全上限。报告会输出实际覆盖范围。

### 3. 自测报告写入 localStorage

自测报告存储在：

```text
ln_v2983_selftest_report
```

诊断报告仍存储在：

```text
ln_v2983_debug_report
```

Debug 页面会同时显示普通诊断摘要和自测摘要。

## 使用方式

1. 先打开 `/fenxi/` 并输入访问凭证进入工具。
2. 打开 `/fenxi/debug.html`。
3. 点击“快速体检”或“深度矩阵自测”。
4. 运行完成后点击“复制自测报告”。
5. 将报告发回用于定位。

如果 iframe 中工具页仍是 locked 状态，自测会停止，并提示先进入主页面。

## 验证重点

部署后重点查看：

- 版本是否为 `V2.9.8.3.fix10`
- 版本戳是否为 `2983fix10-20260511`
- `computePipeline` 是否为 `v2983fix10`
- 自测报告是否能输出 steps / pass / fail / warn
- 深度矩阵是否输出 coverage
- hard 辽宁场景是否继续保持 `sampleUnexpectedKept=[]`
- manualOnly 场景是否继续出现 `interestFastFilter`
