# V2.91RC0 更新说明

## 版本定位

V2.91RC0 是工程化基线与安全收口预备版。

本版不做公式改动，不做筛选规则改动，不做 A/B/C 改动，不做 engine 合并。

## 主要变化

1. 页面标题、页脚、全局版本变量统一为 V2.91RC0。
2. debug 页面标题统一为 V2.91RC0。
3. debug 自测报告顶部版本改为读取当前工具版本，避免仍显示 V2.9.8.3.fix12。
4. 新增工程文档：BASELINE、ROLLBACK、TEST_MATRIX、PERFORMANCE_BUDGET、JS_CORE_DEPENDENCY_MAP。
5. 新增发布验证脚本 `validate-v291rc0-release.js`。
