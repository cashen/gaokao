# V2.91RC0.closure5fix1.frontfix6.export-md5fix1.errorfix2 更新说明

## 修复点
1. 修复 `export-md.v291rc0md5.js` 中 `insertBefore` 的 DOM 安全问题。
   - 原因：`candidateArea.querySelector('h2')` 可能拿到后代标题，不一定是 `candidateArea` 的直接子节点。
   - 修复：新增 `safeInsert()`，只有 referenceNode 确认为父节点子节点时才使用 `insertBefore`，否则自动降级为 `appendChild`。
2. 移除旧 `export-md.v291rc0md3.css` 启动样式，避免橙棕样式回流。
3. 新增 `frontfix6`，对导出按钮、路径标签、说明按钮、资格入口说明按钮做去橙棕兜底。
4. 更新版本戳，避免浏览器继续以 `291rc0md3` 参数缓存旧脚本。

## 不变部分
- 不改候选池。
- 不改 compute-pipeline / filter-engine / plan-engine。
- 不改 closure5fix1 的 A/B/C 业务口径。
- 不改 md5 位次分层规则。
