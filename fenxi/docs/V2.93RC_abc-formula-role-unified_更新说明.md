# V2.93RC.abc-formula-role-unified 更新说明

本版不再沿用 fix/fix2 命名，按“公式角色统一版”收口。

## 目标

- A 保底但不能侮辱：安全、不坑、不失控，同时避免高分/中高分无意义下沉。
- B 主线但不能保守：B 不再只是第二个 A，应承担专业、就业、平台、家庭条件的主方案角色。
- C 机会但不能忽悠：C 必须有真实上探价值；高风险项只能作为风险对照，不能伪装机会。
- 兴趣要听但不能盲从：医学/电气等兴趣与夜班、长周期、现场环境冲突时，做替代路径转译，不做机械惩罚。
- 预算和拒绝项是底线：普通预算/拒绝高收费时，A/B 不纳入高收费、民办、中外合作；C 若出现，也必须是风险对照。

## 验收方式

只需要跑一次 `/fenxi/debug` 的完整 36 例，把日志复制回来即可。

重点看：

- `caseTotal = 36`
- `completed = 36`
- `timeouts = 0`
- `FAIL = 0`
- B 保底化 WARN 是否下降
- A 是否还出现无意义过低
- C 是否还出现伪机会
- 高收费/现场/夜班等硬拒绝项是否进入 A/B
