# V2.9RC.fix-interact2 验证清单

## 1. 版本检查

页面应显示：

```text
V2.9RC.fix-interact2
```

`/fenxi/debug.html` 应显示或包含：

```text
interactDedupe.version = 29rc-interact2-20260513
interactDedupe.opt = true
```

## 2. 固定样本一致性

用以下三组样本与 interact1 对比：

1. 625 分 / 全国 / 平台优先
2. 600 分 / 辽宁 / 稳就业
3. 500 分 / 辽宁 / 普通家庭 / 兴趣真实命中

核对：

- 有效候选数量
- A/B/C 推荐
- 前 10 个候选
- 兴趣命中数量
- 地域 hard 结果

要求：结果一致。

## 3. 高级筛选重复刷新验证

操作：

```text
高级筛选 → filterLevel：全部层级 → 稳妥 → 超冲 → 过低
```

预期：同一轮变化不再出现两次主要 `applyFilters`。

## 4. 地域模式验证

操作：

```text
regionMode：严格 → 软筛 → 不限制 → 严格
```

预期：

- 每次最终变化只按最终状态刷新
- 辽宁 hard 规则不变
- 候选结果符合原规则

## 5. 抽屉关闭回归

操作：

```text
打开兴趣抽屉 → 不改内容 → 关闭
```

预期：不触发全量 `applyFilters`。

操作：

```text
打开兴趣抽屉 → 修改一个兴趣 → 关闭
```

预期：可以刷新，但不能重复刷新。

## 6. 回退测试

将：

```js
window.LN_INTERACT_DEDUPE_OPT = true;
```

改为：

```js
window.LN_INTERACT_DEDUPE_OPT = false;
```

预期：只关闭 interact2 去重，safeperf1 和 interact1 仍保留。
