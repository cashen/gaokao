# V2.91RC0.rules-closure4.family-read1｜家长阅读结构增强版

## 定位

本版基于 `V2.91RC0.rules-closure4.front2`，只做家长阅读结构和前端表达增强，不改候选池、不改排序、不改 A/B/C 业务结果。

## 核心变化

1. 顶部改成“家庭讨论稿”封面气质：暖白、浅米、深灰正文，弱化工具后台感。
2. 新增“当前结论一句话”：先告诉家长孩子大致处在哪个分数/位次层，以及当前应重点比较什么。
3. 新增“我家主要矛盾”：把考公/电网/医学/预算/地域/候选不足等冲突讲成人话。
4. A/B/C 改成家庭会议三份方案：A 先守底线、B 重点讨论、C 看机会。
5. 每张卡片增加“查看证据与复核详情”入口，默认先读取舍和结论，再展开证据。
6. 复核动作以清单形式展示，便于家长拿去核验招生章程、学费、校区、培养方向等。
7. 新增“复制家庭群简版”，适合发给配偶、孩子、亲戚或老师讨论。
8. 明确保留标签信息量，不执行“强制减少首屏标签数量”。

## 边界

本版不修改：

- 原始数据
- 分数/位次换算
- 地域 hard 规则
- 兴趣真实命中模型
- compute-pipeline / filter-engine / plan-engine
- rules-closure4 业务闭环规则

## 家长端原则

本版目标不是更炫，而是更适合 45–50 岁家长阅读：

- 先看结论
- 再看矛盾
- 再看 A/B/C
- 最后展开证据
