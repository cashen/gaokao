# V2.91RC0.parent-trust2｜家长语言与视觉信任定版

## 定位

本版基于 V2.91RC0.parent-trust1，只做家长端表达、视觉降噪和 debug 场景口径修正。

不改公式，不改候选池，不改 A/B/C 计算，不改兴趣真正对口规则，不改地域 hard。

## 主要变化

1. 文案去 AI 味：
   - “家庭场景”主口径收为“我家情况”。
   - “当前倾向”主口径收为“当前优先考虑”。
   - “只看真实命中兴趣方向”收为“只看真正对口的专业”。
   - “学生画像”继续降噪为“孩子情况 / 孩子学习特点”。

2. debug 口径修正：
   - 新增 scenarioRaw：debug 上下文里的原始场景值。
   - 新增 scenarioEffective：parent-trust 推导出的有效场景。
   - 保留 effectivePriority 和 prioritySource。
   - 解决 scenario.current 为空，但最终标记里 scenario 有值时读起来矛盾的问题。

3. 色系降噪：
   - 背景进一步靠近白底浅灰米色。
   - 卡片尽量用白底。
   - 暖棕橙只做主强调。
   - 绿、灰蓝、红棕分别用于命中、辅助、风险。

## 验收重点

- parentTrust = v291rc0parenttrust2。
- scenarioRaw / scenarioEffective / effectivePriority / prioritySource 同时存在。
- A/B/C 和候选池结果不因本版变化而改变。
- 核心计算文件哈希保持不变。
