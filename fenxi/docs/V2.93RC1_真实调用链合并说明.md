# V2.93RC1｜真实调用链合并与运行时瘦身版

本版目标不是重写业务，而是把已经稳定生效的运行时补丁合并进当前主线，降低启动脚本数量和后置补丁叠加。

## 保持不变

- 不改 compute-pipeline / filter-engine / plan-engine 核心公式。
- 不改 region hard、兴趣真实命中、原始投档数据、一分一段数据。
- 不改 rules-closure5fix1 的 A/B/C 业务裁决公式。
- 不偷偷改变推荐结果。

## 合并内容

- `infra-core.v293rc1.js`：基础运行层合并。
- `app-postmain.v293rc1.js`：主入口后置 UI 与协调层合并。
- `family-read-final.v293rc1.js`：家长阅读与前端信任口径合并。
- `app-runtime.v293rc1.js`：详情懒加载、渲染事件、MD 导出、第 6 步布局、交互去重合并。
- `app-final.v293rc1.css`：后置样式合并，减少 CSS 请求。

## 回退开关

在页面启动前设置：

```js
window.LN_V293RC1_MERGE_OPT = false;
```

可回退到旧 legacy 加载链。
