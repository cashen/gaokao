# V2.93RC1.fix1｜启动路径规范化修正版

本版本只修复 V2.93RC1 的启动资源路径解析问题，不改计算公式、不改筛选排序、不改 A/B/C 裁决、不改投档数据和一分一段数据。

## 问题

线上 `/fenxi/` 入口在某些失败重试场景下，会把 `assets/infra-core.v293rc1.js` 误解析到站点根目录：

```text
https://gaokao.powers.org.cn/assets/infra-core.v293rc1.js
```

正确应为当前工具目录下：

```text
/fenxi/assets/infra-core.v293rc1.js
```

这会导致启动链中断，表现为页面一直加载、输入密码无效。

## 修复

1. 新增 `normalizedToolBaseV293RC1Fix1()`，以当前页面目录推导工具根路径。
2. `candidateBases()` 不再 fallback 到站点根目录 `/`。
3. 保留域名无关写法：不写死 `gaokao.powers.org.cn`。
4. 兼容：
   - `/fenxi/`
   - `/fenxi`
   - `/fenxi/index.html`
   - `/fenxi/diagnostics`
   - `/abc/fenxi/`
   - `/abc/fenxi/diagnostics`
5. 增加 debug 标记：

```js
window.__LN_BOOT_BASE_V293RC1FIX1
window.__LN_BOOT_PATH_STANDARDIZED_V293RC1FIX1
```

## 部署后检查

F12 不应再出现：

```text
https://域名/assets/infra-core.v293rc1.js
```

应看到：

```text
https://域名/fenxi/assets/infra-core.v293rc1.js
```

或部署在其他子目录时，解析到当前工具目录下的 `assets/`。
