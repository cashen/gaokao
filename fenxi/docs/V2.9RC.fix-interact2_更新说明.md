## 本次修复

基于 V2.9RC.fix-interact1 继续保守修复。interact1 已处理兴趣/画像抽屉关闭后的重复重算问题；本版新增 `assets/interact-dedupe.v29rc2.js`，针对高级筛选、层级筛选、地域模式、预算/拒绝项等控件，在同一轮 change/input/click 中出现的重复 `applyFilters` 进行指纹去重与短延迟合并。

核心原则：最终状态不变，仍调用原 `applyFilters`；只跳过 360ms 内 UI 指纹完全相同的重复调用。

## 新增开关

```js
window.LN_INTERACT_DEDUPE_OPT = true;
window.LN_INTERACT_DEDUPE_VERSION = '29rc-interact2-20260513';
```

如需回退，只关闭本次去重：

```js
window.LN_INTERACT_DEDUPE_OPT = false;
```

这不会关闭 safeperf1 和 interact1。

## 预期效果

高级筛选下拉、地域模式、预算/拒绝项等控件不再因为同一轮事件重复触发两次刷新而产生轻微卡顿。
