# V2.9.8.3.fix11｜Config启动配置内联与自测启动修正版

本说明同步放在 `fenxi/docs/`，便于只查看 fenxi 子目录时确认版本。

## 核心变化

- 基于 fix9，不重写主筛选链路。
- `/fenxi/debug.html` 新增“快速体检”“深度矩阵自测”“复制自测报告”。
- 新增 `assets/debug-selftest.v2983fix11.js`。
- 自测通过同源 iframe 模拟工具页操作，覆盖位次、家庭底线、画像、兴趣、只看真实命中、场景、A/B/C、翻页、入口函数检查等链路。
- 自测结果写入 `ln_v2983_selftest_report`。

## 注意

需要先在 `/fenxi/` 输入访问凭证进入工具，再打开 `/fenxi/debug.html` 运行自测。否则 iframe 工具页处于 locked，自测会提示停止。
