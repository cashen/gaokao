# V2.91RC0.rules-closure4.front2｜家长端低调视觉修正版

## 定位

本版基于 `V2.91RC0.rules-closure4.front1`，只做前端视觉收口，不改变业务规则、候选池、排序和 A/B/C 结果。

## 主要调整

1. 去掉黑色胶囊按钮和黑底标签，改为浅米、蓝灰、红棕风险色。
2. 顶部从偏蓝工具后台感，收为暖白/浅米/深灰的家庭讨论稿气质。
3. 减少卡片和按钮的强阴影、强凸起，改为细边框和轻分隔。
4. 步骤条降低饱和度，当前步骤用浅米底和暖棕边框提示。
5. 标签统一归类：地域/证据用蓝灰，稳妥/命中用温和绿，风险用红棕，重点用暖棕。
6. 风险词人话化：`超冲` → `位次风险高`，`过低` → `分数利用偏低`，`需谨慎` → `需重点复核`。
7. A/B/C 卡片保留 closure4 的家庭讨论角色，但视觉上更克制，不做营销式凸起。

## 边界

- 不改 `rules-closure.v291rc0closure4.js`。
- 不改 `compute-pipeline / filter-engine / plan-engine`。
- 不改兴趣真实命中。
- 不改地域 hard。
- 不改分数位次换算。
- 不改 A/B/C 业务结果。

## 部署后重点观察

- 顶部是否不再蓝一块、暖一块。
- 黑色胶囊标签是否消失。
- 按钮是否不再有强凸起商业感。
- 风险标签是否仍然醒目但不刺眼。
- PC / 手机上 A/B/C 是否更像家庭讨论报告。
