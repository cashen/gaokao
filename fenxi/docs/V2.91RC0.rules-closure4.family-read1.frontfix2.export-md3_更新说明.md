# V2.91RC0.rules-closure4.family-read1.frontfix2.export-md3 更新说明

版本名：V2.91RC0.rules-closure4.family-read1.frontfix2.export-md3｜暖白统一与 Markdown 排序重构版  
版本戳：291rc0md3-20260515

## 1. 本版边界

本版基于 export-md2，只修前端视觉与 Markdown 输出，不改候选池、不改排序、不改 A/B/C 业务结果、不改兴趣真实命中、不改地域 hard、不改 closure4 闭环规则。

## 2. Markdown 导出重构

- 仅保留“复制 Markdown 明细版”。
- 移除“复制家庭群 MD”和“下载 .md 文件”入口。
- 自选池区域新增“复制自选池 Markdown”。
- 同一“学校 + 专业 + 招生专业代号”跨 A/B/C 重复命中时，在 MD 输出中合并为一个候选，并保留多个来源标签。

## 3. 最终志愿排序规则

- 孩子位次落后 2025 最低位次时，不得归入“匹配/稳妥”。
- 落后 1–1500 位：前段：小冲 / 边缘冲。
- 基本压线：单独标注“前段/中段之间：压线匹配”。
- 领先 1000–5000 位：中段：匹配 / 稳妥。
- 领先 5000–12000 位：后段：保底。
- 领先 12000 位以上：最后：强保底 / 分数利用偏低。

## 4. C 组与高成本观察

- C 组只放机会项，不放明显强保底项。
- 民办、高收费、独立学院、中外合作、分数利用明显偏低的项目，单独进入“高成本兜底观察”。

## 5. 成本复核拆分

不再混用“成本/中外/高收费需复核”，改为：

- 学费待核验
- 民办/独立学院需复核
- 中外合作需复核
- 高收费需重点复核

## 6. 位次文案修正

- 不再出现“孩子领先约 - 位”。
- 近似压线时统一输出“基本压线”。

## 7. 视觉收口

- 色系统一偏暖白、灰黑、蓝灰、轻绿、红色风险。
- 去除棕色大块、黑色/棕色强 CTA、套餐式 A/B/C 摘要卡。
- 保留标签数量，但统一降噪。
