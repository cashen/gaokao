# V2.91RC0.package-slim1｜历史残留文件 pendingdel 退役版

## 1. 基线

本版基于 `V2.91RC0.coordinator1`。

`coordinator1` 已完成 deep 自测与真实体验确认，本版不修改业务链路，只做发布包整理。

## 2. 本版目标

将确认不参与当前主线、不参与回退、不参与 debug / diagnostics 的历史残留文件，移入 `fenxi/pendingdel/` 退役观察区。

这不是永久删除。

## 5. 回退说明

如果发现有文件误退役，可按 `fenxi/pendingdel/pendingdel-manifest.json` 将文件从 `fenxi/pendingdel/assets/` 还原到 `fenxi/assets/`。

当前 rules/ui 回退开关仍保持可用：

```js
window.LN_RULES_BUNDLE_OPT = false;
window.LN_UI_BUNDLE_OPT = false;
```
