# V2.9.5.3.fix2｜初始化与访问码启动修正版

## 修复问题

针对线上控制台报错：

- `data-engine.v2953.js: autoRefresh is not defined`
- `render.v2953.js: renderStructure is not defined`
- `app.v2953fix1.js: debouncedAutoRefresh has already been declared`

本版做了三处修复：

1. 删除 `data-engine.v2953.js` 中不应存在的 `autoRefresh / debouncedAutoRefresh` 引用。
2. 删除 `render.v2953.js` 中错误导出的 `renderStructure`，该函数实际属于 `selection.v2953.js`。
3. 重新输出 `app.v2953fix2.js`，避免重复声明 `debouncedAutoRefresh` 导致整个应用初始化中断。

## 结果

顶部访问码入口可以在数据加载状态下独立响应：输入 `ln2025` 后点击“开启工具”或按 Enter 解锁。

## 保留能力

本版只修初始化与访问码启动，不改筛选、A/B/C、规则集、数据模型与导出逻辑。
