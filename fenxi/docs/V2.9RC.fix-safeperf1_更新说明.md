# V2.9RC.fix-safeperf1｜保守加载优化与可回退安全版

## 改动边界

- 不改公式
- 不改筛选规则
- 不改 A/B/C 推荐逻辑
- 不改兴趣真实命中
- 不改鼠标点击交互
- 不引入 V3，并已移除 fenxi/v3/

## 本版实际优化

1. 新增 `assets/safeperf.v29rc1.js`，提供 `LN_SAFE_PERF_OPT` 总开关。
2. `major_name_model` 改为非阻塞后台预热，不再阻塞主启动。
3. `confusable_major_model` **不做非阻塞延后**，因为 `plan-engine` 会通过 `hasConfusableMajorV2946()` 参与 A/B/C 易混风险评分；本版仅为它增加加载计时和默认缓存，保护结果一致性。
4. `major_name_model` 和 `confusable_major_model` 的静态 JSON fetch 从 `cache:'no-store'` 改为 `cache:'default'`，利用版本号 URL 和浏览器/CDN 缓存改善二次访问。
5. `debug-runtime` 增加资源摘要、最慢资源、最大资源、导航耗时和 safePerf 状态。

## 回退方式

如上线后发现异常，把入口中的：

```js
window.LN_SAFE_PERF_OPT = true;
```

改成：

```js
window.LN_SAFE_PERF_OPT = false;
```

即可关闭 major_name_model 非阻塞优化。

## 预期收益

保守估计：首次访问整体完成时间提升约 10%～25%；二次访问因静态缓存改善更明显。由于保守保留 confusable 阻塞加载，收益低于激进版，但安全性更高。
