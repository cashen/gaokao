# V2.91RC0.coordinator1 更新说明

本版基于 V2.91RC0.ui-core1，是协调层统一入口与调度记录版。

## 边界

- 不改公式
- 不改筛选规则
- 不改 A/B/C
- 不改兴趣真实命中
- 不改 compute-pipeline / filter-engine / plan-engine / render / app 主逻辑
- 不迁移旧调用

## 新增

- `assets/app-coordinator.v291rc0coord1.js`
- `window.LN_APP_COORDINATOR`
- `window.LN_APP_COORDINATOR_OPT`
- `window.LN_APP_COORDINATOR_VERSION`
- debug 自测新增“coordinator1 协调层门面加载与导出检查”

## 目的

先建立统一协调层门面，记录事件入口、刷新请求、抽屉状态、状态快照和 debug 标记，为后续逐步把零散补丁收口到统一调度中心做准备。

## 回退

如发现异常，可在 `index.html` 中将：

```js
window.LN_APP_COORDINATOR_OPT = true;
```

改为：

```js
window.LN_APP_COORDINATOR_OPT = false;
```

这只关闭 coordinator1 的执行能力，不影响 rules-core1、ui-core1、safeperf1、interact1、interact2。
