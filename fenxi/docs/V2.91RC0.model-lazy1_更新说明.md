# V2.91RC0.model-lazy1｜非首屏模型延后加载版

基线：V2.91RC0.model-audit1。

## 目标

让第一次打开时先保证基础结果可用，非首屏解释类模型在首轮结果之后后台预热。

## 安全边界

- 不改公式
- 不改筛选规则
- 不改 A/B/C
- 不改兴趣真实命中
- 不改地域 hard
- 不改 compute-pipeline / filter-engine / plan-engine
- 不切 JSON，不改 JSON 内容

## 本版调整

1. 新增 `assets/model-lazy.v291rc0lazy1.js`。
2. `graduate_catalog_2022_2025.json` 从启动核心 taxonomy 队列移到冷模型预热。
3. `major-name-model` 首次加载保留核心映射，`graduate_subject_reference` 和 `quality_report` 作为冷补充。
4. `confusable-major-model` 首次加载保留易混判断核心模型，`parent_expectation_paths` 和 `warning quality report` 作为冷补充。
5. debug deep 自测新增 `model-lazy1 非首屏模型延后加载检查`。

## 回退

```js
window.LN_MODEL_LAZY_OPT = false;
```

关闭后，相关模型回到阻塞/立即加载口径。
