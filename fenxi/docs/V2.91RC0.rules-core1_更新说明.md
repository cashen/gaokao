# V2.91RC0.rules-core1 更新说明

## 版本定位

V2.91RC0.rules-core1 是基于 V2.91RC0 的规则脚本分段合并安全版。

本版只做低风险规则层收口，不改计算公式、不改筛选规则、不改 A/B/C、不改兴趣真实命中、不改 engine、不改 UI 逻辑。

## 版本信息

- 版本：V2.91RC0.rules-core1
- 版本戳：291rc0-rules-core1-20260513
- 基线：V2.91RC0
- 运行补丁保留：safeperf1、interact1、interact2

## 本版核心变化

新增 6 个按当前真实加载顺序分段合并的规则包：

1. `assets/rules-path-early-core.v291rc0rules1.js`
2. `assets/rules-interest-core.v291rc0rules1.js`
3. `assets/rules-path-core.v291rc0rules1.js`
4. `assets/rules-decision-core.v291rc0rules1.js`
5. `assets/rules-detail-model-early-core.v291rc0rules1.js`
6. `assets/rules-detail-export-late-core.v291rc0rules1.js`

主入口脚本请求数从 84 个下降到 63 个，减少 21 个 JS 请求。

## 为什么采用“分段合并”而不是一个大 rules-core

当前规则文件并非全部连续加载，部分规则文件中间夹有 UI、runtime、app 等依赖层。

为了保证安全，本版只合并当前加载顺序中相邻、连续、等价的规则片段，不提前加载原本后置的规则，不改变覆盖顺序。

## 回退开关

默认开启：

```js
window.LN_RULES_BUNDLE_OPT = true;
```

如需回退到旧的单文件规则加载方式，改为：

```js
window.LN_RULES_BUNDLE_OPT = false;
```

关闭后主入口会加载原 84 个 JS 队列。
