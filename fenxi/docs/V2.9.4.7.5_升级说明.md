# V2.9.4.7.5｜预算宽路径与紧凑方案盘版 升级说明

本版基于 V2.9.4.7.4 继续迭代，重点解决两个问题：

```text
1. 预算宽家庭如何主动比较中外合作、高收费、民办城市专业；
2. A/B/C 方案如何从“每列一个大卡”升级为“每列 3—4 个代表候选的紧凑方案盘”。
```

## 主要新增

```text
家庭预算新增：明确想看中外合作提档
高级筛选新增：办学 / 收费类型
专业搜索新增：主专业归一匹配
排序新增：提档价值优先
A/B/C 新增：紧凑三列方案盘
C 方案新增：中外合作 / 高收费 / 民办城市专业提档路径
```

## 关键逻辑

```text
“会计学”是主专业；
“中外合作”是办学类型；
“提档”是家庭策略。
```

用户搜“会计学”，系统可以匹配“会计学（中外合作办学）”。是否展示中外合作，取决于家庭预算和办学 / 收费类型。

## A/B/C 新展示

```text
A 稳妥公办路径：3—4 个代表候选
B 专业路径：3—4 个代表候选
C 城市 / 层级 / 提档路径：3—4 个代表候选
```

每个候选显示：

```text
冲 / 稳 / 保 / 比较
学校 + 专业
城市 / 学校性质 / 办学收费类型
为什么放这里
主要风险
复核点
```
