# V2.91RC0.rules-closure2｜家庭决策闭环定版

## 定位

本版基于 V2.91RC0.rules-closure1，不回退、不采用 V3。目标不是新增炫技功能，而是把家长真实选择中的硬底线、孩子情况、兴趣、我家情况、当前优先考虑和 A/B/C 方案形成可解释闭环。

## 核心边界

- 不改原始投档数据。
- 不改地域 hard 过滤。
- 不改兴趣真实命中模型。
- 不改分数位次换算。
- 不改 compute-pipeline / filter-engine / plan-engine 原文件。
- 通过新增 rules-closure2 闭环层接入 A/B/C 评分、提示和路径多样性。

## 本版收口内容

1. 电网/能源与不接受现场的强冲突提示。
2. 医学方向与长周期、夜班拒绝的闭环处理。
3. 低分公办、学习强度敏感、不接受现场时的可读性保护。
4. C 方案固定“机会对照”语义，不当成稳妥推荐。
5. broad 先不设限改为观察模式说明。
6. 基础理学与师范路径拆分，应用物理/应用化学/生物科学不再默认归师范。
7. 计算机强代码 / 中代码 / 数字化应用分层。
8. 财会、金融、管理、营销分层。
9. 学校备注、大类招生、校区、中外合作、民办/高收费等风险提示。
10. 家庭场景回归清单，用于后续发版固定复测。

## 家长侧解释原则

- 有冲突不是错，不解释冲突才是错。
- A 守底线，B 重点讨论，C 看机会。
- C 方案不是稳妥建议，必须复核位次波动、学费、校区、培养方式和录取规则。
- 当前优先考虑不能吞掉我家情况。
- 孩子兴趣要尊重，但遇到家庭硬底线必须提示冲突。
