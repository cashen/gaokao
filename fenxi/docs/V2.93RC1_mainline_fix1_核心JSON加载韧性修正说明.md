# V2.93RC1.mainline.fix1｜核心JSON加载韧性修正版

## 修复背景

线上 F12 出现：

```text
专业学科映射（核心）不是有效JSON：.../major_taxonomy.json；Failed to fetch
GET ... major_taxonomy.json net::ERR_HTTP2_PING_FAILED 200 (OK)
```

该问题不是业务公式错误，也不是数据文件内容错误，而是浏览器在读取 JSON 响应体时 HTTP/2 连接中断。旧版 `loadJsonFile()` 对 body 读取失败没有重试，直接把启动判死。

## 本版处理

1. `data-engine.v297fix2.js` 回填 JSON 加载重试：
   - fetch / body 读取失败时有限重试；
   - 第二次起使用 reload / no-store 和 `_try` 参数绕开坏连接；
   - 识别 Cloudflare fallback 返回 HTML 的情况，给出明确错误；
   - 写入 `LN_DATA_ENGINE_JSON_RETRY_V293RC1_MAINLINE_FIX1` 与 debug 事件。

2. `app.v2981.js` 将启动阶段三份核心学科 JSON 从并发改为有限顺序：
   - `major_taxonomy.json`；
   - `raw_major_alias.json`；
   - `subject_groups.json`。

3. `index.html` 默认关闭大批量 script preload：
   - 避免启动阶段 HTTP/2 连接被脚本预加载挤占，影响核心 JSON。
