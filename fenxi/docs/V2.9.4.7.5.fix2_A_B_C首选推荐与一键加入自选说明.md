# V2.9.4.7.5.fix2｜A/B/C 首选推荐与一键加入自选说明

本版解决的问题：`V2.9.4.7.5.fix` 虽然已实现 A/B/C 多候选，但每列候选同权重排列，家长仍然不容易看出“先看哪一个”。本版把每列改成“首选推荐 + 备选小卡”，并提供一键加入自选。

## 变更点

1. A/B/C 每列新增首选推荐大卡。
2. 每列其余候选改为备选小卡。
3. A/B/C 顶部说明改为：A 看底线，B 看专业，C 看上限。
4. 每列增加“加入本方案 N 条”。
5. 方案盘顶部增加“加入全部 A/B/C 候选”。
6. 加入自选时自动去重。
7. B 方案增强专业路径标签。
8. C 方案增强中外合作/高收费/民办提档标签。
9. Pad 自动两列；Android 自动单列。

## A/B/C 不是冲稳保

A/B/C 是路径，冲稳保是每条路径里的安全等级。

- A：稳妥公办路径，先保公办、普通学费、位次安全。
- B：专业路径，先看专业是否看得准、孩子是否学得动。
- C：城市 / 学校层级 / 提档路径，争取上限，但复核要求更高。

## 一键加入逻辑

每列按钮只加入当前方案盘展示的 2—4 条代表候选。总按钮加入 A/B/C 当前展示的全部代表候选。重复候选自动跳过。

## 多终端显示

- PC：三列方案盘。
- Pad：两列，C 横跨下一行。
- Android：单列堆叠，避免挤压。
