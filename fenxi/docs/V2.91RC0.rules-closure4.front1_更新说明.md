# V2.91RC0.rules-closure4.front1｜暖白克制前端收口版

## 定位

基于 `V2.91RC0.rules-closure4｜家庭讨论输出闭环完整版`，只做前端视觉层收口。

## 本版目标

- 参考暖白、香槟金、深灰、低饱和阴影、大留白的克制视觉。
- 保留高考家庭讨论工具的可信感，不做黑金充值风。
- 降低彩色标签噪音，风险色只用于真正风险。
- A/B/C 卡片使用边线、角色标签和轻提示区分，不做大面积撞色。
- 深色主按钮用于核心动作，普通动作使用白底/浅底按钮。
