# V2.91RC0.parent-trust1｜家长端口径与视觉信任收口版

## 定位

本版基于 `V2.91RC0.model-lazy1`，不回退到 V3 或更早版本。

本版不是性能优化版，也不是推荐公式调整版，而是把家长端最容易误解的两件事收口：

1. 业务口径：家庭场景、当前倾向、孩子学习特点、兴趣、A/B/C 各自负责什么。
2. 视觉信任：把主界面色系收成暖白、米色、暖棕橙、灰蓝、温和绿和红棕风险色。

## 主要变化

- “学生基本信息”收口为“考生基本信息”。
- “学生画像”收口为“孩子学习特点”。
- “目标路径”降级为“当前倾向 / A/B/C 倾向微调”。
- 家庭场景显示默认倾向；手动调整后显示“已手动微调”。
- 画像口径改为：主要用于提醒和排序微调，不作为硬排除条件。
- 兴趣口径明确两种模式：普通模式影响排序和 A/B/C 倾向；只看真实命中会缩小候选范围。
- A/B/C 文案收口为家庭讨论方案：A 守底线、B 主讨论、C 看机会。
- 新增 `parent-trust.v291rc0parenttrust1.css` 和 `parent-trust.v291rc0parenttrust1.js`。
- debug flags 增加 `parentTrust / scenario / effectivePriority / prioritySource / visualTrust / copyTrust`。

## 明确不改

- 不改公式。
- 不改候选池。
- 不改 A/B/C 计算。
- 不改兴趣真实命中。
- 不改地域 hard。
- 不改 `compute-pipeline.v2983.js`。
- 不改 `filter-engine.v298fix1.js`。
- 不改 `plan-engine.v297fix2.js`。

## 回退开关

如需临时关闭本版展示增强：

```js
window.LN_PARENT_TRUST_OPT = false;
```

关闭后不影响核心筛选和推荐计算。
