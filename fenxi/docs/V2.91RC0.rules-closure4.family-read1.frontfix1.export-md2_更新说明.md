# V2.91RC0.rules-closure4.family-read1.frontfix1.export-md2｜Markdown位次明细与复核增强版

基于 `export-md1`，本版只增强 Markdown 输出，不改候选池、排序、A/B/C 结果、兴趣真实命中、地域 hard 和 closure4 业务规则。

## 新增能力

1. 每条候选输出“我家位次 vs 2025最低位次”的位次差。
2. 每条候选输出 2024/2025 分数、位次对比。
3. 自动判断近两年位次：收紧、放宽、基本持平。
4. 输出招生计划变化字段；当前数据缺失时明确写“需以当年招生计划复核”。
5. 输出办学性质、学费、地域/校区、专业代号和本科专业目录复核提醒。
6. 输出是否疑似大类招生及分流提醒。
7. 输出“得到/牺牲”“为什么进 A/B/C”“在最终志愿草案中的位置”。
8. 新增“近两年位次变化汇总表”。
9. 新增“最终志愿草案排序建议”：前段小冲、中段匹配/稳妥、后段保底、最后强保底。
10. 新增“没放到主方案里的常见原因”“下一步建议”“风险汇总”“数据口径说明”。

## 重要口径

- A/B/C 是家庭讨论方案，不等于最终志愿填报顺序。
- 正式志愿草案应按“小冲—匹配/稳妥—保底—强保底”重新整理。
- 高分保和强保底可以存在，但不能排在前面。
- 位次变化只作初步复核依据，变化较大时必须复核招生计划、专业名称、学费、校区和是否单列代码。
