# V2.92RC1 回退说明

本版新增的性能和 UI 收口均带回退开关。

## 可用开关

```js
window.LN_DETAIL_LAZY_DISABLE = true
window.LN_UI_CLEAN_DISABLE = true
window.LN_FINAL_DECISION_DISABLE = true
window.LN_CONFUSABLE_LIGHT_DISABLE = true
```

## 回退影响

- 关闭 `LN_DETAIL_LAZY_DISABLE` 会恢复详细卡片提前生成，可能变慢。
- 关闭 `LN_UI_CLEAN_DISABLE` 会恢复部分旧布局和旧按钮样式。
- 关闭 `LN_CONFUSABLE_LIGHT_DISABLE` 后需回到旧全量易混模型加载方式，启动会更慢。

## 未动底层

底层筛选公式、候选池和投档数据没有改动。若需要完全回退，可部署上一版 V2.92RC 包。
