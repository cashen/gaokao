## 新增能力

1. 复制家庭群 Markdown 简版。
2. 复制 Markdown 完整复核版。
3. 下载 `.md` 文件。
4. Markdown 中保留 A/B/C、风险层、角色、取舍点、就业环境、毕业出口、复核动作、证据和冲突提示。
