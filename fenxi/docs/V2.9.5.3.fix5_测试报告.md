# V2.9.5.3.fix5 测试报告

## 修复点

修复 `PLAN_MODES_V2950 is not defined`。原因是模块化后，旧 V2950 方案卡渲染辅助函数仍读取 `PLAN_MODES_V2950`，但当前方案元数据已迁移为 `PLAN_MODES_V29476`。

## 处理方式

在 `plan-engine.v2953fix5.js` 中增加兼容别名：

```js
const PLAN_MODES_V2950 = Object.fromEntries(
  Object.entries(PLAN_MODES_V29476).map(([key, meta]) => [key, {
    ...meta,
    short: meta.shortName || meta.role || key
  }])
);
```
