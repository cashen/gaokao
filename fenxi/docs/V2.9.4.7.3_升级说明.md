# V2.9.4.7.3｜高报师工作流与 A/B/C 方案版升级说明

## 一、版本定位

本版基于 `V2.9.4.7.2｜城市精细化与地域偏好提醒版` 继续迭代。

核心变化不是重新做工具，而是在原有辽宁物理类位次初选、学生画像、城市精细化、易混专业提醒、学校地域官方校准的基础上，增加一层“高报师解释层”。

原来的工具更像：

```text
输入位次 → 筛出学校专业 → 看卡片
```

V2.9.4.7.3 变成：

```text
问底线 → 看位次 → 拆冲突 → 给 A/B/C 三方案 → 出复核清单
```

---

## 二、本版新增

### 1. 高报师诊断面板

结果页新增“高报师诊断”。

当用户设置条件过紧时，系统不再只提示“结果较少”，而是说明：

- 哪些条件互相冲突；
- 哪些条件压缩候选最多；
- 建议优先放宽什么；
- 不建议先放宽什么。

---

### 2. 条件强度识别

系统会把条件拆成：

```text
不关心 / 偏好 / 强偏好 / 硬底线
```

当前解释层覆盖：

- 成本；
- 地域；
- 城市；
- 专业热度；
- 民办路径；
- 中外合作路径。

---

### 3. 候选池漏斗

新增“候选池漏斗”，展示候选如何逐步减少：

```text
位次分段加载 → 区域筛选 → 城市筛选 → 预算保护 → 画像缩水
```

目的是让家长看懂：

```text
不是系统没数据，而是当前条件把结果压缩了。
```

---

### 4. A/B/C 三方案重构

原来的 A/B/C 更接近冲稳保。

本版改成三种取舍路径：

```text
A：稳妥公办方案
B：专业路径方案
C：城市 / 学校层级方案
```

每套方案显示：

- 一句话定位；
- 适合什么家庭；
- 牺牲了什么；
- 主要风险；
- 为什么入选；
- 必须复核什么。

---

## 三、继承不变

继续保留：

- 辽宁物理类 2024 / 2025 投档数据；
- 2025 一分一段位次匹配；
- 分块加载数据引擎；
- 招生名称 / 本科目录 / 研究生参考三层模型；
- 易混专业正主保护：正主不提示，容易被误认的一侧才提示；
- 学生画像提醒；
- 官方高校名单 XLS 校准后的学校地域 JSON；
- 城市精细化；
- PNG / CSV 导出；
- 多终端适配；
- debug 面板。

---

## 四、关键边界

1. A/B/C 方案不是正式志愿顺序。
2. C 方案不是天然更好，它只是更重城市、学校层级或上限。
3. 民办不是不能选，但不能只为本科标签选择。
4. 中外合作不是天然提档，必须核验证书、学费、校区、培养地点。
5. 城市字段是学校官方所在地，不等于专业实际就读校区。
6. 性别字段不做专业排除，只影响提醒优先级。
