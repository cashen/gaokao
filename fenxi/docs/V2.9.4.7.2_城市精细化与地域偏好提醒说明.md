# V2.9.4.7.2｜城市精细化与地域偏好提醒说明

## 一、开发原则

本版只在 V2.9.4.7.1.fix 基础上继续迭代，不重建工具、不回退旧版本。

城市能力来自已有的 `data/school_geo_model/school_geo_reference_v29471.json`。该文件已经由官方高校名单 XLS 校准，包含学校、省份、城市、区域、来源与置信度。

## 二、本版解决什么问题

V2.9.4.7.1.fix 已经能补全学校地域，但页面上城市展示不够显性，导出和 debug 也没有把城市作为一等字段呈现。

V2.9.4.7.2 做的是：

- 把学校所在地显示为“省份 · 城市”；
- 增加目标城市输入；
- 支持城市提醒 / 降权 / 硬筛；
- 导出 CSV 与 PNG 时保留城市；
- debug 面板显示城市规则命中情况。

## 三、城市字段的边界

`schoolCity` 表示学校官方所在地城市，不等于专业实际就读校区。

页面已增加提示：

> 城市来自 school_geo_model 的官方高校名单所在地；它不是专业实际就读校区。具体校区仍要以招生章程和培养方案为准。

这可以防止把“学校所在地”误解成“该专业四年就读校区”。

## 四、筛选逻辑

新增 `cityMode`：

1. `none`：不限制城市；
2. `soft`：只提醒 / 降权，不排除；
3. `hard`：硬筛，只保留目标城市。

新增 `targetCities`：

- 支持多个城市；
- 可用空格、逗号、顿号分隔；
- 如：`沈阳 大连 杭州 青岛`。

## 五、策略卡变化

- “沈阳优先”会自动设置：辽宁省内 + 目标城市沈阳 + 城市软提醒；
- “大连优先”会自动设置：辽宁省内 + 目标城市大连 + 城市软提醒。

这两个策略默认不硬筛，避免过早砍掉候选面。

## 六、导出变化

CSV 新增字段：

- 省份；
- 城市；
- 区域；
- 学校地域来源；
- 地域置信度；
- 地域说明。

PNG 摘要新增目标城市展示，并更新版本号为 V2.9.4.7.2。

## 七、未做的事

本版没有做“专业校区城市”。原因是：专业实际校区需要学校招生章程、培养方案或当年招生计划备注支持，不能仅凭官方高校名单推断。

后续若要做，应新增独立字段，例如：

```json
{
  "schoolCity": "沈阳",
  "campusCity": "待核验",
  "campusCitySource": "admission_plan_or_school_rule"
}
```

不要把 `schoolCity` 当成 `campusCity` 使用。
