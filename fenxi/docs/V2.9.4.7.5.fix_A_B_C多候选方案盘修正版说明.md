# V2.9.4.7.5.fix｜A/B/C 多候选方案盘修正版说明

## 版本定位

本版基于 `V2.9.4.7.5｜预算宽路径与紧凑方案盘版` 修正。

重点不是新增概念，而是修正实际渲染：A/B/C 不再每列只显示 1 个代表候选，而是每条路径下显示 2—4 个候选小卡。

## 修正内容

```text
1. 新增独立入口 app.v29475fix.js / app.v29475fix.css，避免浏览器继续加载旧版缓存。
2. A/B/C 三条路径独立选取候选，不再共用全局 chosen。
3. A 路径、B 路径、C 路径各自最多展示 4 个代表候选。
4. 候选足够时，每列应显示多张 plan-mini-v29475 小卡。
5. 每张小卡显示冲/稳/保/比较、学校专业、位次、办学类型、为什么、风险和复核点。
6. PC 三列展示，Pad/Android 自动单列堆叠。
7. 保留预算宽 / 中外合作提档逻辑。
8. 保留高校专项计划默认保护逻辑。
```

## 正确产品形态

```text
A：稳妥公办路径
  A1 候选
  A2 候选
  A3 候选
  A4 候选

B：专业路径
  B1 候选
  B2 候选
  B3 候选
  B4 候选

C：城市 / 学校层级 / 提档路径
  C1 候选
  C2 候选
  C3 候选
  C4 候选
```

A/B/C 是路径，不是冲稳保；冲稳保是每条路径里的安全等级。

## 多终端显示

```text
PC：三列方案盘。
Pad：根据宽度自动压缩或切成单列，避免列宽过窄。
Android：单列卡片，上下滑动阅读，每个路径内部保持紧凑小卡。
```

## 校验方式

```bash
node --check assets/app.v29475fix.js
node tools/validate-v29475fix-release.js
```
