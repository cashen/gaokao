# V2.9.5.4｜入口收敛与交互优化版｜fix1 模块加载诊断修正版

本版只修复 V2.9.5.4 公网诊断中 `LN_CONFIG`、`LN_EXPORT` 未挂载导致页面停在“正在准备数据”的问题。

## 改动

1. 主资产文件升级为 `v2954fix1`，避免继续命中旧缓存。
2. `diagnostics.html` 增加“脚本加载来源”，可以看清每个脚本实际从哪个 URL 加载。
3. `index.html` 使用顺序加载器，兼容根路径和 `/fenxi/` 路径部署。
4. `config` 根据实际加载路径推导 `data/` 路径，避免 clean URL 下数据目录解析错误。
5. `export` 增加 ready 标记，诊断能区分“文件没加载”和“模块没完成挂载”。
