# V2.9.8.3.fix9｜兴趣匹配快速预筛与画像缓存修正版

本版基于 V2.9.8.3.fix8 继续修复性能瓶颈：

- `compute-pipeline.v2983.js` 新增快速兴趣匹配器，优先使用本科目录代码、专业类代码、学科代码和标准专业名做轻量判断。
- “只看真实命中兴趣方向”不再逐条调用旧 `matchRecord/filterPass` 做重匹配，先用快速预筛缩小候选池。
- `interestSortScore` 改为优先使用快速兴趣分，避免对数千条候选逐条跑完整兴趣匹配。
- `profileKey` 不再把 `manualOnly` 当作画像缓存失效因素，切换“只看真实命中”时尽量复用已有画像分缓存。
- Debug 增加 `interestFastFilter` 与 `interestSortFast` 标记，方便确认兴趣预筛是否走快速路径。

仍保持 fenxi-only update，不覆盖根目录首页。
