# V2.9.5.0｜家长流程重排与方案引擎瘦身版

## 一句话说明

本版把工具从“功能区堆叠”重排为更符合家长心智的五步流程：先定位次，再定底线，再选目标，再看 A/B/C，最后复核自选。

## 主要变化

- 家庭底线卡前置。
- A/B/C 方案盘成为主结果。
- 详细候选区后置。
- 默认开启家长简洁模式。
- A/B/C 渲染入口统一到新版 `renderPlanABC()`。
- 旧版 `renderPlanABC` 函数改名为 deprecated，避免继续被误改。
- 保留所有 V2.9.4.7.6 稳定能力。

## 产品原则

- 不做黑盒推荐。
- 不用性别做专业排除。
- 高校专项默认隐藏。
- 中外合作不是天然提档，必须显示换来、付出和复核。
- A/B/C 不是冲稳保，冲稳保是每条路径里的安全等级。

## 用户流程

1. 定位孩子分数 / 位次。
2. 确认家庭底线：预算、专项资格、地域、城市、是否出省、明确不接受项。
3. 选择目标路径：就业、城市、学校、医学、电网、体制等。
4. 查看 A/B/C 方案盘。
5. 进入详细候选和自选池复核。
