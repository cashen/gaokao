# V2.9RC.fix-interact1｜抽屉关闭重算去重与延后版

## 目标

本版只修一个问题：兴趣/画像相关抽屉关闭后，页面偶发触发 `applyFilters` 重算，造成 300–600ms 左右主线程卡顿。

## 边界

- 不改公式
- 不改筛选规则
- 不改 A/B/C 推荐逻辑
- 不改兴趣真实命中规则
- 不改鼠标点击交互含义
- 不碰 V3
- 不合并 JS
- 不延后 taxonomy_runtime / school_geo_model / chunks / manifest / rank

## 核心修复

新增：

```text
assets/interact-stability.v29rc1.js
```

主要做三件事：

1. 对兴趣/孩子想法状态生成轻量指纹；
2. 抽屉关闭后，如果状态指纹与上一次已计算状态一致，则跳过本次 `applyFilters`；
3. 如果状态确实变化，则仍然执行原来的刷新，但延后到抽屉关闭后，避免关闭动作和重算挤在一起。

## 安全策略

- 状态无变化：不重算；
- 状态有变化：仍按原公式、原筛选、原 A/B/C 计算，只是延后执行；
- 所有逻辑只包裹调度层，不修改 `compute-pipeline.v2983.js`；
- `safeperf1` 的加载优化继续保留。

## 回退方式

如需关闭本次交互优化，可在 `index.html` 中把：

```js
window.LN_INTERACT_FIX_OPT = true;
```

改为：

```js
window.LN_INTERACT_FIX_OPT = false;
```

关闭后不影响 `safeperf1`。
