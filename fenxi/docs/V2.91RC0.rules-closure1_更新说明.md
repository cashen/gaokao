# V2.91RC0.rules-closure1｜家庭条件闭环完整版

## 版本定位

本版基于 `V2.91RC0.parent-trust2 checked`，不回退、不采用 V3。重点解决“条件入口很多，但组合后没有形成家庭真实决策闭环”的问题。

## 本版解决的问题

1. 性别不再只是展示字段，但不作为单独硬排除条件。
   - 男孩/女孩不会直接决定能不能报某专业。
   - 只有在“性别 + 学习强度 + 现场接受度 + 家庭场景 + 兴趣”组合下才影响 A/B/C 排序和提醒。

2. “不接受工地/现场”不再只命中土木、采矿、石油、地质等少数专业。
   - 新增工地/艰苦现场、工厂/设备现场、电力/能源现场、实验/设备环境四类判断。
   - 电气、能源、自动化、机械、测控等方向会按现场属性分层降权或提醒。

3. 考公场景不再容易被电气/能源路径吞掉。
   - 法学、汉语言、财会、统计、师范、计算机等典型考公/考编友好方向上升。
   - 电气、能源、机械、自动化等非典型考公路径在考公场景下不再默认霸屏。

4. 当前优先考虑不再吞掉“我家情况”。
   - 如果我家情况是考公，但当前优先考虑仍残留电网/能源，系统会在排序和 debug 中识别冲突。
   - 电网路径仍可保留，但不会在无明确兴趣时压过考公主线。

5. A/B/C 增加路径多样性守卫。
   - 如果 A/B/C 首选过度集中在同一路径，且用户没有明确选择该方向，会替换为第二路径候选或给出 debug 提醒。
