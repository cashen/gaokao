# V2.9.5.3.fix4｜模块缓存隔离与运行时校验版

## 修复背景

线上反馈出现以下运行时错误：

```text
data-engine.v2953.js: autoRefresh is not defined
render.v2953.js: renderStructure is not defined
app.v2953fix2.js: Identifier 'debouncedAutoRefresh' has already been declared
```

这类问题的根因是模块拆分后旧文件名仍被缓存，且部分模块存在全局变量/函数边界不清。

## 本版处理

1. 所有主模块统一升级为 `v2953fix4` 文件名，隔离浏览器/Cloudflare 缓存。
2. `index.html` 只引用 fix3 模块，不再引用 `v2953.js` / `fix1` / `fix2`。
3. `app.v2953fix4.js` 使用 `window.debouncedAutoRefreshV2953Fix4`，避免重复声明。
4. `data-engine` 不负责刷新页面，避免底层模块依赖 app 层。
5. `render` 不导出不存在的 `renderStructure`。
6. 新增 `diagnostics.html` 作为上线后模块运行检查页。

## 不改动内容

- 不改筛选口径。
- 不改 A/B/C 规则。
- 不改高校专项默认隐藏逻辑。
- 不改主专业归一搜索逻辑。
