# V2.91RC0.rules-closure3｜闭环解释与路径分类定版

版本戳：291rc0closure3-20260514

## 定位

基于 V2.91RC0.rules-closure2，专门修复矩阵测试发现的最后一批闭环解释和路径分类问题。

## 本版解决

1. 路径集中说明：当 A/B/C 因明确兴趣集中到计算机、电气、医学等方向时，页面说明“集中原因”；非明确兴趣导致集中时，系统尝试换入第二路径对照。
2. 考公与医学兴趣冲突：考公场景下如果孩子选择医学，保留医学为兴趣项，但明确说明它不是典型考公主线。
3. soft 地域全局提示：区域优先不等于只看该区域，提示提升到 A/B/C 顶部。
4. broad 观察模式全局提示：先不设限仅用于看方向，不作为最终推荐。
5. 当前优先考虑冲突收窄：只有用户手动微调过 priority，才判定 scenarioPriorityConflict。
6. 路径分类修正：能源化学工程、化学工程、材料化学等归入实验/化工工程，不再误归电气能源。
7. A/B/C 抽样优化：不再仅取 filtered 前 420 条，而是先按闭环分数预排序后取候选。
8. 导出风险字段准备：rules-closure 暴露 closureCsvFields / exportClosureSummary，供导出链路读取闭环标签、冲突和风险说明。

## 边界

- 不改原始数据。
- 不改地域 hard。
- 不改兴趣真实命中模型。
- 不改分数位次换算。
- 不改 compute-pipeline / filter-engine / plan-engine 原文件。

## 部署后重点验证

- deep 自测。
- 1450 组合矩阵抽测。
- 平台优先 + 计算机兴趣是否出现路径集中说明。
- 考公 + 医学兴趣是否出现冲突解释。
- soft 地域是否顶部提示。
- 能源化学工程是否不再归为 electric。
