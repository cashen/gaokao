# V2.9.4.6｜易混专业筛选与辨析增强版

## 版本定位

本版基于 V2.9.4.5，不新增保研率等外部不稳定数据，重点增加“易混专业筛选器”：

> 识别家长容易按名字误判、但本科代码 / 门类 / 专业大类 / 培养路径不同的专业，并在同校近分场景下重点提示。

## 前端变化

1. 高级筛选新增“易混主题”下拉框。
2. 高级筛选新增“只看易混专业提醒”。
3. 候选卡片中新增“名字相近，方向可能不同”的展开对比卡。
4. Debug 模式显示易混模型加载数量。

## 重要边界

- 易混提醒不是专业好坏排序。
- 本提示基于招生名称、本科目录代码、学科门类、专业大类和同校近分关系。
- 具体课程、分流、校区、学费、转专业政策仍需查学校招生章程和培养方案。
