# V2.91RC0.rules-closure4.family-read1.frontfix1｜家长尊重感视觉修正版

基线：V2.91RC0.rules-closure4.family-read1。

本版只修前端尊重感和阅读感，不改候选池、不改排序、不改 A/B/C 业务结果、不改 closure4 家庭决策闭环规则。

## 本版修正

1. 大棕色“查看证据与复核详情”降级为浅底细边按钮。
2. 文案改为“查看依据与复核”，避免强 CTA 感。
3. “家长必读”改为“提醒”，避免训话感。
4. “本卡先看 / 闭环判断 / 下一步复核”改为“先看 / 怎么看 / 下一步”。
5. 复核清单不再在首屏显示方框，改成自然短句。
6. “加入”按钮改为“＋ 加入自选”，样式弱化，避免购物车感。
7. 标签数量保留，但圆角、颜色、字重降噪，改成资料标签感。
8. 步骤条改为轻流程，不做儿童闯关式大按钮。
9. “家长简洁模式”改为“家庭讨论模式”。
10. 棕色减少大块使用，主要用于文字、边线和弱强调。

## 明确不改

- 不改 compute-pipeline / filter-engine / plan-engine。
- 不改 rules-closure.v291rc0closure4.js。
- 不改兴趣真实命中。
- 不改地域 hard。
- 不减少标签数量。
- 不改 A/B/C 业务结果。
