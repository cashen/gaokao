# V2.9.4.6.2｜易混专业提醒侧过滤版

## 版本定位

本版本保留 V2.9.4.6 的易混专业检测结果，但改变前端提醒策略：

> 正主专业不主动显示“易混专业”提醒，只作为对比参照；真正容易被误认的一侧才显示提醒。

## 为什么要做

原 V2.9.4.6 会把同一易混专业对的双方都放入提醒索引。这样在某些场景会误伤正主专业，例如：

- 电气工程及其自动化：本身属于电气类主路径，不应被打成“易混风险”。
- 计算机科学与技术 / 软件工程 / 数据科学与大数据技术：本身属于计算机类主路径，不应被当成“看错提醒”。
- 临床医学 / 口腔医学：本身是医生路径主相关专业，不应被打成“医学易混”。

本版本新增“正主保护”和“提醒侧过滤”。

## 前端策略

- 优先读取 `confusable_major_record_index_v29462.json`。
- 正主记录不进入提醒索引。
- 易混对仍保留在 detectedPairs 中，用作展开对比。
- 卡片文案改为“只在容易被误认的一侧提醒”。

## 核心测试

- 营口理工学院：
  - `大数据管理与应用`：显示提醒。
  - `数据科学与大数据技术`：不显示提醒。

- 电气类：
  - `电气工程及其自动化`：不显示提醒。
  - `自动化 / 测控技术与仪器 / 电子信息工程`：显示提醒。

- 计算机类：
  - `计算机科学与技术 / 软件工程`：不显示提醒。
  - `信息与计算科学 / 信息管理与信息系统`：显示提醒。

## 边界

本版本不是取消易混专业，而是减少误伤。易混检测结果仍然保留，只是前端提醒变得更克制。
