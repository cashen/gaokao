# V2.91RC0.ui-core1 更新说明

## 版本定位

V2.91RC0.ui-core1 基于 V2.91RC0.rules-core1，是 UI 脚本分段合并安全版。

本版只合并部分 UI / 交互展示类脚本，不改计算公式、不改筛选规则、不改 A/B/C、不改兴趣真实命中、不改 engine、不改 DOM 结构、不改点击含义。

## 版本信息

- 版本：V2.91RC0.ui-core1
- 版本戳：291rc0-ui-core1-20260513
- 基线：V2.91RC0.rules-core1
- 保留：rules-core1、safeperf1、interact1、interact2

## 本版核心变化

新增 6 个按当前真实加载顺序分段合并的 UI 包：

1. `assets/ui-form-step-core.v291rc0ui1.js`
2. `assets/ui-result-basic-core.v291rc0ui1.js`
3. `assets/ui-candidate-detail-early-core.v291rc0ui1.js`
4. `assets/ui-notice-profile-early-core.v291rc0ui1.js`
5. `assets/ui-detail-notice-late-core.v291rc0ui1.js`
6. `assets/ui-late-interaction-core.v291rc0ui1.js`

在 rules-core1 已开启时，主入口脚本请求数从 63 个下降到 54 个，进一步减少 9 个 JS 请求。

## 为什么采用“分段合并”

UI 文件之间存在后加载覆盖、旧兼容入口和补丁层关系。本版不做重排，不做重写，只按当前 index.html 中的连续 UI 文件段原样拼接，最大限度保持运行语义一致。

## 回退

默认开启：

```js
window.LN_UI_BUNDLE_OPT = true;
```

如发现异常，可改为：

```js
window.LN_UI_BUNDLE_OPT = false;
```

仅关闭 ui-core1，rules-core1、safeperf1、interact1、interact2 不受影响。
