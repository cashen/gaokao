# V3.0.0.beta2｜家长端阅读节奏与决策摘要栏版

版本戳：`v300beta2-20260512`

## 目标

基于 alpha7 的详细候选卡片与自选池稳定基线，新增“条件变化对照”。

这不是替家长改选择，而是把关键条件变化的代价讲清楚：

- 地域从“只看”改成“优先”，候选会扩大多少；
- 是否关闭“只看真实命中兴趣方向”，会恢复多少底线池；
- 排除高收费/中外合作，会减少多少候选；
- 排除民办独立，会减少多少候选。

## 放置位置

在 Step6「详细候选 & 自选池」中，放在自选池和 A/B/C 详细卡片之前。

## 原则

- 只做比较，不自动替用户改设置。
- 地域 soft 表达为“偏好”，不是“放弃”。
- 兴趣真实命中仍保留为用户选择，不默认关闭。
- 费用、学校性质类建议只提示代价与复核方向。

## Debug

一键总检新增检查：

- 反事实比较适配器存在；
- Step6 反事实比较已生成；
- 地域 hard→soft 对照存在；
- 关闭真实命中可恢复底线池对照存在；
- 费用风险收窄对照存在。
