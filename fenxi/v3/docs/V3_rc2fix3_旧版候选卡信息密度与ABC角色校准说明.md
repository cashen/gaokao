# V3.0.0.rc2.fix3｜旧版候选卡信息密度与A/B/C角色校准版

本版只改 `/fenxi/v3/`，不覆盖旧版 `/fenxi/index.html`。

## 修复重点

1. A/B/C 先按位次角色、家庭底线、学校性质和费用校准，不再把“越低越安全”直接推到 A 前排。
2. B 看专业只承接可达范围内的专业正主/相近、孩子兴趣或明确目标路径，避免审计/法学等无关专业混入电气、计算机主线。
3. C 明确承接可冲、上限探索、平台/城市比较，样例显示冲稳保/位次角色。
4. 资格型计划默认不混入普通方案；高校专项、预科、定向等没有确认资格时只做复核提示。
5. 候选复核卡恢复旧版信息密度：2025分位、学校性质、院校层级、公办民办/职业本科、收费、招生身份、年度位次变化、专业路径、家长重点看和复核清单。
6. 字段读取增加 fallback，解决旧数据里有 2025 分位但 V3 卡片显示“待复核”的问题。

## 回归样本

- 460 分 + 只看辽宁：A 不应由 367 分过低候选占满前排；职业本科、民办、资格计划必须显式标注。
- 600 分 + 计算机/电气 + 电网能源：A/B/C 都应有，东北大学等明显上探候选进入 C，不进入 B 主方案。
- 候选复核筛选为 0 后，基础候选池和 A/B/C 不被污染。
