# V3.0.0.rc5｜候选闭环与精准专业参与计算修正版

版本戳：v300rc5-20260513

## 修改范围
仅覆盖 `/fenxi/v3/` 与 `tools/validate-v300rc5-release.js`，不覆盖旧版 `/fenxi/` 主线，不覆盖根目录首页。

## 核心修复

1. Step3 恢复“展开具体专业”。孩子可以在兴趣方向下继续选择精准专业。
2. 精准专业进入 RC5 主计算链：精确点选、正主、相近、泛相关/易混会影响 B 方案、候选卡解释和报告。
3. 修复候选清单闭环：候选生成写入 Store，点击“加入家庭自选池”后可显示、可移出、可进入导出报告。
4. 候选页保留 A/B/C Tab，但高级筛选回到旧版复核语义，不再把 A/B/C 当高级筛选核心条件。
5. 导出报告写入孩子兴趣方向、精准专业、家庭自选候选。
6. 新增 RC5 debug 与发布校验，覆盖候选生成、自选池、精准专业和导出链路。

## 家庭端原则

家庭端不展示测试样例、分块、loadedRows、mock 学校等开发信息；技术诊断保留在 Debug 页。
