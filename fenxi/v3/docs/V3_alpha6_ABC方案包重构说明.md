# V3.0.0.alpha6｜A/B/C方案包重构版

## 目标

alpha6 基于 alpha5.fix2 的决策上下文，重构第 5 步 A/B/C 方案包。此版本仍为 v3 preview-only，不替代 fix12 正式 compute 主链路。

## 核心原则

- A/B/C 不是普通“冲稳保”，而是家庭讨论用的三套方案包。
- 分数段、家庭路径、地域选择强度、孩子兴趣、学生画像、专业画像共同影响解释。
- 学生画像和专业画像只做提醒与复核，不硬筛。
- Step5 只看方向和样例；Step6 详细卡片继续承接证据等级、风险提示、复核清单和自选池。

## A/B/C 含义

默认：

- A：守底线方案
- B：孩子路径方案
- C：上限探索方案

高分段：

- A：稳妥强校
- B：强专业路径
- C：平台上限

低分/边缘段：

- A：真实保底
- B：可读专业
- C：替代比较
