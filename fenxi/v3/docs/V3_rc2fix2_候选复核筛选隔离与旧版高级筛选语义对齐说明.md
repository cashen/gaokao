# V3.0.0.rc2.fix2｜候选复核筛选隔离与旧版高级筛选语义对齐版

本版只更新 `fenxi/v3/`，不覆盖旧版 `/fenxi/index.html`。

## 修复目标

RC2.fix1 中，候选复核页的高级筛选会进入基础计算链：当用户在候选复核页把条件筛到 0 后，再返回分数页重新计算，仍可能带着上次筛选条件，造成“怎么算都没数”的状态污染。

RC2.fix2 将逻辑拆成两层：

1. **基础候选池**：只由位次、家庭底线、孩子兴趣、学生画像、场景路径、资格入口保护生成，用于 A/B/C 和导出基础数据。
2. **候选复核视图**：在基础候选池上叠加学校、专业、A/B/C、位次角色、目录可信度、层级、收费、易混、重点学科等高级筛选。它只影响当前页面显示，不会污染基础候选池。

## 旧版高级筛选语义对齐

本版增强 `advanced-filter-adapter.v3.js`：

- 学校关键词：只匹配学校名。
- 专业关键词：复刻旧版多字段搜索思路，覆盖招生专业名、cleanMajor、官方本科专业名、专业代码、专业类、学科门类、研一级等。
- 专业类 / 研一级 / 官方代码：复刻旧版多字段 OR 检索。
- 目录可信度：支持高可信、中高可信、待复核。
- 院校层级：支持 985、211、公办/公办倾向、民办/独立、性质待核验。
- 收费类型：支持普通费用视角、只看中外/高收费、排除高收费/民办、只看民办/独立。
- 易混/重点学科：保留旧版“只看易混/需复核”“只看重点学科”的工作台语义。
- 排序：保留画像匹配、A/B/C 角色、位次匹配度、2025 位次、竞争增强、位次放宽、提档价值等口径。

## 候选复核页新增

- 显示“基础候选池”和“当前筛选”两个数字，避免把筛选为 0 误认为没有基础数据。
- 增加“候选筛选漏斗”，显示每个筛选条件从多少条压到多少条。
- 筛选为 0 时显示提示：当前筛选把候选压成 0，但基础候选池仍在。
- 增加“清空本页筛选”“返回基础候选”。
- 重新计算基础候选池时，不带候选复核页高级筛选。

## 状态失效

- 位次、家庭底线、孩子兴趣变化时，自动清空候选复核页高级筛选，避免旧筛选污染新结果。
- 候选复核筛选变化只标记 `candidateReviewView`，不触发基础候选池重算。
