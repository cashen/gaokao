# V3.0.0.alpha7｜详细候选卡片与自选池版

本版基于 `V3.0.0.alpha6.fix3` 一键总检稳定基线继续开发 Step6。

## 核心变化

- A/B/C 方案不再作为终点，Step6 承接为详细候选卡片。
- 每张卡片包含方案角色、分数位次、学校性质、地域、兴趣命中、证据等级、复核项和一句人话解释。
- 新增自选池增删能力，支持从详细卡片加入/移出。
- Debug 一键总检继续保留，主流程自动覆盖 Step6 卡片生成与自选池增删。

## 开发边界

- 仍为 v3 preview-only。
- 不改旧 `/fenxi/index.html`。
- 不替代 fix12 正式 compute 主链路。
