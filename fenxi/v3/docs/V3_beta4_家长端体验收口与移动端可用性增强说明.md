# V3.0.0.beta4｜家长端体验收口与移动端可用性增强版

版本戳：`v300beta4-20260512`

## 定位

基于 `V3.0.0.beta3` 稳定基线继续收口家长端体验。本版不改家庭路径权重、不改 A/B/C 方案包、不改候选卡片生成、不接正式 compute 主链路，只处理真实页面操作节奏和移动端可用性。

## 主要调整

1. 新增 `page-experience-adapter.v3.js`，集中管理家长端页面体验策略。
2. 每个 Step 自动加入“本步重点”提示，减少家长在多 Tab 中迷路。
3. 移动端复核清单默认折叠，避免占用过多首屏空间。
4. 移动端主操作按钮增强触达：底部 Tab 上方形成轻量 sticky 操作区。
5. 导出页复制报告后按钮显示“已复制”，给家长明确反馈。
6. Debug 一键总检增加页面体验策略检查，包括真实页面结构、移动端折叠、底部安全区和复制反馈。

## 不变项

- 不改 Step4 家庭路径权重。
- 不改 Step5 A/B/C 方案包逻辑。
- 不改 Step6 详细候选卡片与自选池逻辑。
- 不改 Step6 条件变化对照。
- 不改 Step7 家庭讨论报告内容结构。
- 不覆盖旧 `/fenxi/index.html`。

## 部署后测试

打开：

```text
/fenxi/v3/debug.html
```

点击：

```text
一键总检：路径矩阵 + 主流程
```

重点看：

- 版本是否为 beta4。
- 一键总检是否 0 失败。
- 页面体验适配器是否存在。
- 真实页面体验策略是否通过。
- 移动端折叠与底部安全区策略是否通过。
- 主流程是否仍最终停在导出页。
