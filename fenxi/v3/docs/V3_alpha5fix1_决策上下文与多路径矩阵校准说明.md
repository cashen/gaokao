# V3.0.0.alpha5.fix1｜决策上下文与多路径矩阵校准版

版本戳：v300alpha5fix1-20260512

## 本版定位

本版基于线上已部署的 V3.0.0.alpha5，不继续向 A/B/C 方案页盲目推进，而是先把 Step4 从“简单场景推荐”校准为“家庭路径推荐”。

核心原则：

- V3 不是重写旧算法，而是把旧版决策逻辑拆成家长能一步一步使用的向导。
- 场景/家庭路径权重大于孩子兴趣；孩子兴趣主要影响 B 方案和详细卡片解释。
- 地域选择不是单纯“放弃/不放弃”，而是有强度：硬底线、偏好、开放比较。
- 高分段、低分段不能套同一套路径解释。

## 新增能力

1. `score-band-strategy-adapter.v3.js`
   - 识别 625+、590–624、550–589、500–549、450–499、367–449。
   - 为每个分数段生成首要问题、A/B/C 解释重点、详细卡片关注点。

2. `region-preference-adapter.v3.js`
   - 把地域拆成：地域底线、地域偏好、地域开放。
   - soft 地域明确表达为“优先但可放宽”，不是放弃。

3. `decision-context-adapter.v3.js`
   - 统一生成 Step4/后续 Step5/Step6 需要的上下文。
   - 包含：位次、分数段、家庭底线、地域强度、孩子兴趣、manualOnly、候选池规模。

4. `scenario-adapter.v3.js` 重构
   - 从 4 个场景扩展为家庭路径：平台优先、强专业优先、省内公办稳妥、普通家庭就业路径、电网能源、考研深造、宽口径比较、真实保底、成本风险控制。
   - 高分电气不再误推单一电网路径。
   - 500 分辽宁 hard 电气路径改为“省内公办稳妥，B 方案承接电气”。
   - 低分电气优先保底和成本风险，不被兴趣带偏。

5. Debug 增强
   - 新增“一键主流路径矩阵自测”。
   - 覆盖高分、中高分、中段、500 分、低分、本科边缘、地域 soft、动物医学等路径。

## 注意

本版仍不触发旧 compute 主链路，不替代 fix12 计算结果。它只校准 V3 Step4 的家庭路径解释层。
