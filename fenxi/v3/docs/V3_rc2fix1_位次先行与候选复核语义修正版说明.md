# V3.0.0.rc2.fix1｜位次先行与候选复核语义修正版

## 修正原因

RC2 迁入了旧版路径规则，但主链路把“兴趣命中”放得过靠前，导致：

- 兴趣命中后 A 被强行转入 B；
- 600 分样本中明显够不上的东北大学 635/643 进入 B 主方案；
- C 上限探索被 B 吸空；
- A 守底线方案可能为 0；
- “自选”语义混乱，系统候选被误读为家庭自选。

## fix1 关键修正

1. A/B/C 先按位次角色分层，再看专业路径。
2. 删除“兴趣命中后 A 强行改 B”的错误逻辑。
3. B 方案只能承接匹配/稳妥等可讨论范围内的专业路径。
4. 明显上探、超冲过远候选只进入 C 上限探索，不能进入 B 主方案。
5. A 恢复家庭底线兜底职责。
6. 第 6 步改为“候选复核 & 家庭自选池”。
7. 候选复核池与家庭自选池彻底分离。
8. 横向比较只使用家庭自选池，不再自动拿系统候选凑表。
9. 候选复核卡恢复旧版核心信息：位次角色、招生身份、成本提醒、年度位次、专业路径、复核清单。
10. Debug 增加 600 分 + 计算机/电气 + 电网能源真实流程矩阵。

## 不变原则

- 不覆盖旧版 `/fenxi/index.html`。
- 性别/画像只做提醒和排序解释，不做专业硬排除。
- 家庭底线优先级高于场景路径。
- 系统候选不等于家庭自选。
