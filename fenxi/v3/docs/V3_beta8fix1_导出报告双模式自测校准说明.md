# V3.0.0.beta8.fix1｜导出报告双模式自测校准版

版本戳：v300beta8fix1-20260512

## 修复原因
beta8 中导出报告已改为“精简版 / 完整版”双模式，默认输出精简版。但一键总检仍然用旧口径检查当前 markdown，要求其中必须包含“当前家庭决策处境、决策日志、自选池”等完整版内容，导致导出功能实际正常、自测口径误报。

## 修复内容
- 一键总检区分 compactMarkdown 与 fullMarkdown。
- 精简版检查“当前结论、A/B/C、必须复核、条件变化”。
- 完整版检查“当前家庭决策处境、决策日志、A/B/C 详细卡片摘要、自选池、条件变化对照、证据等级、复核任务清单”。
- 不改变家庭路径、A/B/C、候选生成、证据等级判断和导出内容结构。

## 测试方式
部署后进入 `/fenxi/v3/debug.html`，点击“一键总检：路径矩阵 + 主流程”，期望 0 失败。
