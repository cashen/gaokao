# V3.0.0.beta2｜家长端阅读节奏与决策摘要栏版

基于 beta1 稳定主流程，不改业务权重和筛选逻辑，只增强家长端阅读节奏。

## 本版新增

- 在主工具页进度条下方新增“当前决策摘要栏”。
- 摘要栏持续显示：当前步骤、下一步要做什么、位次/分数、地域选择、孩子兴趣、家庭路径、当前候选和已完成项。
- 移动端自动收敛为两列或单列，避免普通家长在多 Tab 中迷路。
- Debug 一键总检新增“家长端决策摘要渲染方法存在”检查。

## 不变

- 不改 Step4 家庭路径权重。
- 不改 Step5 A/B/C 方案包。
- 不改 Step6 详细卡片、条件变化对照和导出报告。
- 不覆盖旧 /fenxi/index.html。
