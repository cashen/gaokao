# V3.0.0.alpha5.fix2｜孩子画像与专业画像回迁版

本版基于 alpha5.fix1，不继续堆 A/B/C，而是把旧版“学生画像只做提醒、不硬筛”和“专业画像/易混专业复核”回迁到 V3 决策上下文。

## 核心原则

1. 家庭路径权重高于孩子兴趣。
2. 孩子兴趣主要影响 B 方案解释和详细卡片，不直接盖过家庭路径。
3. 学生画像只调整提醒顺序和复核重点，不按性别、学习倾向硬排除专业。
4. 专业画像用于区分正主、相近、需复核方向，为后续详细卡片准备证据链。
5. 旧版瀑布流逻辑不丢，V3 只改变家长的使用节奏和展示方式。
