# V3.0.0.rc4｜旧版公式回归与家庭端展示重排版

## 目标

RC4 保留 V3 分步 UI，但把位次风险判断回到旧版 fenxi 公式，去掉家庭端的调试样例和开发口径文案，并重排 A/B/C 与候选页。

## 核心调整

1. 位次层级使用旧版 `classify(rank)` 公式：可冲、匹配、稳妥、保底、过低按当前位次乘区间计算。
2. 数据加载窗口按旧版思路保留上探和兜底空间：normal 使用 `rank * [0.84, 1.45]`。
3. Step1 取消“填入测试样例并加载”“位次附近样例”“loadedRows/分块/耗时”等家庭端展示。
4. Step3 不再展示学校样例，只展示专业方向解释和兴趣命中数量。
5. Step5 先显示位次风险盘，再显示 A/B/C。
6. Step6 改为 Tab：推荐先看、A 守底线、B 看专业、C 看上限、全部候选、筛选条件、家庭自选池。
7. 家庭端文案去掉旧版复刻、执行筛选、分块、调试等开发词。

## 验收样本

- 600 分 / 13601 位：18006 位应为保底；19074 位应为过低。
- 580 分样本：低分候选不能作为主推荐前排，只能作为保底或过低兜底。
- 460 分样本：职业本科、民办、高收费要显著标识，过低候选后置。
- 筛选为 0：只影响当前 Tab，不改写 A/B/C。
