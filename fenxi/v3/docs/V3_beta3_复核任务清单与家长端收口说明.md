# V3.0.0.beta4｜家长端体验收口与移动端可用性增强版

## 目标

beta3 不调整家庭路径、A/B/C、详细候选和导出报告的业务权重，只补齐家长端的“下一步到底查什么”。

## 新增能力

- 新增 `review-checklist-adapter.v3.js`。
- 在主页面决策摘要栏下方新增“复核清单”。
- 自动汇总学费/中外合作、地域底线、兴趣池过窄、专业正主/相近、学习强度、热门词误读、条件变化对照、自选池等待确认事项。
- Debug 一键总检新增复核清单存在性、生成能力和覆盖范围检查。

## 原则

复核清单只负责把风险和待确认事项前置，不改筛选结果，不替代招生章程、官方计划、学费、校区和培养方案复核。
