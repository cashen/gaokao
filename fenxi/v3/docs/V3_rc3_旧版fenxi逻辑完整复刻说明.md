# V3.0.0.rc3｜旧版 fenxi 逻辑完整复刻到 V3 UI 版

本版停止 rc2 fix 链，按旧版 `/fenxi/` 的候选判断口径重建 V3：

- A/B/C 先按位次可行性，再看家庭底线、专业路径和上限价值。
- A 守底线不是最低分优先；过低候选只作兜底核验。
- B 看专业只承接可达范围内的专业正主/相近和孩子兴趣/目标路径。
- C 看上限承接可冲、上探、平台/城市、提档价值，明确风险。
- 候选复核页恢复旧版高报师复核工作台：学校/专业/目录/层级/收费/位次角色/易混/重点学科/旧版排序。
- 候选复核筛选只影响当前视图，不污染基础候选池、A/B/C 和家庭自选池。
- 候选卡恢复旧版信息密度：学校性质、985/211/双非/公办/民办/职业本科、2025分位、位次角色、招生身份、成本提示、年度变化、专业路径、名称陷阱、复核清单。

仍保持 fenxi/v3-only update，不覆盖旧版 `/fenxi/index.html`。
