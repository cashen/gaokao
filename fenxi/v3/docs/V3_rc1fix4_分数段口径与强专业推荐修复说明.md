# V3.0.0.rc1.fix5｜复核清单去技术味与条件变化文案修正版

版本戳：`v300rc1fix5-20260512`

本版基于 `rc1.fix3`，只修 RC1 受控试用前发现的口径与展示问题，不替换旧 `/fenxi/` 主入口，不启用旧 compute 替换。

## 修复内容

1. 分数段展示口径统一：有有效分数时优先按分数判段，避免 `580 分 / 20541 位` 被显示为 `590–624`。
2. `550–589` 文案调整为“专业优先段”，强调专业正主程度、就业确定性和学科/行业匹配。
3. Step1 输入变化后清理下游预览、A/B/C、候选卡片、导出报告和自选池，避免 localStorage 旧草稿残留造成跨测试污染。
4. 版本戳变化时自动重置旧草稿状态，保留访问码，不继承旧版本的候选与报告结果。
5. 强专业路径下，B 方案排序增加专业正主度、兴趣匹配、学科/行业匹配权重。
6. 金融类非顶尖平台组合增加风险提示并在强专业主线中降级。
7. `大数据管理与应用` 增加管理学路径提醒，避免误当作计算机正主方向。
8. 精简版报告隐藏 `evidenceLevel / missingFields` 等技术味表达，改为人话复核提示。
9. 资格型计划条件变化文案改成人话说明。
10. 复核项合并为“专业真实内容复核 / 招生章程复核 / 资格费用校区复核”。
