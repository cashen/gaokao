# V3.0.0.beta8｜导出报告增强与精简完整版版

## 版本定位

基于 beta4 稳定基线继续开发，只增强 Step6 详细候选卡片的家长端比较能力，不改家庭路径权重、不改 A/B/C 方案包、不改候选生成规则。

## 本版新增

- 新增 `candidate-compare-adapter.v3.js`
- Step6 增加卡片筛选：全部 / A / B / C / 只看自选
- Step6 增加排序：按方案与接近程度、位次最接近、安全垫更大、分数更高、复核风险更多、学校名称
- Step6 增加横向比较表，优先读取自选池；自选池为空时先展示当前筛选下的代表样例
- Debug 一键总检新增候选比较适配器、筛选排序策略、横向比较表生成检查

## 不改内容

- 不改 Step4 家庭路径权重
- 不改 Step5 A/B/C 方案包
- 不改 Step6 候选生成逻辑
- 不改反事实比较
- 不改导出报告内容
- 不接旧版正式 compute
- 不覆盖旧 `/fenxi/index.html`

## 验收重点

部署后打开 `/fenxi/v3/debug.html`，点击“一键总检：路径矩阵 + 主流程”。重点看：

- 版本是否为 beta5
- 一键总检是否 0 失败
- 候选比较适配器是否存在
- Step6 卡片筛选排序能力是否接入
- Step6 横向比较表是否可生成
- 主流程是否仍停在导出页
