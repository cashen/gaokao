# V3 孩子专业偏好模块说明

位置：第 3 步，家庭底线之后，场景选择之前。

标题：孩子对什么专业方向感兴趣？（可选，可多选）

## 已实现

- 9 大类专业方向卡片
- 搜索框
- 大类最多 3 个
- 展开具体专业
- 已选标签可删除
- 暂不确定 / 听系统推荐
- manualOnly「只看真实命中兴趣方向」状态
- 生成结构化数据：selectedGroups、selectedMajors、weights、summary

## 9 大类

1. 计算机与人工智能
2. 电子信息与通信
3. 电气能源与自动化
4. 机械、车辆与智能制造
5. 医学、药学与健康
6. 农学、动物医学与食品
7. 经济、管理与金融
8. 法学、人文与教育
9. 理学基础与新材料

## 后续接入方向

默认模式下，兴趣影响排序和说明，尤其提升 B 方案权重；manualOnly 开启后，再接入 fix12 的 interestFastFilter 真实命中过滤。
