# V3.0.0.beta10｜旧版正式计算双轨对比增强版

本版基于 beta9，不改变 V3 当前主流程和候选展示，只增强旧版正式计算链路接入前的安全对比能力。

## 目标

- 继续保持 V3 家庭路径、A/B/C、详细卡片、证据等级和导出报告稳定。
- 在正式接入旧版 compute 前，先输出双轨对比结构。
- 记录旧结果数量、V3 结果数量、差异样本和原因分类。

## 安全边界

- 不主动调用旧 applyFilters 替换结果。
- 不替换 Step5/Step6 当前候选结果。
- 不改变 Step4 家庭路径权重。
- 不改变 A/B/C 方案包和候选生成规则。

## Debug 增强

一键总检新增：

- 旧版正式计算双轨对比策略存在。
- 旧版计算桥接具备差异样本能力。
- 旧版正式计算差异样本已生成。
- 旧版正式计算原因分类已生成。
- 正式 compute 接入护栏仍关闭替换。

## 后续

beta10 通过后，可继续做 beta10.fix1：在安全开关下尝试读取旧 compute 输出，但仍然只做对比，不替换 V3 主链路。
