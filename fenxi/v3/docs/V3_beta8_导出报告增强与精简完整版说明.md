# V3.0.0.beta8｜导出报告增强与精简完整版版

本版基于 beta7 稳定基线，仅增强导出报告表达，不改变家庭路径权重、A/B/C 方案、候选生成、证据等级和旧版 compute 接入状态。

## 核心变化

- 导出报告支持「精简版」和「完整版」双模式。
- 精简版适合复制到微信、家庭群，突出当前结论、A/B/C 样例、必须复核和条件变化。
- 完整版适合归档复核，保留决策日志、A/B/C 详细卡片摘要、自选池、条件变化、证据等级和复核任务。
- 导出页新增模式切换按钮，复制时按当前模式生成报告。

## 安全边界

- 不改 Step4 家庭路径权重。
- 不改 Step5 A/B/C 方案包。
- 不改 Step6 候选生成与详细卡片来源。
- 不改证据等级判断。
- 不覆盖旧 /fenxi/index.html。
