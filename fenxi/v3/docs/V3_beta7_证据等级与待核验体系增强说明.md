# V3.0.0.beta8.fix1｜导出报告双模式自测校准版

本版基于 beta6 稳定基线，只增强证据等级和待核验表达，不改变家庭路径、A/B/C 方案包、候选卡片生成规则和旧 compute 接入预备策略。

## 新增

- `evidence-adapter.v3.js`
- 四类证据桶：数据确认、模型判断、需要复核、缺失数据
- Step6 详细卡片展示证据摘要
- 导出报告写入证据等级提示
- Debug 一键总检增加证据体系检查

## 原则

- 分数/位次等已加载数据标为数据确认。
- 兴趣命中、专业画像、学生画像提醒标为模型判断。
- 学费、中外合作、学校性质、校区、培养方案等保留复核任务。
- 空值和待核验字段进入缺失数据，不假装确定。

## 不改变

- 不改 Step4 家庭路径权重。
- 不改 Step5 A/B/C 逻辑。
- 不改 Step6 候选生成规则。
- 不接正式 compute。
- 不覆盖旧 `/fenxi/index.html`。
