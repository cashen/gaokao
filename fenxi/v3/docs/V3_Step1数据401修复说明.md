# V3 Step1 数据 401 修复说明

alpha2 中 v3 访问码只写入 localStorage，没有调用 `/fenxi/api/login` 建立服务器侧 `ln_gateway_session` Cookie。由于 `/fenxi/data/` 受 Cloudflare Pages Functions middleware 保护，直接 fetch `/fenxi/data/manifest.json` 会返回 HTTP 401。

alpha2.fix1 修复：

1. `access-gate.v3.js` 在输入 `ln2026` 后调用 `/fenxi/api/login`。
2. 如果本机已有 v3 localStorage 访问状态，启动时自动检查 `/fenxi/api/session`，必要时自动补登录。
3. `legacy-data-adapter.v3.js` 的数据 fetch 携带 `credentials: same-origin`。
4. `debug.html` 显示服务器会话状态，并把该项纳入自测。

本修复不接入旧 compute 主筛选链路，只解决 v3 Step1 读取 fix12 数据文件的授权问题。
