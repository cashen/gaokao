# V3.0.0.beta2｜家长端阅读节奏与决策摘要栏版

版本戳：`v300beta2-20260512`

## 目标

在 alpha8 反事实比较与条件放宽建议通过后，继续补齐底部 Tab 的“导出”页。V3 导出优先做家庭讨论报告，不急于替代旧版 PNG/PDF 导出。

## 本版新增

- 新增 `report-export-adapter.v3.js`
- Step7/导出页生成可复制 Markdown 报告
- 报告包含：
  - 当前家庭决策处境
  - 决策日志
  - A/B/C 方案包
  - 详细卡片摘要
  - 自选池
  - 条件变化对照
  - 下一步复核清单
- Debug 一键总检增加导出报告自测

## 原则

报告是家庭讨论稿，不替代招生章程、官方计划、学费、校区和培养方案复核。
