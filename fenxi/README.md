# 辽宁物理类高考志愿初选工具 V2.9.4.7.3

## 版本定位

**V2.9.4.7.3｜高报师工作流与 A/B/C 方案版**。

本版基于 `V2.9.4.7.2｜城市精细化与地域偏好提醒版` 继续迭代，不回退、不重做底层工具。底层仍然继承 `V2.9.4.7.1.fix｜学生画像与学校地域官方校准版`，保留易混专业提醒侧过滤、学生画像提醒、官方高校名单 XLS 校准后的 `school_geo_model`。

## 本次变更总览

本次主要完成 **18 项产品与前端变更**，其中包括：

- **6 项高报师工作流变更**；
- **5 项规则冲突诊断变更**；
- **4 项 A/B/C 方案展示变更**；
- **3 项导出、版本和校验变更**。

本版不是简单改标题，而是把结果页从“候选列表视角”升级为“高报师解释 + A/B/C 方案视角”。

## 一、核心新增能力

### 1. 高报师诊断面板

结果页新增“高报师诊断”区域。

系统会根据当前位次、预算、区域、城市、专业偏好、严格画像、是否低分公办等条件，给出：

- 当前分数 / 位次段判断；
- 主要冲突判断；
- 候选压缩原因；
- 建议优先放宽什么；
- 不建议先放宽什么。

示例逻辑：

```text
低分 + 公办 + 好城市 + 热门专业 + 不出省 + 普通学费
```

系统不会只提示“结果较少”，而会提示：

```text
当前条件属于低分段多重约束。
建议优先放宽城市或专业热度，不建议优先放宽成本底线。
```

---

### 2. 条件强度识别

本版新增内部条件强度模型。

系统会把用户条件拆成：

```text
不关心
偏好
强偏好
硬底线
```

当前已进入解释层的条件包括：

- 家庭成本；
- 地域范围；
- 城市要求；
- 专业热度；
- 民办路径；
- 中外合作路径。

这不是给家长贴标签，而是帮助系统判断哪些条件可以放宽，哪些不应轻易放宽。

---

### 3. 候选池漏斗统计

本版新增候选池压缩漏斗。

系统会显示候选是如何逐步减少的，例如：

```text
位次分段加载：120 条
区域硬筛：58 条
城市硬筛：11 条
预算/高收费保护：6 条
画像拒绝项缩水：2 条
```

这样家长能看懂：

```text
不是系统没有数据，
而是当前条件把候选压缩得太窄。
```

---

### 4. A/B/C 三方案重构

原先的 A/B/C 更像“冲、稳、保”。

本版改为高报师式三路径：

```text
A：稳妥公办方案
B：专业路径方案
C：城市 / 学校层级方案
```

每套方案都显示：

- 一句话定位；
- 适合什么家庭；
- 牺牲了什么；
- 主要风险是什么；
- 为什么入选；
- 必须复核什么。

这三套方案不是冲稳保，而是三种取舍：

```text
A 负责稳；
B 负责准；
C 负责上限。
```

---

### 5. 民办与中外合作进入路径比较

本版继续保留普通家庭防高收费逻辑，但不再把民办和中外合作简单视为“风险项”。

新的解释口径是：

```text
民办不是不能选，而是要算清成本、专业、学校资源和家庭承受力。
中外合作不是天然提档，而是要确认是否真的提高了院校层次、专业质量和未来路径。
```

在预算较宽、强城市、学校层级优先、低分本科边缘等场景下，系统会把民办 / 中外合作作为 C 方案的可比较路径，并提示证书、学费、校区、培养地点等复核项。

## 二、18 项具体变更

### 高报师工作流变更 6 项

1. 结果页标题从“当前可选范围与 A/B/C 三方案”升级为“高报师诊断与 A/B/C 三方案”。
2. 新增高报师诊断面板。

6. 继续保留原始详细候选列表，避免破坏旧使用习惯。

### 规则冲突诊断变更 5 项

8. 新增强省内 + 强就业冲突诊断。

- 考研兜底幻觉；
- 电网想象复核；

15. 每套方案新增“适合家庭、牺牲项、主要风险、为什么入选、需复核”结构。

### 导出、版本与校验变更 3 项

## 四、重要边界

1. 招生名称 ≠ 本科目录专业。
2. 本科目录专业是校准基准。
3. 研究生学科只能参考，不能反推本科实力。
4. 易混专业提醒只提示容易被误认的一侧，正主专业不提示。
5. 性别字段不能用于专业排除，只能影响提醒优先级。
6. 学校地域优先使用官方高校名单 XLS 校准结果。
7. 城市字段表示学校官方所在地，不等于专业实际就读校区。
8. 民办不是不能选，但不能只为本科标签选择。
9. 中外合作不是天然提档，必须核验证书、学费、培养地点、是否必须出国。
10. A/B/C 方案不是最终志愿顺序，只是高报师式取舍路径。

## 五、多终端适配说明

本版重点照顾 PC / Pad / Android 浏览器使用：

- PC 端：三套方案横向展示，便于对比；
- Pad 端：方案卡自动换行，保留完整说明；
- 手机端：诊断面板、候选漏斗、A/B/C 方案自动纵向排列；
- 底部移动导航继续保留：筛选 / 结果 / 候选 / 导出；
- 高报师诊断面板使用可折叠的“条件强度与候选漏斗”，避免手机端信息过重。

## 七、建议测试场景

### 场景 1：普通家庭 540—500

建议验证：

- A 方案是否优先公办、普通学费；
- B 方案是否更偏专业路径；
- C 方案是否提示城市 / 学校层级风险；
- 是否出现“不要先放宽成本底线”的提示。

### 场景 2：500—450，低分公办

建议验证：

- 是否提示低分多重约束；
- 是否提示公办不等于专业适配；
- 是否保留民办 / 高职路径对照的提醒。

### 场景 3：预算宽 + 城市优先

建议验证：

- 中外合作 / 民办是否进入 C 方案比较；
- 是否提示证书、学费、校区、是否必须出国；
- 是否避免把中外合作包装成天然更优。

### 场景 4：电网能源策略

建议验证：

- 是否提示电气正主与泛电类区别；
- 是否要求复核国网招聘口径；
- 是否避免把自动化、测控、能源动力全部等同电气。

### 场景 5：医学方向策略

建议验证：

- 是否提示“医学技术 ≠ 临床医生路径”；
- 是否要求复核执业资格和培养周期；
- 是否避免把带“医学”的专业混为一类。
