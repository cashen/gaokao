# 辽宁物理类高考志愿初选工具 V2.9.4.7.5

## 版本定位

**V2.9.4.7.5｜预算宽路径与紧凑方案盘版**。

本版基于 `V2.9.4.7.4｜专项计划资格默认保护版` 继续迭代，不回退、不另起炉灶。底层继续保留：辽宁物理类 2024/2025 投档数据、2025 一分一段位次匹配、分块加载、专业名三层模型、易混专业提醒侧过滤、学生画像提醒、学校地域城市精细化、高校专项资格默认保护、冲突诊断与 A/B/C 方案框架。

## 本次变更总览

本次主要完成 **15 项变更**：

1. 家庭预算新增“明确想看中外合作提档”选项。
2. 高级筛选新增“办学 / 收费类型”。
3. 办学 / 收费类型支持：全部候选、只看普通学费、可比较中外合作、只看中外合作提档、民办本科可比较、排除高收费/民办。
4. 专业搜索升级为“主专业归一搜索”。
5. 搜“会计学”可以匹配“会计学（中外合作办学）”等括号扩展名称。
6. 系统新增主专业名、办学类型、费用属性标签识别。
7. 中外合作、高收费、民办本科候选在卡片中显示明显标签。
8. 新增“提档价值优先”排序。
9. C 方案升级为“城市 / 学校层级 / 中外合作提档路径”。
10. A/B/C 从单张大卡升级为紧凑方案盘。
11. 每列默认显示 3—4 个代表候选，而不是只显示 1 个。
12. 每列显示候选统计：共几条、冲几条、稳几条、保几条、比较几条。
13. 每个候选小卡显示：冲/稳/保/比较、为什么放这里、主要风险、复核点。
14. 移动端保留单列紧凑展示，避免三列硬挤。
15. 新增 `tools/validate-v29475-release.js` 校验脚本。

## 一、为什么做这一版

之前 A/B/C 方案已经能说明：

```text
A：稳妥公办
B：专业路径
C：城市 / 学校层级
```

但每列如果只有一个大方案，会显得空，也不像真实高报师摆方案。

本版改成：

```text
A 是一条路径，下面放 3—4 个代表候选；
B 是一条路径，下面放 3—4 个代表候选；
C 是一条路径，下面放 3—4 个代表候选。
```

同时，预算宽家庭和中外合作提档不再靠用户猜关键词，例如不再要求用户必须输入：

```text
会计学（中外合作办学）
```

更合理的方式是：

```text
专业关键词：会计学
办学 / 收费类型：中外合作可比较 / 只看中外合作提档
家庭预算：预算较宽 / 明确想看中外合作提档
```

## 二、预算宽 / 中外合作提档逻辑

本版把三个概念拆开：

```text
会计学 = 主专业
中外合作 = 办学类型
提档 = 家庭策略
```

系统内部会把：

```text
会计学（中外合作办学）
```

归一为：

```text
主专业名：会计学
办学类型：中外合作
费用属性：高收费
```

因此用户搜：

```text
会计学
```

可以匹配：

```text
会计学
会计学（中外合作办学）
会计学（国际会计）
会计学（ACCA）
工商管理类（含会计学方向）
```

最终是否展示中外合作，取决于家庭预算和办学 / 收费类型。

## 三、A/B/C 方案盘逻辑

A/B/C 不是冲稳保。

```text
A/B/C = 决策路径
冲稳保 = 每条路径里的安全等级
```

所以 A 里面可以有冲、稳、保，B 里面也可以有冲、稳、保，C 里面也可以有冲、稳、保/比较。

### A：稳妥公办路径

优先：

```text
公办
普通学费
位次稳 / 保
专业误认风险低
孩子适配风险低
地域符合底线
```

### B：专业路径

优先：

```text
专业正主
相近专业替代
孩子适配较高
就业 / 考研 / 考公路径清楚
易混风险可解释
```

### C：城市 / 学校层级 / 中外合作提档路径

优先：

```text
城市更好
学校层级更高
中外合作提档
民办城市专业
资源更好但成本更高
```

## 四、典型用法

### 场景 1：普通家庭搜会计学

```text
家庭预算：普通家庭，优先普通学费
专业关键词：会计学
办学 / 收费类型：普通学费/普通专业
```

预期：

```text
普通会计学优先；
中外合作 / 高收费 / 民办默认不进入主方案。
```

### 场景 2：预算较宽，想比较全部会计学

```text
家庭预算：预算较宽，可比较中外合作/民办
专业关键词：会计学
办学 / 收费类型：全部候选
```

预期：

```text
普通会计学、中外合作会计学、民办会计学都可进入比较；
但中外合作和民办会打风险与复核标签。
```

### 场景 3：明确只看中外合作提档

```text
家庭预算：明确想看中外合作提档
专业关键词：会计学
办学 / 收费类型：只看中外合作提档
```

预期：

```text
会计学（中外合作办学）等项目能被搜到；
C 方案变为城市 / 学校层级 / 中外合作提档路径；
卡片提示学费、证书、校区、培养模式复核。
```

## 五、仍然保留的 V2.9.4.7.4 逻辑

```text
高校专项计划不是普通候选。
默认隐藏。
只有考生明确选择“已通过高校专项计划审核”，系统才展示。
```

也就是说，中外合作提档功能不会破坏专项计划默认保护。
