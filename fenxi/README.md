# 辽宁物理类高考志愿初选工具

当前版本：V2.9.5.4｜规则中心落地与场景保护修正版｜fix2 规则中心落地与场景保护修正版。

本版基于 V2.9.5.3_textfix 稳定包继续小步修订，只调整访问入口展示、页面标题、顶部说明标签和“重置条件”按钮样式，不改变筛选规则、A/B/C 方案逻辑、专项保护、数据模型和导出口径。

## 本版调整

- 页面标题移除“旧版调试副标题”遗留命名。
- 顶部可见区域不再直接展示访问码。
- 访问输入框不再用占位文案暗示访问码。
- 访问失败、重新输入等提示不再暴露正确凭证。
- 顶部标签由旧版规则标签调整为“家长初筛规则”。
- 数据状态文案调整为“本科目录与招生名已复核”。
- “定位孩子分数 / 位次”中的“重置条件”按钮改为柔和绿色样式，提升可识别性。
- 所有主资产文件升级为 v2954fix2 命名，降低旧缓存误加载概率。

## 部署

将本包根目录内容部署到 Cloudflare Pages 即可。

## 说明

本工具仍是纯前端静态工具。前端访问凭证适合小范围测试与家庭内部使用；如需更严格的访问控制，建议在 Cloudflare Pages 前增加 Cloudflare Access。
