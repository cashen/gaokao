# 辽宁物理类高考志愿初选工具

## V2.9.5.0｜家长流程重排与方案引擎瘦身版

本版基于 `V2.9.4.7.6｜A/B/C 方案引擎与路径解释版` 继续迭代，目标不是继续堆功能，而是把家长真实使用流程重新理顺，并对 A/B/C 方案盘做局部瘦身和可演进处理。

## 本次核心改动

1. 新五步流程固定为：①位次 → ②家庭底线 → ③目标路径 → ④A/B/C方案盘 → ⑤详细候选与自选。
2. 新增并前置“家庭底线卡”，集中处理预算、专项资格、地域城市、是否出省、明确不接受项。
3. A/B/C 方案盘前移为主结果展示，放在家庭底线与目标路径之后、详细候选之前。
4. 新增“家长简洁模式”，默认收起高级规则和高级筛选，降低新手家长认知负担。
5. 保留原有透明规则，不做黑盒推荐：高校专项默认隐藏、预算宽/中外合作提档、主专业归一、易混提醒、学生画像、城市校准均继续保留。
6. 接管并瘦身 `renderPlanABC()`：旧版多代 `renderPlanABC` 已改名为 deprecated，运行入口统一到 V2.9.5.0 新版。
7. A/B/C 解释进一步清晰化：A 显示底线命中，B 显示专业路径正主/相近/需核验，C 显示换来/付出/复核。
8. 详细候选区降级为“给高报师和熟练用户复核”的区域，不再抢主结果视线。
9. 移动端继续保持单列/紧凑布局，底部导航改为：位次、底线、方案、自选、导出。
10. 新增 `tools/validate-v2950-release.js`，检查入口、五步流程、家庭底线卡、A/B/C 方案盘、简洁模式和导出入口。

## 保留能力

- 辽宁物理类 2024 / 2025 投档数据
- 2025 一分一段位次匹配
- 分块加载数据引擎
- 专业名三层模型：招生名称 / 本科目录 / 研究生参考
- 易混专业正主保护
- 学生画像提醒
- 学校地域城市校准
- 高校专项默认保护
- 预算宽 / 中外合作提档路径
- 主专业归一搜索
- A/B/C 方案盘
- 自选池与 CSV / PNG 导出

## 建议验证场景

1. 普通家庭 530 分：先填位次，再确认普通学费、公办、省内，查看 A/B/C 是否清楚。
2. 预算宽 + 会计学：选择“明确想看中外合作提档”，搜索会计学，查看 C 方案是否包含中外合作/高收费提档解释。
3. 高校专项未审核：默认不应在 A/B/C 和详细候选中出现高校专项计划。
4. Android 小屏：默认简洁模式下应先看到位次、底线、目标、方案，不应被高级筛选淹没。
5. 高报师完整模式：关闭“家长简洁模式”后，应能看到高级规则和高级筛选。
