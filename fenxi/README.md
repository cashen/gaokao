# 辽宁物理类高考志愿初选工具 V2.9.4.5

本包基于 V2.9.4.4 增量升级，主题为：**家长关心点表达增强版**。

## 本版核心

不新增“保研率”模块，不引入新的外部采集数据；只把已有数据翻译成家长更关心的表达：

- 这个招生名到底是不是最终专业？
- 是大类、试验班、中外合作，还是具体专业？
- 2025 比 2024 更难进还是更好进？
- 普通家庭是否存在成本风险？
- 专业名字有没有容易误解的地方？
- 这条候选是建议保留、谨慎保留，还是复核后再保留？

node tools/validate-major-name-model-v2944.js
