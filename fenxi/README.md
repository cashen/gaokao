# 辽宁物理类高考志愿初选工具 V2.9.4.7.2

## 版本定位

V2.9.4.7.2｜城市精细化与地域偏好提醒版。

本版基于 `V2.9.4.7.1.fix｜学生画像与学校地域官方校准版` 继续迭代，不回退、不重做底层工具。

## 本版新增

1. 学校所在地城市显性化：卡片、家长必读、CSV、PNG、debug 均展示 `省份 · 城市`。
2. 城市偏好输入：支持多个目标城市，空格、逗号、顿号分隔。
3. 城市偏好模式：
   - 不限制城市；
   - 只提醒 / 降权，不排除；
   - 硬筛：只看目标城市。
4. 沈阳优先、大连优先策略卡接入城市偏好。
5. 导出 CSV 新增省份、城市、区域、地域来源、地域置信度和地域说明。
6. PNG 摘要显示目标城市和城市版本号。
7. debug 面板显示城市模式、目标城市和当前结果城市 Top。
8. 新增 `tools/validate-school-city-v29472.js`，用于校验全量学校城市字段和入口引用。

## 继承不变的核心逻辑

- 辽宁物理类 2024 / 2025 投档数据。
- 2025 一分一段位次匹配。
- 分块加载数据引擎。
- 专业名三层模型：招生名称 / 本科目录 / 研究生参考。
- 本科目录 K/T 标识解释。
- 家长关心点表达。
- 易混专业识别。
- 易混专业正主保护与提醒侧过滤：正主不提示，容易被误认的一侧才提示。
- 学生画像提醒。
- 学校地域标准化补全。
- 官方高校名单 XLS 校准后的 `school_geo_reference`。
- PNG 导出。
- 多终端适配。
- debug 面板。

## 重要边界

1. 招生名称 ≠ 本科目录专业。
2. 本科目录专业是校准基准。
3. 研究生学科只能参考，不能反推本科实力。
4. 易混专业提醒只提示容易被误认的一侧，正主专业不提示。
5. 性别字段不能用于专业排除，只能影响提醒优先级。
6. 学校地域优先使用官方高校名单 XLS 校准结果。
7. 城市字段表示学校官方所在地，不等于专业实际就读校区。
8. 普通家庭视角下，重点看：方向是否看错、成本是否可承受、孩子是否学得动、路径是否清楚。
