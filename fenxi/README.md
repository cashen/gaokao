# 辽宁物理类高考志愿初选工具 V2.9.4.7.4

## 版本定位

**V2.9.4.7.4｜专项计划资格默认保护版**。

本版基于 `V2.9.4.7.3｜高报师工作流与 A/B/C 方案版` 继续迭代，不回退、不重做底层工具。底层继续保留：辽宁物理类 2024/2025 投档数据、2025 一分一段位次匹配、分块加载、专业名三层模型、易混专业提醒侧过滤、学生画像提醒、学校地域城市精细化、冲突诊断与 A/B/C 三方案框架。

## 本次变更总览

本次主要完成 **12 项变更**：

1. 新增“高校专项资格”输入字段。
2. 默认值为“未通过 / 未审核”。
3. 默认隐藏 `辽宁省高校专项计划`、`高校专项计划` 等资格入口。
4. 用户选择“已通过高校专项计划审核”后，专项候选才进入结果。
5. 用户选择“不确定”时，暂按未审核处理，继续隐藏专项候选。
6. 结果区新增“高校专项计划默认保护”提示。
7. 统计区新增“专项隐藏”计数。
8. 候选池漏斗新增“高校专项资格保护”阶段。
9. 专项计划默认不参与 A/B/C 三方案。
10. 专项计划默认不参与冲突诊断的普通候选缓解建议。
11. 已通过审核时，专项候选打上“高校专项资格”标签并加入复核项。
12. 新增 `tools/validate-v29474-release.js` 校验脚本。

## 一、为什么要做这一版

投档数据里出现的：

```text
辽宁省高校专项计划
高校专项计划
```

不是普通考生“分够就能报”的入口。它通常要求考生提前完成专项资格申请、审核和公示。

如果默认混入普通候选池，会带来三类误导：

```text
1. 普通考生看到自己不能报的入口；
2. A/B/C 方案被专项计划污染；
3. 家长误以为低分多了一个普通机会。
```

所以本版定下一个默认保护原则：

```text
高校专项计划不是普通候选。
默认隐藏。
只有考生明确选择“已通过高校专项计划审核”，系统才展示。
```

## 二、新增字段

位置：第一步“填孩子分数 / 位次”区域。

字段名称：

```text
高校专项资格
```

选项：

```text
未通过 / 未审核（默认）
已通过高校专项计划审核
不确定，暂按未审核处理
```

默认逻辑：

```text
未通过 / 未审核 = 隐藏专项计划
不确定 = 隐藏专项计划
已通过 = 显示专项计划，并强提醒复核
```

## 三、筛选逻辑

### 1. 默认未审核

专项计划不进入：

```text
普通结果列表
A/B/C 三方案
冲突诊断候选池
候选池漏斗后续普通路径
```

结果区会显示：

```text
已隐藏高校专项计划候选 X 条。
当前默认“未通过 / 未审核”。这些不是普通考生“分够就能报”的入口。
```

### 2. 已通过审核

专项计划进入候选列表，并带标签：

```text
高校专项资格
```

复核项会增加：

```text
专项资格审核
资格审核结果
公示名单
当年招生计划
招生章程
```

结果区会提示：

```text
已显示高校专项计划候选 X 条。正式填报前仍需复核资格审核结果、公示名单和当年招生计划。
```

### 3. 不确定

按未审核处理。

```text
不确定，暂按未审核隐藏。
```

这是为了防止把资格入口误当普通候选。

## 四、识别规则

本版只重点识别：

```text
辽宁省高校专项计划
高校专项计划
```

暂时不把所有“专项”一刀切隐藏，避免误伤：

```text
国际合作专项
民族班
预科班
定向
其他特殊入口
```

这些仍保留原来的“专项/特殊入口”风险提醒，后续可以单独拆规则。

## 五、与 A/B/C 方案的关系

### 未审核 / 不确定

```text
A/B/C 三方案全部忽略高校专项计划。
```

### 已通过审核

专项候选可以进入结果与方案，但必须带标签和复核项。

更稳的使用建议是：

```text
普通候选 A/B/C 正常看；
专项计划候选单独重点复核资格。
```

## 六、与冲突诊断的关系

专项计划不能用来缓解普通考生的结果偏少。

例如：

```text
低分 + 公办 + 城市优先 + 普通学费
```

系统不能因为专项计划看起来位次更友好，就把它作为普通考生的解决方案。

除非用户明确选择：

```text
已通过高校专项计划审核
```

否则它不参与普通候选池和冲突缓解建议。

## 七、继承不变的核心逻辑

- 位次优先，分数辅助；
- 招生名称 ≠ 本科目录专业；
- 本科目录专业是校准基准；
- 研究生学科只能参考，不能反推本科实力；
- 易混专业正主保护：正主不提示，容易被误认的一侧才提示；
- 性别字段不能用于专业排除；
- 学校地域优先使用官方高校名单 XLS 校准结果；
- 城市字段表示学校官方所在地，不等于专业实际就读校区；
- 民办不是不能选，但不能只为本科标签选择；
- 中外合作不是天然提档，必须核验证书、学费、培养地点、是否必须出国；
- A/B/C 方案不是最终志愿顺序，只是高报师式取舍路径。
