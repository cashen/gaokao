# V2.9.4.7.6｜A/B/C 方案引擎与路径解释版

本版基于 **V2.9.4.7.5.fix3｜A/B/C 首选样式与备选小卡修正版** 继续开发。

本次不是全局重写，也不是继续简单叠加卡片，而是做了一次**局部架构整理**：只接管 A/B/C 方案盘、专业路径解释、C 方案提档价值解释和自选来源记录；数据加载、主筛选、专项计划保护、预算宽 / 中外合作提档、主专业归一搜索等稳定能力继续保留。

## 本次核心变更

1. 新增 `PLAN_MODES_V29476`，把 A/B/C 从页面卡片升级为可配置的方案模式。
2. A 方案明确为“守底线”：公办、普通学费、位次安全、地域可控、非专项误入。
3. B 方案新增 `PATH_RULES_V29476` 专业路径库初版。
4. B 方案首批支持 9 类路径：财会 / 经管、电气 / 能源、电子信息 / 通信、计算机 / 数字技术、医学 / 医学技术、师范 / 考编、机械 / 自动化 / 交通、考公 / 体制、深造依赖 / 传统工科。
5. C 方案新增“提档价值解释”，每个 C 候选展示“换来了什么、付出了什么”。
6. C 方案可区分普通批层级提升、中外合作 / 高收费提档、民办城市专业、城市资源提升等子路径。
7. 首选推荐理由按 A/B/C 分别生成：A 看为什么稳，B 看为什么是路径，C 看换来什么、付出什么。
8. 备选小卡增加路径/提档小标签，避免 A/B/C 看起来都是普通候选列表。
9. 自选池新增来源记录：来源方案、方案角色、路径标签、加入时间。
10. “加入 A/B/C 方案”时自动保存来源，后续复核和 CSV 导出可追溯。
11. CSV 导出新增：来源方案、方案角色、路径标签、主专业名、办学类型、复核项等字段。
12. 保留 29474 高校专项计划默认隐藏逻辑，未通过专项资格时不会进入 A/B/C。
13. 保留 29475 预算宽 / 中外合作提档逻辑，搜“会计学”仍可通过主专业归一匹配“会计学（中外合作办学）”。
14. PC / Pad / Android 的方案盘布局继续保留，新增路径解释块的响应式样式。
15. 新增 `tools/validate-v29476-release.js`，用于检查入口、方案引擎、专业路径库、提档价值解释、自选来源记录和导出字段。

## 版本定位

```text
A 不是一组学校，A 是守底线；
B 不是一组专业，B 是走路径；
```

# 辽宁物理类高考志愿初选工具 V2.9.4.7.5.fix2

## 版本定位

**V2.9.4.7.5.fix2｜A/B/C 首选推荐与一键加入自选版**。

本版基于 `V2.9.4.7.5.fix｜A/B/C 多候选方案盘修正版` 继续迭代，不回退、不另起炉灶。底层继续保留：辽宁物理类 2024/2025 投档数据、2025 一分一段位次匹配、分块加载、专业名三层模型、易混专业提醒侧过滤、学生画像提醒、学校地域城市精细化、高校专项资格默认保护、预算宽/中外合作提档、主专业归一搜索、冲突诊断与 A/B/C 方案盘。

## 本次变更总览

本次主要完成 **13 项修正 / 增强**：

1. A/B/C 每列从“4 张同权重小卡”升级为“1 张首选推荐大卡 + 2—3 张备选小卡”。
2. A/B/C 顶部文案强化差异：A 看底线，B 看专业，C 看上限。
3. A 方案强化“公办、普通学费、位次更稳、少犯大错”的稳妥逻辑。
4. B 方案强化“专业路径、专业正主/替代、孩子适配、就业/考研/体制方向”的路径逻辑。
5. C 方案强化“城市、学校层级、中外合作/民办/高收费提档”的上限逻辑。
6. B 方案增加专业路径标签，例如财会/经管、电气/能源、电子信息/通信、计算机/数字技术、医学/医学技术、师范/考编等。
7. C 方案增加提档路径标签，例如中外合作/高收费提档、民办城市专业、学校层级更高、城市资源匹配等。
8. A/B/C 选取逻辑增加“路径差异保护”，避免 A、B、C 看起来过于相似。
9. 每列新增“加入本方案 N 条”按钮。
10. 方案盘顶部新增“加入全部 A/B/C 候选”按钮。
11. 加入自选时按“学校 + 专业 + 计划类型 + 年份 + 位次/分数”自动去重，避免重复加入。
12. PC 端保持三列方案盘；Pad 自动改为 2 列 + C 横跨；Android / 小屏改为单列堆叠，避免硬挤。
13. 新增独立入口文件 `assets/app.v29475fix2.js` 和 `assets/app.v29475fix2.css`，`index.html` 已切换到 fix2 入口。

## 一、为什么做这一版

`V2.9.4.7.5.fix` 已经解决了 A/B/C 每列不再只有 1 张卡的问题，但实际使用中仍然存在两个体验问题：

```text
1. A 和 B 都是公办、普通学费、工科时，家长会觉得两列差不多。
2. 每列 4 张卡同权重排列，缺少“这列先看哪一个”的首选推荐感。
```

本版把 A/B/C 进一步改成高报师更常见的展示方式：

```text
A：稳妥公办路径
  首选推荐 1 个
  备选比较 2—3 个

B：专业路径
  首选推荐 1 个
  备选比较 2—3 个

C：城市 / 学校层级 / 提档路径
  首选推荐 1 个
  备选比较 2—3 个
```

这样家长能先看到每条路径的首选，再看补充比较。

## 二、A/B/C 的新解释

A/B/C 不是冲稳保。

```text
A/B/C = 决策路径
冲稳保 = 每条路径里的安全等级
```

### A：稳妥公办路径

核心是：

```text
先保底线：公办、普通学费、位次更稳。
```

适合：

```text
普通家庭
低容错家庭
强省内家庭
公办优先家庭
不想先碰高收费/民办/中外合作的家庭
```

### B：专业路径

核心是：

```text
先看方向：专业是否看得准，孩子是否学得动。
```

适合：

```text
强就业家庭
孩子有明确兴趣家庭
强考研家庭
强体制家庭
需要区分专业正主和相近替代的家庭
```

### C：城市 / 学校层级 / 提档路径

核心是：

```text
争取上限：城市、学校层级或中外合作提档，但复核要求更高。
```

适合：

```text
预算较宽家庭
强城市家庭
学校层级优先家庭
明确想看中外合作提档的家庭
愿意比较民办城市专业的家庭
```

## 三、首选推荐与备选小卡

每列默认展示：

```text
1 张首选推荐大卡
2—3 张备选小卡
```

首选推荐大卡显示：

```text
冲 / 稳 / 保 / 比较
学校 + 专业
城市 / 性质 / 学费 / 位次
为什么放这里
主要风险
复核点

```

备选小卡显示：

```text

冲 / 稳 / 保 / 比较
学校 + 专业
为什么作为备选
主要风险
复核点
加入按钮
```

## 四、一键加入自选

本版新增：

```text
加入 A 方案 N 条
加入 B 方案 N 条
加入 C 方案 N 条
加入全部 A/B/C 候选
```

加入时会自动去重。去重键不是简单的学校名 + 专业名，而是尽量使用：

```text
学校 + 招生专业名 + 计划类型 / 批次 + 年份 + 位次 / 分数
```

这样可以避免把以下几类误合并：

```text
会计学
会计学（中外合作办学）
会计学（高校专项计划）
```
