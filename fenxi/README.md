# 辽宁物理类高考志愿初选工具 V2.9.4.6.2

## 版本定位

V2.9.4.6.2｜易混专业提醒侧过滤版

本版本基于 V2.9.4.6.1，不改变投档数据、一分一段、本科目录、家长关心点和易混专业检测结果，只优化易混提醒的展示侧：

> 正主专业不主动打“易混专业”提醒；真正容易被误认为正主/目标路径的一侧才显示提醒。

## 核心变化

- 保留 `confusable_major_detected_pairs_v2946.json` 原始易混专业对。
- 新增 `confusable_major_detected_pairs_v29462.json`，为每个 pair 的 item 标注：anchor / warning / neutral。
- 新增 `confusable_major_record_index_v29462.json`，只包含需要提醒的一侧。
- 前端改用 `confusable-major-model.v29462.js` 和 `app.v29462.js`。

## 典型效果

- 营口理工学院：
  - 数据科学与大数据技术：正主保护，不主动提示。
  - 大数据管理与应用：显示易混提醒。

- 电气/国网场景：
  - 电气工程及其自动化：正主保护，不主动提示。
  - 自动化、测控技术与仪器、电子信息工程：显示提醒。

## 运行方式

部署整个目录到静态网站根目录即可，打开 `index.html`。

访问码保持：`ln2025`。
