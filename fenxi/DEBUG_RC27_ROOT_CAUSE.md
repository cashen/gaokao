# V2.92RC2.7 audit-conflict-aware-runner

本版修复 RC2.6 的最后一类误判：

- RC2.6 已经可以跑完 36/36，TIMEOUT=0，说明 debug runner 已经通。
- 剩余 FAIL 主要来自审计口径：当学生兴趣与家庭底线冲突时，审计器仍强制 ABC 围绕原兴趣。
- 典型场景：医学兴趣但拒绝夜班/长周期；电气/电网兴趣但拒绝现场/设备环境。
- RC2.7 将这类情况改为 conflict-aware WARN：不再判定为“全局兴趣失效”，而是要求检查风险提示、降权和替代路径。
- 同时扩展“财会金融+城市优先”的可接受路径，把财会、金融、管理、公共服务、表达类、数据管理/信管类都纳入人类场景口径。

边界：不改 DATA，不改正式 A/B/C 公式，不改业务推荐算法，只修 debug 人类审计语义。
