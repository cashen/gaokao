# v3.9.6.6-ln-rank-pool-entry-width-keyword-ui

本版基于 v3.9.6.5，仅做搜索页 UI 动线与多终端体验收口，不改关键词搜索后端逻辑，不动 `/fenxi`。

## 核心变化

1. 自选池入口从搜索工作台内部移出，改成稳定的固定入口。
   - PC：右侧固定小块 `自选池 N`，点击直接进入完整自选池页。
   - 手机：底部固定条 `自选池 N`，点击直接进入完整自选池页。
   - 不做抽屉、不做半屏弹层，避免手机误触和二次维护。

2. 页面宽度收住。
   - 全局页面外壳最大宽度约 1280px。
   - 搜索工作台、分数卡、结果区最大宽度约 1180px。
   - 避免 PC 宽屏下页面过宽、信息过散。

3. 专业 / 项目 / 行业关键词输入框精细化。
   - 输入框不再横跨整页。
   - placeholder 缩短为 `如：计算机/中外/石油`。
   - 下方增加常用词 chips：计算机、电气、自动化、土木、中外、石油、交通、医学、师范。
   - 点击 chip 会追加到输入框，重复点击不会重复添加。

4. 版本继续统一。
   - index.html 引用 `app.v3966.js`。
   - selection-pool.html 引用 `selection-pool.v3966.js`。
   - 新增 `release-meta.v3966.js`。

## 不变

- 不改 `/fenxi`。
- 不改 `/fenxi/data`。
- 不包含 `functions/fenxi`。
- 不包含 `functions/_middleware.js`。
- 不改 `/api/major-bands` 搜索逻辑。
- 不改公办底线显示边界。
- 不改 AI 诊断和飞书报告逻辑。
