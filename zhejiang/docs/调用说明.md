# 调用说明

## 1. 加载 manifest

```js
const manifest = await fetch('./data/manifest.json').then(r => r.json())
```

## 2. 查询学校

```js
const schools = await fetch('./data/index/schools_index.json').then(r => r.json())
const item = schools.find(x => x.school_name === '辽宁科技大学')
```

## 3. 通过 record_id 找 raw 文件

```js
const locator = await fetch('./data/index/record_locator.json').then(r => r.json())
const loc = locator['zj2025_05743']
// loc.raw_file = raw/2025/zj_2025_part_002.json
```

## 4. 读取 raw 分片

```js
const rows = await fetch('./data/' + loc.raw_file).then(r => r.json())
const record = rows.find(x => x.record_id === 'zj2025_05743')
```

## 5. 使用分数分片

```js
const rows = await fetch('./data/shards/2025/analysis/zj_2025_analysis_550_599.json').then(r => r.json())
```
