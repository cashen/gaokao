# 字段说明

| 字段 | 含义 |
|---|---|
| record_id | 唯一记录编号 |
| source_row | 原始 XML 行号 |
| year | 年份 |
| batch_code | 批次编码 |
| batch_name | 批次名称 |
| school_province | 学校所在省份/投档分组 |
| school_code | 院校代码，保留前导 0 |
| school_name | 院校名称 |
| major_name | 专业名称 |
| score.avg_score | 2024 平均分，2025 通常为空 |
| score.min_score | 最低分 |
| score.first_stage_min_score | 2025 一段最低分 |
| score.analysis_score | 默认分析分 |
| score.final_score | 2025 最终最低分 |
| rank_raw | 原始位次文本 |
| rank | 数字位次 |
| compare_key_exact | 对比键：院校代码 + 专业名 |
